## 数值红线(每卷)
| 指标 | 红线 | 说明 |
|---|---|---|
| 燃点间隔 | ≥1/卷,≤3/卷 | 燃后必须落弹(情感/生活拍) |
| 泪点配额 | ≤2/卷 | 连续两个泪点间≥5章 |
| 钩分布 | 对话切≤55%/悬念≥20%/叙述收≤20% | 连续2章叙述收=平淡警报 |
| 松段配给 | 每8-12章≤1章 | 危机周期间隔上限=12章 |
| 爽点蓄压 | 任意时刻充能≥2条 | 爆发处必须埋新钩 |
| 峰章体量 | 卡带上限+20% | alt-takes必走 |
