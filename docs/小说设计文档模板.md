# 小说设计文档（Novel Design Document）
> **本文件是写第一章之前必须填完的文件。没填完不许动笔。**
> 这是32份审计+3份专项研究+45章实践后提炼的终极前置模板。

## 一、核心冲突（不能是"赚钱"或"变强"）

- **核心问题句**（一个问句，终卷回答）：
  <!-- 例："一个修了二十年手机的人重生回2005年，能不能不再只做一个手艺人？" -->

- **主角最怕失去的东西**（不是命，是比命更疼的东西）：
  <!-- 例：妹妹的前途 / 父亲的认可 / "公道"二字的招牌 -->

- **如果主角失败，最坏结果是什么**（必须具体到画面）：
  <!-- 例：妹妹背着编织袋上了去南方的大巴 -->

- **对手是谁**（不是"环境"或"时代"，是一个有名字的人）：
  <!-- 例：曹三（本地地头蛇）→ 迅捷白牙（外来资本）→ 省城总代（ unseen boss） -->

- **对手的目标是什么**（对手按自己的理性做事，不降智）：
  <!-- 例：曹三要垄断三楼；迅捷要吃掉县城市场再往省城扩 -->

## 四、赢法轮换表（连续两章禁同款）

| 赢法类型 | 说明 | 使用章号 |
|---|---|---|
| 智取 | 靠信息差或计谋赢 | |
| 硬碰 | 正面硬扛，比谁更硬 | |
| 借力 | 利用第三方或对手的破绽 | |
| 忍让 | 暂时退让，换取更大空间 | |
| 认亲/认人 | 情感打动，不战而胜 | |
| 代价换 | 付出看得见的代价换取胜利 | |

**规则：每章记录使用了哪种赢法。连续两章同款=大纲有问题。**
