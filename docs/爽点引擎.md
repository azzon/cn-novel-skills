# 爽点引擎：蓄压-兑现管道（v2，调研已融合）

> 调研来源：斗破退婚/大奉税银案/赘婿岁布战/飞卢vs起点四场拆解+龙空系教程（详见story/audit/打脸技法调研-2026-09-11.md）。

> 依据：书主方向判断（"读者要看装逼打脸，要期待链，要欲罢不能"）+CSDN打脸四步法（铺垫→挑衅→拉扯→爆发）+NGA"度"警告（压不够打脸无力/压过头弃书）+本库旧书教训。名场面拆解待调研代理返回后补§六。

## 一、总纲：主角不输，只蓄压

爽文的"挫折"是延迟满足，不是悲剧。三种"不利"分级：
- **面子受损**（被低估/被嘲讽/被刁难）→ ✅蓄压燃料，多多益善
- **利益受阻**（被截胡/压价/亏钱）→ ✅可蓄压，但**5章内必须有更大反提**
- **核心溃败**（事业崩/家人出大事/当众认输）→ ❌禁止
（修正此前"让曹三赢一次"的表述：曹三赢的是利益=充能，不是面子——面子战主角不可输。）

**爽点仪表（每章冷读三问）**：①管道在充能的悬念≥2条？②当章兑现≥1个小爽？③距上次大爽≤8章、距上次台阶（实力/地位/资产升级）≤10章？

## 二、装逼七型（轮换防复读）

| 型 | 定义 | 本书案例位 |
|---|---|---|
| 实力型 | 当场露一手 | 修机马拉松/夜市首修（主型） |
| 成果型 | 拿结果说话 | 月底流水摊开/柜台前排队的散客 |
| 借力型 | 大人物背书 | 丁师傅一句"这孩子手比我稳"/罗胖子赊租 |
| 先知型（无心） | "随口"说中，事后才炸 | **知识分层纪律(金手指地图§三)**:泛趋势高频/中预测每卷2-3次/精确预言每卷≤3次且事后给凡人解释——先知解决做什么,不解决怎么做 |
| 反杀型 | 对手刁难→证据链反杀 | 鬼秤局 |
| 侧面型 | 不出场也装 | 竞争对手研究他/顾客转述走样/曹三背后打听他 |
| 认可型 | 权威/长辈的沉默认可 | 父亲在电子城门口站了很久没进去（最高级，不用一句台词） |

**轮换规则**：连续2章同型=红灯；两个大爽点不相邻同型；"先知型"每卷≤3次（用多就神棍化）。

## 三、高级七律（回答"怎么优雅地装"）

1. **爽点绑定价值观**：读者爽的是他认同的价值赢（手艺/孝心/识人/勤奋），不是钱本身；打脸对象必是读者讨厌的人（势利/虚伪/恃强凌弱/伪专家）。
2. **用事实不用宣言**：主角不解释不吹，让事实自己揭开（机器说话/流水说话/结果说话）。台词越少越贵。
3. **震惊四层写法**（配角路人震惊的正确姿势）：
   - ①**当事者失态的细节**——烟掉在脚面上没觉着/报价单捏皱了/嘴硬到一半卡住（动作，不是"他震惊了"）
   - ②**内行的震惊**——说行话或沉默：丁师傅看焊点不说话=最高认可（内行震惊永远比外行喝彩值钱）
   - ③**外行连锁**——围观→议论→传开（具体到某两个人吵起来）
   - ④**回味拍**——事后这事在电子城怎么传、传成什么样（走样=幽默+二次爽："听说一中的学生用牙签就把主板修了"）
4. **观众要有人味**：面子战必有观众，但观众各怀立场（看热闹的/担心的/酸的还是盼他赢的），不是复读"这怎么可能"的啦啦队。
5. **打脸必带利息**：兑现永远超额——赢之外顺手多拿一样（名声/长期客户/对手阵营裂痕/关键人物记住他）。
6. **拉扯1-2次**：爆发前"差一点"（对方不信→再验一次→彻底哑火），张力翻倍；但**不拖章**（当章爆或下章爆，蓄压可以长、兑现必须快）。
7. **幽默解尬**：装逼完成立刻自嘲一笔或让配角拆台（防主角油腻）——与本库喜剧编制联动。

**低级黑名单**：主角自吹/"你怎么可能！"/路人复读惊叹/反派无脑降智/打脸无铺垫空爆。

## 四、期待链（书主核心洞察的制度化）

**定义**：任意时刻管道里**同时在充能的悬念≥2条**；当章爽点兑现的瞬间，新挑衅必须已经在场。

**结构规律**：A线爆发的高潮段=B线挑衅入场的最佳位置（读者情绪最高点埋钩最便宜，钩子命中率最高）——这就是"一个装逼没走到高潮就开始铺下一个"的机械实现。

**悬念三原料**（不全是敌人）：挑衅型（曹三/黑柜台/迅捷）、认可型（丁师傅会认可他吗/父亲会直腰吗）、机会型（柜台基金凑得齐吗/那批货是不是雷）。

**管道台账**（ledgers/爽点管道.md）：每条P记录：编号|类型(七型之一)|悬念原料|蓄压自章|计划兑现章|利息设计|状态(充能/已兑现/超期)。drift-audit红灯：管道<2条在充/兑现超期未爆/兑现无利息/连续同型。

## 五、与既有体系的缝合

- 场景卡新增必填：**爽点行**——`爽点: 兑现P3(反杀型,利息:散客回流)/充能P5(认可型:丁师傅驻足)`，无爽点行的卡=骨架卡。
- bundle注入新增：管道状态（在充能各条+距兑现章数）——生成时模型知道"这条线该加压还是该爆"。
- 冷读清单加三问（§一爽点仪表）。
- 与"喘息章/温情拍"的调和：喘息章也带**小兑现或先知型微装**（超女夜他"随口"说决赛冠军，全院第二天看他的眼神都不对了——温情与爽不冲突）。

## 六、名场面拆解（调研精华）

- **斗破"莫欺少年穷"**：一句台词三重功能（泄愤宣言+人物立骨+钩子）；"三年之约"=期货机制——打脸不满额兑现，改约期，把一次爽变成三年期待。
- **大奉税银案**：死局+秒解双连击——先让所有人（含读者）确认无解，再解；"破而后立"因果链：爆发不靠运气，靠前文每一步都算数。
- **赘婿岁布战**：低位开局高位碾压——对手不知道他的真实层次，读者知道=信息差爽（与"先知型"同构）；成果型爆发：赢完直接摊结果，不辩论。
- **飞卢vs起点双引擎**：飞卢=每2000字一小爽的直球流；起点=铺垫15-20章的憋大招流。**直球≠无铺垫**——飞卢的"直"是兑现快，不是无蓄压。

## 八、期待链四件套（圈内术语归位）

①看点-爽点循环（看点=预告的爽点，爽点兑现时抛新看点）②连环伏笔（A兑现处埋B）③未完成心理闭环（蔡格尼克效应：人对未完成事件记忆更深——在充能的线就是开着口的闭环）④3-5线并行（本书取2-3条：再多织不住）。

## 十、回调兑付（书主2026-09-12指示：一个爽点高潮不是爽一次就结束）

**总纲：爽点不是事件，是资产。** 首爽兑付后，该P转入**回调池**（不销毁），可通过四式反复兑付：

**回调一式·传播波次**（侧面型装逼的多次化）：同一事实在新圈层发酵——转述走样=幽默+二次爽（"听说一中的学生用牙签就把主板修了"）。台账=ledgers/口碑账.md（谁知道主角的哪些事、传播半径）。
**回调二式·存证兑付**（期货）：事前留证（家书/字条/预言帖/聊天记录），事后翻出=封神时刻。中石油"家书存证"即此式。三年之约=对赌期货。
**回调三式·圈层错位**（信息差喜剧）：两拨互不知情的人相遇，误会叠加；或某圈层压轴才知道（诡秘马甲流：每个角色发现"原来那时候就是他"，旧事件全部重新解读）。
**回调四式·旧敌再遇**（矛盾多波次）：被打脸者不甘→升级挑衅→更大打脸；或其背后大佬出场找回场子——全职高手老东家范式：每次交手都是旧矛盾的复利。

**操作纪律**：①每次大爽兑现时，当场登记回调计划（谁能再次震惊/触发物/最早间隔≥3章）②回调必须升级不复读（新圈层更高/对手更强/解读更神）③回调触发常挂在下一波爽点的高潮段（双响）④观众知情账与主角知情账分开记。

### 回调兑付·机制命名与操作规律（v2,调研定稿,详见story/audit/爽点回调-*.md）

**名作机制**:全职「旧账升息」(矛盾不变,战场/见证规模/对手层级三选一升格)|诡秘「马甲复利」(知情面每扩一圈,旧事件自动升维重定价——回调不是重复是重定价)|大奉「圈层扩音」(高光登记在他人视角的账本上,揭露时按账本逐条回放)|赘婿反例「单点透支」(不升息只复读,第4次掉马惊讶归零——临界点=同一马甲被同一圈层第3次识破且无新信息差/新赌注)。

**触发器四型**:身份揭露/旧案重定价/能力新壳/见证人换血。回调=用新触发器唤醒旧账,不是重讲旧账。

**操作规律五条**:①同一矛盾复兑3-4次为宜,间隔内必有独立小兑付垫场(防光记账不发息) ②信息差三栏账(谁知道/谁不知道/谁以为知道)——二次爽=翻转一个知情栏,**翻转者身份越意外利息越高** ③防模板三板斧:每次复兑至少升一格+允许反向回调(主角也是被回调对象)+代价实付 ④变调复用(同一句话换人说/同一场景地位反转,禁原样复读) ⑤二刷原理=重定价(用终局知识重读早期章节获得第二层爽)。

**回调登记9字段**(口碑账+回调池共用schema):回调ID与首爽事件(章/地点/类型/在场者)|已知人群清单(谁亲见/谁听说/几号走样版本)|传播半径与圈层(已传入/下一目标/各圈版本差异)|存证物(类型/埋设时忽略理由/保管人)|期货到期日|回调触发点(新对手质疑/旧敌回归/新圈层入场/存证意外曝光)|兑付形式(验证/超额/反转)与首爽差异变数|兑付后再传播(新谣言种子/续下一轮)|联动账(动了哪个马甲,知情状态表更新)。
