# AI协作法（本项目实证宪章，v2）

> 本文件回答："怎么让AI真正干好写小说这活"。全部条款来自本项目可复现实验，不是理论。
> v2融合协作机制红队批判(audits/21)。

## 七条实证定律

**定律一：注入胜于指令。**
"要有生活气"叮嘱一百遍不如往上下文里塞一条"包子两块五"。实证：旧书79章只有注入了素材的第1章有生活气；第79章对照实验，注入素材库后生活气盲读1.5→5。
推论：想要什么，就把它的原料放进bundle；只有原料进不了上下文的品质，才靠指令。

**定律二：刻度胜于自觉。**
凡不可数的规则必失守（旧书：无刻度的正向规则100%塌方，有检测的负向规则100%守住）。实证：金额≥2/闲笔≥1入check后，"凑也要凑出生活气"。
推论：任何新要求落地时问一句"它能不能被机器或冷读数出来"。

**定律三：轮换胜于自控。**
AI的一个成功写法会被立刻复读到死（三连短句77/79章）。自觉没用，靠台账+门：章末形态/单元型/装逼七型/笑点责任人全部轮换入账。
推论：每发现一个新指纹，就多一条轮换维度；指纹发现靠冷读的"这章让我想起上一章"。

**定律四：多遍胜于单遍。**
单遍生成时模型必然牺牲不可检测的品质（注意力零和）。实证：最好的一章（旧ch1、新ch79v2）全部是多遍产物；beat-expand/line-polish/de-ai就是血肉遍/声纹遍/去味遍。
推论：结构遍→血肉遍→收束遍是底线工艺，不是可选优化。

**定律五：盲读胜于自评。**
AI自评永远虚高。实证：两次盲读（新旧79章对比、ch1冷读）抓到了全部检查器抓不到的问题（数学穿帮/指代错/AI总结腔）。
推论：每章必冷读，重要章盲评对比；冷读者的"毒舌指数"靠persona差异维持，不靠同一个裁判。

**定律六：门拦下限，不保上限。**
门保证"不是垃圾"，不保证"是名场面"。均匀的7/10是门内最优解，也是最大陷阱（平均数陷阱——待红队确认）。
推论：峰值章需要额外机制（多方案盲选alt-takes/名场面钉桩set-piece），门之外必须有"冲9/10"的通道。

**定律七：AI是"记不住+刹不住"的协作者。**
记不住：感情发生过它忘、人物成长过它忘、梗用过它忘——一切靠台账+机器刻度兜底。刹不住：一个节奏它会推到读者腻为止——一切靠轮换+红灯刹住。
推论：台账纪律（禁无章号记账）和轮换纪律不是官僚主义，是给AI装的外置海马体和刹车片。

## 操作节奏（当前定稿流程）

填卡(含生活层+爽点行) → bundle(11件注入) → 结构遍生成 → 门拦截循环(check+gate) → 冷读(双轨:5章窗口软门+峰章硬门) → 重要章盲评/多方案 → done验收 → 八账盖章 → 卷级漂移审计(每10章)+爽点红线。

## 八条新增定律（v2，来自协作机制红队）

**定律八：注意力是零和的，约束超载=全面装样子。**
一次生成并行~65条约束时，AI的策略是满足可检测的、牺牲不可检测的——字数带打架时它谁的话都不全听。→ **焦点制**：卡声明2-3项本章焦点，bundle置顶，冲突时焦点获胜；卡字数带=唯一权威。

**定律九：注入物会被照抄，所以要有泄漏门。**
连人肉精修的招牌章都照抄了范例段原句（实锤）。素材库越大，抄得越欢。→ 泄漏门：正文与注入包成句重叠≥10字=FAIL；素材"变形后入文"（数字可留，表述必重造）。

**定律十：存在性检查会被"便宜按钮"攻破。**
塞一个孤立数字可同时满足金额与闲笔两项检查。→ 检查要查结构证据（同段两金额共现=算账；闲笔须含对白=人物腔），剩余的交给冷读。

**定律十一：任何协议都会变成新指纹。**
慢拍三微拍/震惊四层一旦"每章必做"，就成了下一代的"三连短句"。→ 配额协议必须带轮换窗（慢拍每2-3章≤1次；小兑现只准震惊前两层），轮换账统一记在钩分布账尾。

**定律十二：门保下限，不保上限——要显式冲峰。**
均匀的7/10是门内最优解，也是最大陷阱。→ 章级字段：峰章（卷纲标记）解锁字数上限5200+alt-takes多方案盲选必走+done --strict；30章窗内冷读分无≥8=drift红灯。

**定律十三：数据不预警就一定爆。**
素材库90条≈30章耗尽；伏笔裁剪会静默丢数据。→ status常显"素材余量/预计耗尽章"，<30条红灯触发扩容义务。

**定律十四：门会缺齿运行。**
check里42项有3项的人名表还是旧书角色——看起来在查，实际空转。→ 一切书内实体（人名/声纹禁词）必须从声纹表派生，禁止硬编码；缺齿=虚假安全感。

**定律十五：单裁判单锚会漂移。**
每次冷读换人，标准随情绪走。→ 双锚常备（白金锚=天花板，自家范例段=及格线）+固定参考章月度复评，移动>2即重校。

## 一句话总纲

**给AI的每一样东西都要过三问：它进得了生成现场吗（注入）？它数得出来吗（刻度）？它会不会被复读成指纹（轮换）？——三问全过才上线，缺一问就等着在冷读里再见。**
