# 人物圣经模板 v2（活文档·三层生命周期）

> 使用: 构思阶段(book_design phase_3)必须完整填写恒定层+初始化演进层。之后按 docs/活文档协议.md 演进。
> 缺任何引擎字段 = system_readiness 亮红"先修再产"。欲望必须私人化(职业义务不算欲望,premise-fit第六维)。

## 一、恒定层（立项锁定,重大转折才改,变更须commit注明）

### 主角引擎（五字段缺一不可）
- **Ghost(过去之鬼)**: 主角身上发生过什么没有愈合的事?(具体事件,不是"童年不幸")
- **Wound(正在流血的伤)**: 这件事此刻还在怎么疼?谁看得到?谁不知道?
- **Lie(信的谎)**: 因Ghost而相信的错误结论(如"只要X就Y")
- **Want(表层欲望)**: 私人的、迫切的、可输赢的目标——**必须能回答"得不到会失去什么"**
- **Need(深层需要)**: 表层欲望下面的真相;Want与Need必须同轴(每追Want一步,离Need的答案近一步且代价+1)

### 欲望引擎四件套(教训:背景板用法三回合耗尽)
1. **被冤/被负者活着吗?**(愧疚/仇恨要活的、会走动的)
2. **卷宗/真相缺的那一页**在谁手里?(悬置真敌人,每卷可漏一片)
3. **第一案与主线如何焊接**?(前三章内,不许"结完案才想起爹")
4. **披露排期**: 主角背景/创伤的各层,分别在哪些章被谁发现?(登记于演进层)

### 对手引擎(每对手一份)
- 与主角欲望的**直接冲突点**(抢同一样东西,而非只是看不惯)
- 自洽逻辑(他为什么不认为自己错——写不出这条就是脸谱)
- **威胁兑现表**: 能拿走主角的什么(具体到:转正/自由/某人在乎的人);每3章实际兑现一次(态度冷遇不算)
- 弧光终点(最终对峙时读者应该为什么而犹豫)

### 关系不可逆移动表
| 关系 | 起点 | 每卷移动 | 终点(读者为何犹豫) |
