## 2. 收割正则根因分析(线索1答案: 为什么放过了占位行)

旧代码三处缺陷叠加:

```python
# 旧harvest核心(已废)
if re.match(r"-\s*(最强段落摘录|生活气摘录)", line.strip()):
    seg = re.split(r"[:：]\s*", line.strip(), maxsplit=1)[-1] if ": " in line or "：" in line else ""
    seg = re.split(r"\)\s*[:：]\s*", line.strip())[-1]   # ← 事故根因
    if seg and "（填）" not in seg:
        entries.append(...)
```

1. **全角括号失配**: 第二行 `\)` 只配半角右括号。031/032栏头是全角`）：`→正则不中→`re.split`不中时**原样返回整行**→`[-1]`取到整个占位栏头。
2. **占位词表太窄**: 只拦"（填）"。冷读001/003的占位是"待agent"变体, 畅通无阻。
3. **泛关键词引文窗口**: 第二收割路径对全文任意`“…”`引文, 只要前40字符内出现"最强/白金/手感/最好"就收——白金锚对照行(`与白金锚"每段有一件具体的事在发生"同手感`)和读者提问(`读者心里憋着的问题说得出——"美凤那半句…"`)双双中招。判词和问题成了"范例"。
4. (附)正文摘录无溯源: 沙箱验证书的3条摘录(皮鞋段/十五天段/掏烟段)**在其正文里根本不存在**(评者转写走样或正文后改)——旧机制无任何"摘录必须在正文命中"的验证。

## 6. 范例段库架构评审(问题4答案)

3. **双源未去重**: 槽4(风格包.md静态范例段, 永不轮换)与槽0(飞轮库, 每卷更新)职责重叠——建议明确分工: 风格包范例段=立项锚样本(冻结), 飞轮=滚动最佳, bundle注入时按文本去重(本次已消除030龙四海双注, 但机制上仍可能复发)。
