# 红队研究总合成：11路调研 × 现有系统差距清单

> 研究来源：红队A(开篇)/D(节奏压力)/E(叙事声音)/G(世界观释放)/I(情感线)五代理 + B(AI痛点)/C(对话)/F(人物)/H(长篇)/J(读者商业)主循环自查。
> 本文档是系统优化的施工图：每条差距标注【改哪里】【怎么改】。

## 一、开篇系统差距（opening-arc）→ 研究来源A

| 现状 | 研究结论 | 改法 |
|---|---|---|
| 无"死局"概念 | 第一章必须有死局（带期限的不可回避危机），9种类型学 | 契约书加"死局"必填项+九型选型 |
| 无三落差结构 | 斗破式"三次抬高-摔落"=势能即追读欲 | 第1章微卡加落差设计 |
| 专名预算≤7 | 红队G：首章专名≤5、单章新设定≤2 | 收紧预算 |
| 无"两段内刺激性对话" | 开篇两段内必须出现刺激性对话 | 反模板检查加条 |
| 无慢热准入判断 | 慢热四条件缺一不可，新人默认快 | 加准入闸门 |
| 无一变一恒 | 局势每章变，主角元逻辑恒定 | 契约书加"元逻辑"项 |
| 无目标压低原则 | 大奉目标压到"自保+当富家翁"——小而具体才可信 | 契约书目标项加压低要求 |
| 无衔接度警告 | 阅文官方：黄金三章与后续"衔接度"比炸裂度更决定生死 | 闸门加检查 |
| 无首付律细化 | 三章内金手指亮相+至少一次小额兑付 | 已有雏形，强化措辞 |
| 无副线小钩 | 微悬念埋在闲笔（称呼变化等零成本细节） | 微卡加项 |

## 二、节奏系统差距（pacing-score）→ 研究来源D

| 现状 | 研究结论 | 改法 |
|---|---|---|
| 无字数级密度 | 每500-800字一个情绪波动点；1500字无起伏=流失红线 | 加微观密度节 |
| 无情绪高峰频率 | top10%追读=每1.8-2章一次高峰（bottom10%=4.7章） | 加硬指标 |
| 爽点分级不全 | 小(每章)/中(3-5章)/大(10章-每卷)/重大转折(20章) | 补四级体系 |
| 无虐爽比 | 压抑20-30%：爽70-80%；删1/3爽点集中释放→追读35%→67% | 加配比+反直觉数据 |
| 无两级倒计时 | 长期30万字+绑主线/每卷中部短期倒计时指向卷末；**每章推进时间线** | 加倒计时节 |
| 无期待线管理 | 同时3-5条期待线，每章至少一条活跃，单线静止≤3章 | 加检查项 |
| 钩子规则不全 | 10类型轮换，连续两章不重样，1强2缓；上章钩子本章前30%回收一半 | 强化3节 |
| 无伏笔回收期限 | 小10章/中30章/大100章，回收前定期新线索 | 加期限表 |
| 无兑现纪律 | 等越久兑越干脆（云岚宗样本）；拖延注水=口碑杀手；爽完立刻接新悬念 | 加纪律 |
| 波浪式不明 | 小不爽→小爽→…→大不爽→大爽；两章升温一章降温 | 明确公式 |

## 三、叙事声音差距（风格包/de-ai）→ 研究来源E

| 现状 | 研究结论 | 改法 |
|---|---|---|
| de-ai无第九类 | 隐形摄影机（叙述者零态度）是AI第九类硬特征 | de-ai加类 |
| 情绪标注规则打架 | de-ai禁情绪标注 vs v4许情绪标签——需显式辨析：**禁叙述层空转贴标("他感到愤怒")，许对话标签层高效属性词("不耐烦地摆手")** | 两文档都加辨析注 |
| 无"我"化判定法 | 叙述句主语换"我"仍成立=叙述者已在人物腔 | 风格包加判定法 |
| 感叹号无温差规则 | 感叹号集中对话与峰值，叙述段保持句号——冷叙述+热对白密度差=喜剧感 | 风格包强化 |
| 理论注脚缺 | 屏面语(表声表形)/次生口语/自由直接思想三个学术概念 | 风格包依据栏 |
| 转换规则表缺 | 14条文学腔→网文腔转换规则（含例句） | 风格包v6 |

## 四、对话系统差距（dialogue-doctor）→ 研究来源C

| 现状 | 研究结论 | 改法 |
|---|---|---|
| 无意图标注 | 蓝图标注双方试探目的与隐藏（"都在演戏"→对话自带张力） | 加对话意图层 |
| 无群戏上限 | 超过5人对话AI会乱，拆2-3人一组 | 加上限 |
| 织毛衣已有 | 每3-5句台词+1段动作/心理描写（与研究一致，验证通过） | 不改 |
| 无打断抢话 | 删减法：砍过渡词/互相打断/省略号没说完的话 | 修订处方加条 |
| 无潜台词总则 | "角色不会直接表达真实想法"一句话修复 | 加铁律 |

## 五、情感线差距（romance-line）→ 研究来源I

| 现状 | 研究结论 | 改法 |
|---|---|---|
| 无名字替换测试 | 心动段落换另一对CP依然成立→打回 | 加验收硬线 |
| 禁喻清单不全 | 月光/星辰/心跳加速/脸红/手心出汗/"心里某处柔软"；只许动作/物证/沉默 | 补全清单 |
| 无虐点分级 | 内因虐(性格立场必然)>外力虐(误会巧合) | 加分级 |
| 无回应时机 | 一方最需要的时刻另一方出现（雪中送炭非锦上添花） | 加法则 |
| 无反向给予节点 | 非双强结构必须登记"她救他的时刻" | 加规则 |
| AI四件套 | 状态注入(进度锚+物证清单)+禁喻+潜台词+一次一细节 | 加AI专项节 |

## 六、人物系统差距（char-bible）→ 研究来源F

| 现状 | 研究结论 | 改法 |
|---|---|---|
| 弧光类型不全 | 三类型：正向/负向/**平面弧光**(坚定者改变世界——网文主角常用) | 补类型 |
| 无翻转法 | 缺点变优点或反之，关键时刻意料之外的决定 | 加技法 |
| 反差点不显 | 欲望与软肋的反差=活人感核心（AI人物走直线的解药） | 强化 |

## 七、世界观系统差距（iceberg-budget/world-rules）→ 研究来源G

| 现状 | 研究结论 | 改法 |
|---|---|---|
| 无量化锚点 | 单场景新设定≤1/单章≤2/首章专名≤5/首卷示区≤7 | iceberg加锚点 |
| 无设定挂麻烦律 | 设定永远以"对主角当下不利/有用之物"进场，从不以"背景知识"进场 | world-rules加律 |
| 七种进场模式缺 | 测评判决/体感谜团/死局倒计时/底层爬升/日常入侵/解说合法性/经济压强 | iceberg加模式选型 |
| 无不可靠转述 | 设定由有立场的角色带着目的说 | world-rules加 |
| "如你所知"未禁 | 信息倾倒的对话化伪装 | check.py加检测 |

## 八、长篇防崩差距（pipeline/ops）→ 研究来源B/H

| 现状 | 研究结论 | 改法 |
|---|---|---|
| drift-audit已有(每10章) | 不做上下文管理时设定矛盾密集出现在20-40万字区间——验证了机制必要性 | 保持 |
| 无可见性管理 | 每条设定可设"从第几卷开始公开" | iceberg-budget加可见性字段 |
| 无装配两档 | 日常章注入"仅名称"，关键章"完整+最近N章" | pipeline注入协议 |
| 无结尾整齐检测 | AI结局过于 tidy——剥除谜团，爽完必须留新钩 | check.py+章末检查 |
| 无重复检测 | 长程短语重复是平台检测AI八维度之一 | drift-audit加 |

## 九、check.py 差距（工具层）

1. **死代码**：378行return后残留speaker_sents等不可达代码（旧bug回归）→清除
2. 新增检查：
   - 首章/任意章专名密度（首章>5 FAIL）
   - "如你所知/众所周知你应该知道"式设定伪装对话（FAIL）
   - 章末钩子存在性（末三行含悬念信号词/问句/动作中断）
   - 感叹号温差（叙述段感叹号占比过高=失去温差）
   - 心理裸写密度（无引号心理句）
   - 对话节奏违例（连续>5轮无动作心理——已有类似，对齐3-5句标准）
   - 死喻检测（心动场景月光/星辰/心跳加速/脸红）
   - 结尾圆满检测（章末"安全回家/真相大白/误会全消"信号）
   - 首句长度（>25字 WARN——研究说≤10字碎片式）

## 十、冷读标准差距（reader-proxy）

- 冷读必须**对照白金原文样本**打分（大奉/斗破/诡秘开篇节选作锚），不自创标准
- 六项量规加"网文味"项：主语"我"化测试/情绪标签直给/屏面语格式
