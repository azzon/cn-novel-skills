# 白金锚样本（冷读开篇章对照用）

> 用法: 开篇章/卷首末/高潮章冷读时,令代理**先读本文件特征要点,再读被测章**,回答:
> ①同屏混排测试——本章任意三段与锚特征描述的白金段并排,像不像真人白金作家写的?
> ②若代理连劣锚(story/audit/劣锚样张.md)都打高分,本轮结论弃用(裁判失真)。
> 每卷可由 style-compiler 增补当卷锚特征;版权原因存技法拆解不存大段原文。

## 一、白金开篇节奏特征(大奉/斗破/诡秘第1章技法拆解)

1. **第一段就出事**: 白金开篇没有一段"环境铺垫"。第一段必有异常/冲突/悬念在跑(诡秘: 直接在密室醒来面对血字;斗破: 退婚当口)。
2. **信息投放 ≤3/屏**: 每一屏(约300字)最多交代3条新信息,且每条都挂在冲突上,不挂在旁白上。
3. **金手指 ≤500字亮相,且带代价**: 能力出现必伴随限制/代价/副作用,没有"白得"。
4. **第一个爽点 ≤1500字,兑现要有人看见**: 主角能力展示必须有在场的旁观者反应——世界因他更新。无人收货的爽点=白爽。
5. **章末钩=具体事件,不是氛围**: "门外响起了脚步声" > "夜色渐深,他知道这一切才刚刚开始"。

## 二、白金对白锚特征(一人一声)

1. 对白占比 40-55%;每2-3轮台词插一段动作/环境/内心(织毛衣),无连续6轮以上纯对话。
2. 遮名可辨: 遮住名字,凭句式/词汇/废话习惯能猜出说话人(老油条说半句留半句;莽人句短带语气词;书生主谓完整)。
3. 对白推进冲突或暴露性格,二占其一;纯信息播报对白(两个都知道的人互讲已知事)=零容忍。
4. 真人对白是"漏"的: 有废话/碎片/答非所问;打磨成金句的对白群=AI腔。

## 三、刑侦类专用锚(法医秦见微适用)

1. **专业细节带人物**: 法医动作描写必须同时是性格描写(擦器械两遍=克制人设);纯术语罗列=说明书。
2. **案件即倒计时**: 尸体/证据自带保质期,破案压力从物理事实里长出来,不靠旁白喊"时间不多了"。
3. **体制内摩擦写法**: 上级压制不写正面冲突,写流程卡人(挂案/不给卷宗/调岗威胁)——权力的真实形状。
4. **推理链可见**: 结论前读者手里必须齐备线索(公平性),侦探的推导每步挂证据。

## 四、混排测试执行口径

- 抽被测章 3 段(开头/中部/章末)与上述特征逐一比对打分;
- **锚定通过** = 代理能具体说出"这章哪一段最接近白金手感、差在哪一维";
- 代理只会说"文笔流畅/节奏不错"类空评 = 未读锚,重跑。
