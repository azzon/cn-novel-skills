# 白金锚样本（冷读对照用）

> 用途：reader-proxy冷读时与本章混排对比——"像不像同一个人写的"。
> 来源：红队A/D/E研究中的原文引证。冷读代理先读锚再读本章。

## 《大奉打更人》第一章（开篇·死局倒计时式）

> 警校毕业的许七安幽幽醒来，发现自己身处牢狱之中，三日后流放边陲。（情境概括）

税银案（叙述者跳进人物腔·自由直接思想）：

```
老子特么本来就没钱，你还给我掉链子，气死偶咧。
```

（注：第三人称叙述中，不加引号、不加"他想"、人称不调——叙述声音混入人物的词库）

交织模板（动作/对白/心理裸写轮转）：

```
许新年顿住，沉默的看着他。

"你能弄到卷宗吗？税银丢失案的卷宗。"

许新年皱了皱眉："你要这个干嘛。"

我要破案....许七安沉声道："……"
```

幽默消解沉重信息：

```
"众所周知，父母双亡的人都不简单。"
```

（一句话同时完成背景交代+调性确立+套路自嘲）

严肃场景内心跑偏：

```
啪！许七安给了自己一巴掌。
重新推理！
```

## 《斗破苍穹》第一章（开篇·三落差·只压不爆）

> 结构：测验受挫580字→路人嘲讽199字→族人势利226字→萧媚变化892字→薰儿1235字——5个团块全是"当众羞辱"堆叠，第一章只压不爆。

第一句（事件碎片）：

```
斗之力，三段！
```

（测验魔石碑显示的报数——≤6字，不递画面）

长期倒计时原型：

```
"三十年河东，三十年河西，莫欺少年穷！"
```

（退婚→仇恨转化为明确小目标+时间期限=三年之约，全书长期倒计时）

## 《诡秘之主》第一章（开篇·体感谜团式·表声）

开篇五字（表声：文字在"喊"）：

```
痛！
好痛！
```

（单句成段=重音；感叹号=重音标记）

## 共性清单（冷读时逐项对照）

1. 首句≤10字，事件碎片不递画面
2. 第一章有带期限的死局（三日后流放/三年之约）
3. 心理裸写不进引号，叙述者随时跳进人物腔
4. 对话独立成段，绝不与叙述混排
5. 情绪放大且直给（"啪！"给自己一巴掌；痛！好痛！）
6. 严肃场景允许内心跑偏（喜剧引擎）
7. 每句话给信息/给情绪/留钩子三选一
8. 信息全部从行动/对话/称呼变化里漏出，禁设定旁白
