# 时代记忆调研：电视剧综艺春晚（2026-09-12，14路时代调研之一）

调研完成。以下为核实结果(全部经维基百科/央视网/中新网交叉确认，个别搜索限流处以百科页面为准)：

## 2005-2010 电视剧·综艺·春晚记忆表(重生文素材)

| 年月 | 作品 | 破防点 | 主角用法 |
|---|---|---|---|
| 2005-02 | 家有儿女 | 重组家庭情景喜剧首播(北京台2005-02-12),刘星金句刷屏，重播王(江西收视22.7%) | 全家围炉温情场；“刘星式贫嘴”=主角自嘲人格 |
| 2005-09-12 | 亮剑 | 央视一套黄金档，首周均收11.42%/最高13.7%,年度央视冠军，后重播超3000次；“狭路相逢勇者胜” | 陪爸看李云龙的父子场；主角酒桌“背”台词镇场 |
| 2005-09-23 | 神话(电影) | 成龙金喜善，《美丽的神话》满街传唱；剧版2010年胡歌再爆CCTV-8 | 影院蹭热点；顺手“预言”会拍剧版，2010应验=神预测素材 |
| 2005春晚 | 千手观音 | 21位聋哑演员邰丽华领舞，歌舞类一等奖+特别大奖，全民屏息3分钟 | 全民记忆锚点：除夕全家不换台；多年后一句“当年千手观音”即破防 |
| 2006春晚 | 说事儿 | 白云黑土续集+《月子》，“你太有才了”“那是相当的”成年度流行语 | 春晚段子次日全班复读；主角用“你太有才了”混脸熟 |
| 2006-01-02 | 武林外传 | 央视八套最高收9.49%、豆瓣9.6;“额滴神啊”/葵花点穴手/排山倒海/“子曾经曰过”全员金句 | 宿舍全家笑场人人接梗；主角与暗恋对象对台词的名场面 |
| 2006-02 | 易中天品三国 | 百家讲坛爆红起点，“学术超男”；栏目入选2006十大新闻事件 | 劝家人囤书=出版风口；长辈饭桌谈资 |
| 2006-10-01 | 于丹《论语》心得 | 国庆7天连讲一夜爆红，书销300万+ | 预测会爆：“国庆看于丹”，家人惊为天人；书成送礼硬通货 |
| 2006-03 | 快乐大本营(翻红) | 05改版+PK赛，“快乐家族”五人主持群成型(大陆首个)，2009全国收视最高娱乐节目 | 周五晚仪式感；主角预言“这五人能火很多年” |
| 2006-12-24 | 士兵突击 | 西安台首播、2007年CCTV-8爆红，白玉兰最佳剧；“不抛弃不放弃”汶川后成全民口号 | 主角与父亲的和解场：许三多=笨小孩逆袭，父亲看哭 |
| 2007-05-16 | 奋斗 | 北京收视第一(均6.3%/结局7.71%),80后青春剧里程碑，“今天你奋斗了吗” | 大学宿舍集体追剧；陆涛迷茫=主角心境镜像；米莱语录撩人 |
| 2009-04-01 | 潜伏 | 四卫视上星，北京卫视均8.01%/结局14%创台纪录，白玉兰最佳；余则成翠平假戏真做 | 全民谍战热：办公室自嘲“余则成”；与同事赌结局 |
| 2009-11 | 蜗居 | 地方台7-8月先播、11月上星引爆全国；房奴账本台词扎心，海清“演完痛恨房价”，因争议一度停播重剪 | 时代痛点：长辈饭桌叹“房子啊”；主角预知房价走势，欲言又止的沉默戏 |
| 2009春晚 | 不差钱 | 小沈阳一夜顶流，“这个真没有”“眼睛一闭一睁”，观众票选小品一等奖 | 全民模仿周：开学第一句“为什么呢”；“这个真没有”打太极 |

**时间线防穿帮备注**：神话2005=电影(剧版2010-01);士兵突击爆红滞后到2007;蜗居先地方台后上星；快乐大本营是2005改版→2006快乐家族→2009巅峰的渐进翻红，不是一夜翻红。
