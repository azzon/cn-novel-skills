# 系统重设计方案 v2.0（基于32份审计+3份专项研究的终极整合）

> 2026-09-12。基于45章正文、32份审计报告、3份专项研究（金庸叙事技法/角色差异化/网文爽点设计2026）的全部发现。

## 一、根因诊断（五个层级）

| 层级 | 问题 | 根因 | 现有门能否修 |
|---|---|---|---|
| L1 文字 | 每人说话都装、金句排班、段尾判词 | LLM默认"聚"不"漏"；金句配额制 | ✅ 已修#44/48-50 |
| L2 场景 | 概述代替画面、峰后必释、章太短 | 生成目标字数太低；无场景深度门 | ✅ 已修G1提升+#51 |
| L3 结构 | 赢得太顺、零失败、全员支持主角 | 大纲层面无真敌、无真代价 | ⚠ 需大纲重设计 |
| L4 角色 | 千人一面、认知同源、主角不可见 | LLM单声源+RLHF助手腔 | ⚠ 需声口卡+聪明预算 |
| L5 爽感 | 爽点密度不足、兑付不诚实、铺垫不足 | 爽点管道失管+悬置不足 | ⚠ 需爽点设计重做 |

**结论：L1和L2已有机器门兜底。L3/L4/L5需要系统重设计。**

## 二、三份研究的核心发现

### 金庸叙事技法
- **赢法轮换**：光明顶六场六型（智取/拖平/以医服人/点到为止/受剑不败/认亲不战），绝无同款
- **代价实付**：聚贤庄乔峰武力完胜，付出"名字的死亡"，代价带复利
- **名场面的检验标准**："赢完之后，主角的世界哪里回不去了"
- **铺垫=两本账**：能力账（主角怎么变强）+绝境账（局势怎么恶化）

### 角色差异化系统
- **差异化=独特的"够不着"**：词汇够不着/认知够不着/信息够不着/表达够不着
- **病因**：LLM单声源+RLHF助手腔+金句配额制
- **四步解法**：一降（聪明预算分级）、二漏（废话率≥30%）、三换目的（表达→应付）、四立禁区（每人登记绝不说的词）

### 网文爽点设计2026
- **爽=悬置期待被确认的瞬间**。铺垫是本钱，兑付是利息
- **压抑占20-30%是红线**。围观者反应是放大器
- **2026核心竞争力=复合情绪价值+人味**
- **AI泛滥后，"对白说人话、细节有体温"成了稀缺资产**

## 三、系统重设计（六个模块）

### 模块1：场景卡重设计（L3结构修复）

**旧模板问题**：场景卡定义"发生什么事"（事件+数字），不定义"谁受伤了"。

**新模板核心字段**：
```
- 情感目标: 读完这章读者应该感到什么？（不是"知道什么"）
- 冲突源: 谁/什么在阻止主角？（必须有具体的人和具体的阻力）
- 代价: 主角这章付出了什么？（钱/时间/尊严/关系/信息——必须有）
- 赢法类型: 六选一（智取/硬碰/借力/忍让/退让/认亲——不重复前两章的赢法）
- 峰值场景: 本章情感最强烈的那一拍是什么？（一个画面，不是一句总结）
- 峰后动作: 峰值后紧接的动作/物件/沉默（禁解释）
- 开场型: 对话直入/动作直入/异常直入/判断句
```

### 模块2：角色声口卡（L4角色修复）

基于角色差异化研究，为8个主要角色各建一张声口卡：

每张卡包含：
- 聪明等级（A=仅主角/B=限领域/C=普通/D=偶尔聪明）
- 知识域（只聊自己懂的话题）
- 3个口头禅（不是格言，是口头禅）
- 3个禁词（这个角色绝对不会说的词）
- 碎片习惯（怎么把话说断）
- 废话主题（不聊正事时聊什么）
- 说话目的（大多数时候在干什么——应付/推脱/抱怨/炫耀/关心）

### 模块3：爽点管道升级（L5爽感修复）

**新规则**：
1. 每章至少1个小爽点，每3-5章1个大爽点
2. 大爽点前必须≥2章蓄压（压抑占20-30%是红线）
3. 赢法轮换：连续两章不能用同一种赢法
4. 每次赢必须付出看得见的代价
5. 围观者反应是放大器：每个大爽点必须有至少一个旁观者反应
6. 成功后24小时内开新麻烦（不能让主角安逸超过一章）

### 模块4：对白声口执行（L1文字保障）

已有dialogue-voice技能+机器门#48-50。追加：
1. 聪明预算分级：A级（主角）每章≤2句聪明话；B级（罗胖子/苏棠/丁师傅）每章≤1句；C级（其他所有人）每章0句
2. 废话率≥30%：每段对话至少三成是不推进剧情的废话
3. 每场最多一人说漂亮话
4. 遮名测试是验收硬线

### 模块5：峰后禁释令执行（L2场景保障）

已有#52机器门。追加生成端规则：
1. 情感峰值段落（哭/怒/喜/疼/暖）后，下一段必须是：动作/物件/沉默/环境
2. 禁一切叙述者解释
3. 峰值段落本身必须有身体反应（不是心理活动，是身体反应：手抖/喉咙堵/后背出汗）
4. 身体反应占情感位的40-60%（当前13%）

### 模块6：长跑基础设施（持续性保障）

1. evals回归闸已在pre-commit中
2. structure_check.py监控结构同构
3. 漂移审计每10章强制
4. 风格包范例段每10章更新一次（从近期最佳章节提取）
5. 当前时刻卡每次done时强制更新

## 六、核心原则（不可妥协）

1. **每章至少一个真失败或真代价**
2. **每章至少一个有名字的对手在正面阻拦**
3. **连续两章不能用同一种赢法**
4. **情感峰值后禁解释，用动作/物件收**
5. **大多数角色说话是为了应付，不是为了表达**
6. **配角警句同章合计≤1枚**
7. **每章≥3个带数字的金额，且金额参与情绪运算**
8. **遮名测试是验收硬线**
