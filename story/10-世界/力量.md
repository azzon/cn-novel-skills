# 10-世界/力量

## 回响等级（以温度量化）

| 档 | 温度范围 | 特征 | 战力锚 |
|---|---|---|---|
| 空白回响 | 环境同温 | 只剩情绪轮廓，无人格细节，如"焦虑""等待" | 无害，但影响周围人情绪 |
| 低阶回响 | +1~3°C | 保留部分记忆碎片，重复具体动作 | 微弱影响物质世界（移动小物件） |
| 中阶回响 | +4~10°C | 保留生前大部分记忆，有模糊意识 | 能短暂降低局部温度、在镜中显形 |
| 高阶回响 | +11~30°C | 保留完整记忆，有原始意识但无自我认知 | 能短暂具现（3秒），移动较大物体 |
| 完整回响 | 37.2°C | 完整意识+完整人格+自我认知，能对话 | 能持续存在不衰变，可与人交流 |
| 合成回响 | 不稳定 | 多个回响强制融合的怪物 | 极度危险，多重人格互相冲突 |

## 修行者体系

### 送行者（主角所属）
能听见回响、与之对话、帮其了结后送走。每送走一个继承碎片。

- **Lv.1 感知者**：能看见回响轮廓，感知温度
- **Lv.2 倾听者**：能听见回响的重复内容，进入回响记忆
- **Lv.3 对话者**：能与回响双向交流，帮其了结
- **Lv.4 送行者**：能送走已了结的回响，继承碎片
- **Lv.5 归还者**：能将继承的碎片还回回响（理论存在，主角终卷达成）

### 收集者（镜像反派所属）
能捕获回响、囚禁于体内、调用回响能力。

- 与送行者是同一体质的不同用法
- 收集者体内可有上百个回响
- 代价：人格被稀释，最终"自己"消失
- 战斗方式：切换不同回响的人格和技能

### 驯响师（官方体制）
政府认证的回响管理者，负责回响登记、危险回响封印。

- 使用工具（回响容器、温度计、隔离阵）
- 不能与回响对话，只能管理
- 是 bureaucratic 体系，有流程和规定

### 猎响者（黑市）
非法捕获和交易回响的猎人。

- 使用陷阱和诱饵（死者的执念物品）
- 黑市的主要供货商
- 是单元案件的主要对手

## 主角进度表（十卷）

| 卷 | 能力阶段 | 本卷战力戏 |
|---|---|---|
| 一 | 感知者→倾听者 | 第一次进入回响记忆；继承左撇子 |
| 二 | 倾听者（稳固） | 能主动进入回响记忆查案；继承更多碎片 |
| 三 | 倾听者→对话者 | 第一次与回响双向对话；遇到37.2°C |
| 四 | 对话者（稳固） | 能帮回响了结；开始系统继承 |
| 五 | 对话者→送行者 | 第一次送走回响；发现"去了哪里"的线索 |
| 六 | 送行者（稳固） | 系统送走；自我消亡加速；身世揭示 |
| 七 | 送行者（深化） | 发现吞噬者的存在；开始抵抗 |
| 八 | 送行者→归还者 | 学会归还；面对镜像反派的最终战 |
| 九 | 归还者 | 归还所有碎片；接近"空白"状态 |
| 十 | 空白→新生 | 在空白中找到最初的自己；终极选择 |

## 防崩规则

- 送行者不能捕获回响（能力方向不同）
- 收集者不能送走回响（放了就收不回来）
- 37.2°C回响无法被强制吞噬（有意识，会抵抗）
- 合成回响极不稳定，随时可能暴走
- 亲和体的继承不可逆（除非达到归还者级别）
