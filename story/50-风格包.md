# 50-风格包 v1：《重生2005》（白金DNA+生活气DNA继承版）

## 一句话总结
冷面毒舌的说书人讲一个先知维修工的搞钱日常——手艺可视化，钱都落数字，人物全带毛边。

## 十五条写作法则（承自v7，全文继承）
第一句≤10字事件碎片｜每段1-2句｜对话独立成段不混排｜标签四种位置轮换｜单句成段=重音｜心理裸写不进引号｜避免一问一答直答｜叙述者随时跳人物腔｜情绪外露且放大（文学写克制，网文写过载）｜严肃场景内心跑偏｜三字短语连用给韵律｜每句话给信息/给情绪/留钩子｜警句每场景至多一句｜松段配额：至少一段只干活不抖机灵｜摘要句压缩仅限过渡且≤30字。

## 感叹号温差律
感叹号只给对话热峰值（吆喝/砍价/吵架/大笑），叙述段句号收尾冷面。全章零感叹号=全冷报警。

## 生活气DNA（十六条~二十三条，全文承自v7——本书执行更严）
闲笔配额律：每章≥1处≥60字离题（年代吐槽/行当八卦/家事），须人物腔。
多通道感官律：≥3通道/章；**本行加码：修机场景五感默认全套（松香味/金属凉/汗/放大镜下的绿漆/键盘声）**。
物价在场律：**本书是搞钱文，加码为每章≥3个金额，全部参与运算或选择**；生存账（柜台租金/家庭开销/学费）每卷续记。
秒级减速律：家庭情感拍（父对视/钱摆桌上）减速到三微拍。
口语密度律：每章行话≥2个（素材库F区）；砍价戏必用还价规矩（一次买意/两次诚心/三次探价）。
声纹出场律：见story/20-人物/声纹表.md配额。
章长硬线：2400-2800/章，<1800禁入库。
禁预告拆台：潜台词不解说。

## 本书专属装置（对标1984川菜馆/重生08一手正文拆解, story/audit/对标正文拆解-2026-09-12.md）
- **每章一账**（1984签名装置,读者能背资产负债表）:章末一条小账(收入/支出/余额,精确到毛),但**形态轮换**——明账/心里账/妹妹替记/陈会计的正式账/母亲的绢包,禁连续两章同形态;它是马小丁的人物习惯,不是叙述腔。
- **短段落节奏**（重生08实测:段均20-25字,短段40%+）:段均≤30字,长段(>60字)≤3段/章。
- **时代倒计时**（免费端装置移植）:"距超女决赛还有X天/距年关还有X天"式的时代事件钟,每3-5章一响,先知感自带紧迫。
- **对手四拍贬值**（1984王老五范式）:反派不一次写死——轻视→怀疑→恐慌→认命,四拍分布在不同兑现点。
- **路人反应带价格换算**:围观者永远用自己的账本理解奇迹("这一天挣的顶我一个月?"——1984范式)。
- **先知路线图早亮**（重回2005范式）:卷一内亮一次三行路线图(2006山寨/2007房/2009 3G)然后烧掉——读者带着地图追全程。

## 本书专属铁律
- **年代铁律**：禁出现2005年不存在的事物（查素材库G区锚）。
- **钱的三种价**：拿货价/同行价/散客价——每次交易先说清用的哪种价。
- **先知不外露**：主角的先知只用于选择，每次都要给一个当下人能接受的表面理由（"我猜的"/"看行情"），禁对任何人说"我记得未来"。

## 词表
网文腔：齐活/砸手里/水深/接盘/走量/吃差价/活儿（赃物）/板机/炸弹机/充新/鬼秤。
年代词：下线/买断/下海/大哥大（已成古董）/BP机（已死）/小灵通/网管/包夜。
禁词（文学腔）：命运的齿轮/空气凝固/嘴角勾起/瞳孔骤缩/不由得/仿佛生命的。

## 风格卡（声音档案·注入用）
- **叙述者**：冷面毒舌说书人，站马小丁这边，是他的损友；句号冷收，感叹号只借给热闹。
- **马小丁**：短句，报价腔（先说数再说理），手艺人的轴；内心裸写全是算账和估价；绝不抒情绝不喊口号；幽默是干的（"手机膜比人膜贵"）。
- **马建军（父）**：极短句，沉默顿挫；话都拐着弯说关心（"吃饭了"=全部）；提到厂里必用过去式。
- **崔兰（母）**：市井絮叨带笑，账算得比谁都清；对外五毛也要收，对内零头全抹。
- **苏棠**：中长句快节奏，砍价三句夸一刀血；爽利不矫情；生气也讲逻辑。
- **曹三**：油滑长句阴阳怪气，"水深呐小兄弟"；说真话时反而最短。
- **罗胖子**：慢拖腔，官腔混江湖腔，重要的话都在象棋桌上说。

## 范例段（自写·校准锚——大审计-28后更新: ch30/37/39最佳段）

**范例A: 家庭情感拍（出处ch30·示范"不煽情的峰章"）**
```
回家。晚饭后，马建军把帆布包打开，旧毛巾一层一层解开，露出存折，拍在桌上。

"两万零八。"马建军说，"买断的钱，死期下个月到期。到期以后，给你入股。"

马小丁捧着那个存折，红皮的，边角磨白了。他想起两个月前爹把买断通知摆在桌上那天，这个家的账页是灰的。现在，这本存折和他柜台底下那个基金本，要并到一本账上去了。

"我看过你修机器。"马建军把存折往儿子那边推了推，腰杆挺得笔直，是完完整整的一寸加上不知道多少寸，"手比我的稳。这钱跟着你，比跟着银行强。"
```
**学什么**: 存折拍桌(动作代情感)、"一寸加上不知道多少寸"(量化克制)、"比跟着银行强"(信任不直说)。

**范例B: 对白声口（出处ch37/39·示范"漏不要聚"）**
```
"这机器唱歌，"一个大爷捂着耳朵乐，"比我家彩电响！"

"大爷，回家给您孙子放《两只蝴蝶》，他保准不闹觉。"

"我不买。"大爷嘴上说着，手已经把音量键按上了，"我就听听。我孙子爱听这个。"

"大爷，三百二，良品，带单。"

"两百八！"

"二百八是普品。"王大龙插进来，"大爷，这机子您孙子用，得保。回头坏了，单子一拿，找我！"
```
**学什么**: 大爷"我不买"但手在按键(嘴硬身体诚实)、王大龙"找我"(两字兜底)、价目自然嵌在对话里不另起叙述。

**范例C: 对抗爽拍（出处ch39·示范"反派真赢不遮丑"）**
```
"马哥，咱们卖一台亏五十，他们卖一台赚一百。这买卖我越算越想不通。"

"想不通就别想。"马小丁说，"看总账。"

总账上的另外两栏，把这个窟窿堵上了：维修部当月利九百。贴牌机卖得越多，坏得越快，修得越多；旧机收售利八百。新机一冲，旧机持有人慌了，出手的多，收价压得低，转手利反而厚了。

三栏并一栏，当月总账，亏五百。
```
**学什么**: 亏就是亏(不遮不掩)、数据说话(三栏并一栏)、"看总账"三个字里含着不慌。
