# 50-风格包 v4：白金对标版（基于斗破/诡秘/大奉原文逐句对比）

> 来源：白金原文逐句对比报告。这是第一次基于真实白金文本（而非自创标准）的风格规范。

## 核心认知转变

```
我的认知（错误）：             白金市场的现实：
──────────────              ──────────────
好的文字 = 精炼/克制/余味     好的网文 = 疼/急/爽
温柔的开场也可以              必须第一章就给死局
读者会为质感停留              读者为痛点付费
氛围是资产                    氛围是负债（拖节奏）
暗示情绪是高级                直说情绪是效率
```

## 十条铁律（从白金原文直接提取）

### 1. 第一句话：≤10字的碎片
```
斗破："斗之力，三段！"（7字）
诡秘："痛！好痛！"（5字）
大奉："大奉京兆府，监牢。"（9字）
```
扔事件碎片逼读者追。不递完整画面。

### 2. 段落格式：对话永远独立成段
**绝不把对话和叙述混在同一段。** 对话说完就换段。
```
错误（我v5的做法）：
"你问我？"老许的眉毛挑得老高。陈默认识他三年了...（170字一段）

正确（大奉的做法）：
"你问我？"
老许的眉毛挑得老高。
"我干了三十年什么没见过？前年有一个案子..."
```

### 3. 压力系统：第一章必须给死局
```
斗破：当众羞辱 + "废物"标签 + 三年屈辱史
大奉：五日后斩首 + 两天后流放 + 女眷送教坊司
诡秘：濒死头痛 + 左轮枪自杀 + 血字遗书
```
全章必须有一个**倒计时**（X天后Y会发生）挂在所有闲聊上。

### 4. 情绪标签：扫读也懂
```
我的（错误）：老许把烟转了两圈（要求细读推情绪）
白金（正确）：老许不耐烦地说（扫读也懂）
```
用情绪/态度做对话标签，不用动作。

### 5. 600字规则：前600字交代完整前提
```
斗破在前600字完成：力量体系 + 前史 + 社会死局
大奉在前800字完成：地点 + 穿越 + 税银案 + 流放 + 死刑
```
中段闲聊必须挂在压力线上，不能飘。

### 6. 不预告笑话
```
错误："陈默认识他三年了，每次做这个表情，接下来肯定要讲一大段话。"
正确：直接让老许讲长话，长度本身完成笑果。
```

### 7. 爽点兑付：第一章必须有
主角必须在一个小场景里"赢"一次——证明自己、打脸质疑者、解决问题。

### 8. 句式变异：不重复效果镜头
"不是A，是B"判词句 + 短句静场收尾：每章最多用2次，不能连用。

### 9. 用词层级：最低门槛
网文腔词必须有：干脆/猛地/二话不说/脸色一变/心里一动。
禁用文学腔词：仿佛/宛如/透出/渗出/浮现。

### 10. 叙事声音：有性格的说书人
叙述者可以吐槽、评价、预告、跟读者对话。
不是隐形的摄影机。

## 我的作品 vs 白金的"味道"

| 作品 | 读起来像 |
|---|---|
| 斗破 | 少年漫画：滚烫的情绪，快/直/热 |
| 诡秘 | 潮湿的哥特悬疑：冷/慢/暗处有东西 |
| 大奉 | 相声演员掉进死牢：贫嘴不停，铡刀是真的 |
| **我v5** | **深夜电台都市怪谈：温柔/克制/有余味** |

→ 需要：相声演员掉进死牢的模式。温柔留作调味，不作文体。
