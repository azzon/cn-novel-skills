# set-piece:名场面钉桩(构思域)

> 溯源:情绪场面专项调研(编剧set-piece先定场面再倒推/起点百万票选共性/《道诡异仙》"名场面是整体故事的具象化,是整本书的锚点,定住两三百万字不写飘")·08(神作五题之"半年后记得哪个画面")。产物:`story/30-情节/名场面谱.md`。

## 前置条件

plot-spine 存在(场面挂在主线问题上);建议在volume-outline前跑(先场面后排期——编剧法)。

## 流程

**1 全书钉桩(立项层)**
1.1 定3-6个全书级名场面:每卷分摊1-2个;六型选型——**对峙/逆转/告别/揭底/围杀/平凡见真**(最后一型:大战写完写一碗面,最容易被低估);
1.2 **一景一句测试**:每个场面能用一句话转述成画面吗("雨夜里他替全城的神像撑伞")——不能=还没想清,重想;
1.3 绑定检查:每个场面绑主角目标与弧光(炫技场面=删)。

**2 单场面设计卡(每个场面一卡)**
- **铺垫链**:前十几章埋的牌(登记入伏笔总谱——场面是总兑现);信息差吊满(读者知底牌,剧中人不知);
- **回收链**:这个场面改变什么(格局/关系/认知,至少两项不可逆);
- **意象锚≤3**:一个可被记住的物/动作/画面(灰雾/圣名/一碗面);
- **出圈金句×1**:能脱离上下文被传播的一句话("三十年河东"式)——**每场面限一句,多了稀释**;
- **情绪+信息量**:情绪顶点的同时至少两条线在此交汇(名场面是多线的交叉点)。

**3 写作期接口**
3.1 卷纲中标注"章王候选"章;写作时章王候选走 alt-takes 多版盲选;
3.2 写完自测:半年后读者记得哪个画面?(arc-review的锚点对表项与此闭环)。

## 闸门

全书3-6个且分摊到卷/一景一句全过/每场面铺垫回收链入谱/意象锚≤3金句=1。

## Next Step

`NEXT-SKILL: opening-arc`(场面入章场景清单)。

## evals

- "这卷得有个大场面"(→单场面设计卡)
- "这本书能被记住什么"(→全书钉桩)
- "高潮写得挺热闹但记不住"(→一景一句+意象锚诊断)

## 逆转型子模板（红队20260919卷级批:名场面六型之外的第七型——"以为要赢了"）

三件套缺一=假高潮(arc-review"说不出的高潮"的事前预防):
1. **假胜利拍**: 胜利要有情绪重量(人物押上了/全场认定了),假得越真翻得越狠;
2. **翻牌线索回指**: 反转由≥2处已埋线索兑现(伏笔账登记),揭示拍必须回指("原来那天他…"),禁新信息空降;
3. **恶化量级**: 反转后局面必须比不动还糟一档(不然读者觉得"白紧张")。
与cool-point反转钩三律互链:三律管章末钩,本型管整场名场面。每卷≤1-2次(比反转钩更贵)。
