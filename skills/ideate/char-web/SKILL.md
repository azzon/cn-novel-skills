# char-web:人物网络

> 溯源:docs/21(对手=主角变体/假盟友)·22(立场原则:对手三件套)。产物:`story/20-人物/网络.md`。

## 前置条件

主角与主要配角的 `char-bible` 产物存在(网络连接的是已完成的人)。

## 流程

**1 关系图**
1.1 画主要人物关系图(节点=人,边=关系动词,禁"朋友/敌人"这种名词边——用"欠/护/忌/瞒"这种可写戏的动词);
1.2 每条边标注:双方各自怎么看这段关系(信息差即戏)。

**2 立场光谱**
2.1 每个对手填三件套:**正当立场**(他为什么认为自己对)/守护之物/付过的代价;
2.2 光谱排布:按对主线问题的不同回答排开,主角只是光谱上的一极,不是中心;
2.3 三件套写不出→该对手退为功能性路人(降级处理,不给大戏)。

**3 镜像与假面**
3.1 主对手=主角的变体(争同一目标,价值观有理——立场原则);至少一个"镜像人物"(主角的可能未来);
3.2 设≥1个假盟友(表面同路,立场相左)与≥1个假对手(表面为敌,暗中同路)——每卷至少变一次阵营温度。

**4 态度互斥矩阵**
4.1 抽查矩阵:任意两人对核心事件的态度必须有差异;全同→合并或改立场(人人同意的地方没有戏)。

## 闸门

关系边全动词化/对手三件套齐/光谱非中心化/真假两面各≥1/互斥抽查零全同。
