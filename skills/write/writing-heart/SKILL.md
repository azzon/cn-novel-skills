# writing-heart:灵魂层(可证伪版·磨刀十五批重写)

> 原版闸门全为主观状态("我爱角色吗")不可证伪,且越权覆盖机器硬门——重写为锚定冷读量规。

## 灵魂三问(每问都有落地判据)
1. **这一章的心跳瞬间在哪?** → 判据: 写完自标1段,冷读量规①-④该项须≥7且引文命中;命不中=没有心跳瞬间,重写该段
2. **作者私货埋了吗?** → 判据: 场景卡"私货"栏已登记且正文可指认(每人1个与剧情无关的动作)
3. **情感峰值收在动作/物件/沉默了吗?** → 判据: check.py #52峰后禁释 0违例(机器FAIL线=≥2处;0-1处靠人工复看)

## 注入五法(操作化)
- 感官锚定情感(不写"难过",写手里攥着的东西变了形)
- 延迟满足(情感拍之间隔动作/物件拍)
- 一句顶十句(每场至多1句人物内心直陈,其余靠行为)
- 沉默位(对话留白≥1处,谁都没接话)
- 具体名词(抽象情绪全部落到可触摸物件)

## 边界(划死,不越权)
**本技能只裁决"文风层内部"选择(如:细节A vs 细节B)。凡与机器硬门冲突(对话占比/峰后禁释/声口禁词等),一律机器门获胜,本技能不得作为豁免理由。**(原版"灵魂优先宁可对话少"条款废除)

## 闸门
三问各携判据通过+边界零违反 → 本技能贡献完成。产物: 场景卡"私货/慢拍"栏+心跳瞬间段标定。
