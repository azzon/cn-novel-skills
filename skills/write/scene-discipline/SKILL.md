# scene-discipline:场景化写作纪律（全书通用）

> 来源：全书138章多维度审计的系统性教训。
> v3更新（红队D审计）：实施"规则分层"——写作时只挂核心规则，其余全部下沉到事后检测。配额从"每章一刀切"改为"段级均值+章间方差"。

## 🎯 规则分层制度（v3核心变更）

### 写作时只挂6条（防不可逆劣化的铁律）
1. 禁止叙述概述对话
2. 禁止叙述概述发现
3. 声纹差异——遮名可辨
4. 角色即兴权——角色活了是最高成就
5. 每章一个心跳——写完问"有没有让读者咯噔一下的瞬间"
6. 入戏写——重点对手戏前用第一人称让角色即兴说100字

### 其余规则全部下沉到事后（check.py + scene-audit）
- 心理活动密度、对话占比、对话场景数 → check.py自动检测
- 反AI纪律（"不是A是B"/枚举/警句）→ 写完后修正，不前置
- 配额表 → 从"每章限额"改为"段级均值"（高潮章警句可以密，过场章警句可以零）

### ⚠️ 角色即兴权（新·与铁律同级）
```
写对话时，角色说了计划外的话、你觉得"这就是他"→ 照写。
事后回填场景卡即可，不算违规。

白金作家把"角色不受控制地自己想干一件事"视为角色立住的最高标志。
我们的系统此前把它定义为bug。现在纠正。
```

### 情绪预演协议（新·重点章必做）
```
全装轨章（高潮/名场面/情感重场）写之前，先以作者身份写一段：
"这一章我最想写的瞬间是___。我想让读者在___那一拍倒吸凉气。"

先有想写的冲动，再动笔。工艺退到服务位。
```

## ⛔ 六条铁律（保留但执行方式变更）

### 铁律1：禁止叙述概述有戏可看的对话（v4修订: 增加豁免通道）
```
❌ 他们讨论了红笔案的细节，最终决定分头行动。  ← 对话有戏可看但被压缩
✅ "你查纸坊，我查钱庄。"陈更把地图推过去。
   "要是碰到执笔的人呢？"
   "碰到再说。"
✅ 两人商量了一会，觉得天衣无缝。  ← 合法压缩: 对话无戏可看(纯过渡/共识确认)
```
**判定标准(修订)**：
- 有交锋/信息差/情绪碰撞的对话 → 必须逐句写。压缩=FAIL。
- 纯过渡(共识确认/时间跳跃/无冲突) → 可压缩为一句。
- 判据: 删掉压缩句后，读者是否丢失了"想知道的"?丢→必须展开;不丢→合法压缩。

### 铁律2：禁止叙述概述发现
```
❌ 陈更查了卷宗，发现了关键线索。
❌ 经过三天的调查，他终于弄清了真相。
✅ 陈更翻开第三册。手指停在了第七十三页。
   他把纸凑到灯下。纸背透出一个印子——淡的，圆的，像针眼。
```
**判定标准**：如果"发现"的过程被一句话带过，而非展开为带有动作、感官、递进的场景——FAIL。

### 铁律3：声纹差异——每个角色说话必须"遮名可辨"

```
❌ 所有人都用中等长度的文学语气说话：
   陈更说："这个问题很严重。"
   闻人霜说："确实很严重。"  
   樊大说："太严重了。"
   墨鸦说："非常严重。"

✅ 每个人用自己的方式说同一件事：
   陈更把账册翻到第七十三页，手指按住。
   "利息不对。月息二分，滚了三年，应该是十九两五。这里写的是二十六两四。"
   
   闻人霜凑过来看了一眼。"第六款。虚立利息者，债主反坐。核三遍。"
   
   "核什么核！"樊大凑过来瞄了一眼，"假的！一看就是假的！这字歪的！"
   
   墨鸦没有看账。他在看账房先生的脸。
   "他的手在抖。"他说。"做贼的人，手才会抖。"
```

**判定标准**：遮住角色名，能不能从对话本身判断出谁在说话？
- 陈更→看数字精确度（一定是"十九两五"不是"差不多"）
- 闻人霜→看律条引用（一定是"第几款"不是"规定说"）
- 樊大→看词汇粗细（一定是"假的""歪的"不是"存疑"）
- 墨鸦→看观察角度（他看人不说账，他评人的行为不评事）

**声纹卡注入制度**：
写任何角色的对话前，必须把该角色的声纹卡贴在场景卡旁边。
声纹卡位置：`story/20-人物/声纹表.md`
不贴卡不写对话。这是纪律。

**声纹违例检测**（check.py #23）：
每个角色有禁用词表。角色说了禁用词:check.py #23报WARN(允许喜剧性故意违例,登记豁免即可);**硬FAIL在voice_check.py声口卡禁词门**。
例：樊大说"可谓"→#23 WARN+voice_check硬FAIL（樊大是屠户不会说"可谓"）
例：墨鸦说"咱们"→FAIL（墨鸦是六层养的孤儿不会说"咱们"）

**角色专属词汇域**（一秒辨认法）（本书快照——仅本书有效，新书须用char-voice重算）：
| 角色 | 他/她一开口就会说的词 | 绝对不会说的词 |
|---|---|---|
| 陈更 | 账/契/核/验/利/本/秤 | 大概/差不多/算了 |
| 闻人霜 | 律/款/章程/核三遍/存照 | 可能/也许/感觉 |
| 樊大 | 肉/揍/吃/娘/力气/更子 | 可谓/然也/诚如 |
| 墨鸦 | 奉谕/六层/楼里/查 | 高兴/害怕/咱们 |
| 文渊 | 本座/可惜/斯文/老夫 | 他娘的/混账/放屁 |
| 钱通宝 | 小可/这单有的赚/贤弟 | 真数/准话 |

### 铁律4：角色即兴权——角色活了是最高成就
```
写对话时，角色说了计划外的话、你觉得"这就是他"→ 照写。
事后回填场景卡即可，不算违规（详见上文「⚠️ 角色即兴权」）。
```
**判定标准**：角色不受控制地自己想干一件事，不是bug，是角色立住的最高标志。

### 铁律5：每章一个心跳
写完问自己：这一章有没有让读者"心里咯噔一下"的瞬间？
没有——这章是死的，重写（与writing-heart灵魂三问同源）。

### 铁律6：入戏写
重点对手戏动笔前，用第一人称让角色即兴说100字，再回到第三人称落笔。

### 附：心理活动每千字≥2处（v3已下沉到check.py事后检测，不再列为铁律）
```
❌ （全章没有任何内心独白、心理反应、情感挣扎）
✅ 他想，师父要是还在，这时候该说什么。
✅ 心里一沉。他知道这意味着什么。
✅ 他忽然想起母亲信里那句话——越欠越富。
```
**判定标准**：check.py自动检测（心理词频<0.5/千字=FAIL,<2.0/千字=WARN;白金标准2.0/千字）。心理活动不限于"他想"，可以是条件反射（手停了）、身体反应（后背发凉）、条件联想（忽然想起某人的话）。

## 🚀 三引擎纪律（红队20260918系统级修复: 代入感/AI检测/付费意愿）

### 引擎A：反AI指纹律（平台检测硬红线）
- 每章至少 **3个超短独立段**（≤5字，如"有了。""就是它。""不对。"）
- 每章至少 **3个长段**（≥80字，信息密度高、有画面推进）
- 段落长度方差 **必须>40**——禁止连续5段字数接近（±15字内）
- 对话标签必须多变：说/回/喊/嘟囔/没接话/半天没吭声/应了一声——禁连续"他说"
- 句式必须有碎片句（≤5字）与长句（≥30字）混杂
- **机器门**: check.py段长方差<25=FAIL, <35=WARN

### 引擎B：记忆碎片律（代入感引擎）
- 每千字至少 **1条主角的感官记忆闪回**
- 必须是具体的感官细节（气味/声音/触觉/画面），不是情节复述
- 正确："忽然想起小时候外婆灶台上的柴火味，混着咸菜的酸。"
- 错误："他想起小时候外婆对他很好。"（这是情节，不是感官）
- 闪回应打断当前动作，制造"人是有过去的"质感
- **机器门**: check.py记忆碎片<0.5/千字=WARN

### 引擎C：社交货币律（付费意愿引擎）
- 每章至少 **2个"读者会截图发群"的高光拍**
- 高光拍定义：让读者忍不住想跟人讨论的瞬间
  - 全场愣住/鸦雀无声的反应拍
  - 拍桌/拍腿叫好的爽点拍
  - 让人笑出声的对话
  - 能当金句截图的短句
- **不是"写得好"就行，是"读者想拿给别人看"才行**
- **机器门**: check.py社交货币拍<2=WARN

## ⛔ 反AI纪律（红队7文学品质审计新增·2026-09-10）

### 反AI-1："不是A是B"纠偏句式每章≤1处
红队7检测10章29次，是最严重的AI指纹。
```
❌ 不是因为他可怜，是因为他知道了。
❌ 不是宽免，不是慈悲，是"留"。
✅ 他们教的手法，是本座教的。（直接断言即可，不需先立后破）
```

### 反AI-2：枚举癖——叙事层禁用"第一/第二/第三"列表
```
❌ 第一层，公开是保护。第二层，公开是扩军。第三层，公开是请旨。
✅ 公开是保护。也是扩军。最要紧的，是请旨。
```
**规则**：世界观文书（供状/帖/判词）内的枚举保留。叙事层的枚举改为场景化呈现。

### 反AI-3：警句配额每章≤2句 + "本座"只留白老爷（本书快照——仅本书有效，新书须用char-voice重算）
- 警句每章≤2句且勿章章顶格（10/10章每章2-3句=无方差；0/1/2混合才有呼吸）
- "本座"只给白老爷用（红队7检测5角色共用79次）
- 念账人改自称"老夫"或直呼己名
- 文渊用"老夫"
- 清道夫用"我"

### 反AI-4：每章至少一段60-120字长呼吸段 + 2-3处生活感官闲笔
红队7检测：66%段落≤40字，全书无一处长段蓄势。
```
生活闲笔例：
- 茶棚早市卖什么早点
- 狱卒的伙食是什么
- 雪落在屋顶的气味
- 某个不重要的角色在做什么无关的事
```
**规则**：每章至少1段60字以上的长呼吸段（不推进剧情，只活在这个世界里），2-3处与主线无关的感官闲笔。让读者闻到味道、摸到质地、听到不重要的声音。

### 反AI-5：对话标签动作化
```
❌ "……"他说。"……"她问。
✅ "……"陈更把笔搁了。"……"闻人霜的手按在刀柄上。
```
红队7检测："说"字10章出现96次。按角色配动作标签：樊大用挠头/嗓门，闻人霜用笔（"笔没有停"），陈更用吹墨/拨算盘。

### 五问自检升级版（写完每章后）
1. **遮名测试**：遮住角色名，能不能从对话判断出谁在说话？
2. **电影测试**：拍成电视剧有没有足够的台词+动作？
3. **删减测试**：删掉所有对话，叙述还能独立成章吗？能→FAIL
4. **声纹测试**：五个角色的各一句对话打乱，能重新配对吗？不能→FAIL
5. **心理测试**：每个主要角色至少一次内心活动？没有→他是工具人→FAIL
6. **AI测试**：把这一章给一个不知情的读者看，他能猜出是AI写的吗？能→FAIL

## 🔧 信息交付三法（查案/发现/揭示必用）

信息不能靠叙述"告知"读者，必须通过以下三种方式之一"演"给读者：

### 方法1：对话交付（最常用）
两个角色讨论案情，信息在对话中自然流出。
```
"死者手里攥着一支笔。"
"什么笔？"
"红杆的。笔头秃了——秃得不成样子。"
```

### 方法2：动作交付（最适合发现）
角色通过具体动作（翻页、对灯、摸痕）让读者"跟着发现"。
```
他翻开第三册。手指停在第七十三页。
纸背透出一个印子——淡的，圆的。
他用指腹摸了摸。硬的。烧进去的。
```

### 方法3：比较交付（最适合揭示差异）
两个角色或两份物证放在一起，差异自己说话。
```
他把两本账并排摆在灵前。
戒尺落下去。笃。声闷的。
戒尺移过去。笃。也是闷的。
```

## ⚠️ 最后一道自检（写完每章后问自己五个问题）

1. **遮名测试**：把角色名遮住，能不能从对话判断出谁在说话？
2. **电影测试**：如果拍成电视剧，这一章有没有足够的"演员台词+动作戏"？还是全是旁白解说？
3. **删减测试**：如果删掉所有对话，剩下的叙述还能不能独立成章？如果能——说明对话只是装饰，不是骨架。FAIL。
4. **声纹测试**：摘出五个角色的各一句对话，打乱顺序，能不能重新配对？如果不能——声纹没有差异。FAIL。
5. **心理测试**：每个主要角色在这一章里，至少有一次"心里想什么"？如果一个角色的内心完全空白——他在这章里是工具人。FAIL。

## 📐 视点纪律（红队20260919缺陷023: 400万字长跑视点漂移防线）

### 规则
- 默认**限制第三人称**(跟一个角色的所见/所想/所感)
- 每章最多**一个视点角色**(禁止head-hopping)
- 视点角色的内心活动不限量;非视点角色的"内心"只能通过外在行为暗示
- 跨视点需用分节符(空行/※/---)并重新锚定(首段点名新视点角色)

### 为什么这是铁律
400万字尺度下视点漂移是最隐蔽的崩坏——每章偏1%,读者感觉不到;每卷偏10%,读者说"写散了";每50章偏50%,读者弃书。而机器门检不出"这是谁的内心"因为标记词无法区分视点归属。

### 例外
全知说书体(如保守起见的"后来人们说……")不算视点漂移,但每卷≤3次。

## 🔇 独角戏章型豁免（红队20260919缺陷025）

### 问题
check.py门#16(对话<35%=FAIL)/#18(<2场景=FAIL)把独角戏(追踪/独行/昏迷/闭关/雪夜)结构性判死。但400万字必然需要这类章。

### 豁免条件(全部满足才豁免)
1. 场景卡"场景型"标注为: 独白/追踪/潜行/闪回/冥想/灾变之一
2. 主角有至少3处心理活动或感官描写
3. 章末有钩(悬念/发现/转折)
4. 章内无≥5轮纯对话(即不是伪装的对话章)

### 豁免后替代配额
