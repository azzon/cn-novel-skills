# line-polish:轴制润色

> 溯源:docs/20(文笔论/自查20条)·23(句末落点)·MJbae多轴polish模式。产物:修订后的场景文件(整文件重输出)。

## 前置条件

场景已过scene-audit(先验收后润色——顺序不可反)。

## 流程(四轴,逐轴过,每轴独立报告)

**轴1 陈词滥调轴**
1.1 逐句查AI腔库存(不是…而是/仿佛/似乎/眼神闪过/空气凝固类,docs/20禁词表)+ 本书专属禁词(风格卡禁项);
1.2 处方:替换或删除——**报出每一处的原句与改句**。

**轴2 声音轴**(只管叙述句;对话句一律转dialogue-doctor)
2.1 逐人核对话:遮名可辨吗;有没有说出"死穴词"(char-voice表);
2.2 处方:按声纹表重写违例句。

**轴3 节奏轴**
3.1 长短句呼吸(语料校准:网文叙述以逗号长句为主——整句20-30字占七成半,短句是重拍工具不是默认态):紧张段短句化但禁全程碎片;连等长>3句拆;连续超多段的极短段连排=反向违例;
3.2 松段配额检查(本场景≥1段只干活不抖机灵);
3.3 笑点句末落点核查(抖完后有没有多余的字)。

**轴4 钩轴**
4.1 场景末三行:钩力度与场景卡预标一致吗;轻钩不轻、重钩不重→只改末三行。

**输出纪律**
- **整文件重输出**(修订意见+重生成,禁字符串补丁);
- 润色后跑 check.py 复验;改动逐轴留痕(改了什么/为什么,一行一条)。

## 闸门

四轴全跑/每轴有逐条处方/整文件输出/复验全绿/无轴外私改。

## Next Step

`NEXT-SKILL: ops:ledger-update`(若钩或笑点改动影响台账)或直接归档。

## evals

- "这段差点意思"(→先问哪一轴,再动手)
- "帮我全文润一遍"(→拒无差别通改,逐轴)
- "对话不像他说的"(→轴2单项)
