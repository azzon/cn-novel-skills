## 状态八态消歧
| 态 | 判定 | 处置 |
|---|---|---|
| planned | 卡存在,章不存在,N≥next | 可开工 |
| gap(缺章) | 章不存在,N<max | 禁直接补写,路由arc-restructure(防事故C重演) |
| card_missing | 章存在,卡缺失(ch41/43实况) | 历史欠账;done --revise降WARN |
| drafting | 章存在,git未clean | done的目标态 |
| committed | 章git clean | done默认拒绝(exit 2,提示--revise) |
| 改写已归档章 | done N --revise | gate modified模式;强制WARN"ledger需对第N章重跑" |
| 卡卷错配 | 卡卷号≠期望卷 | 新章FAIL;--revise=WARN |
| 卡先行不可证 | 卡与正文同commit | 接受为已知限制,不做伪证明 |

状态以**章**为粒度（现实是单卡单文件）。超期节奏项派生：冷读=story/audit/冷读-第NNN章.md（新命名约定）；漂移=漂移审计-*.md取max；盖章=六账含"第0?N章"token。**MVP只对newest章强制盖章**，历史欠账一行汇总。

## 命令规格（退出码统一: 0过/1未过/2用法或前置缺失）
| 命令 | 输出 | 退出 |
|---|---|---|
| status | 进度行+每章状态+节奏欠账+下一动作 | 0 |
| next [N] | 工作契约:期望卷/卡字段/将跑的门/done交付物/轨道 | 0/2 |
| bundle N | stdout注入包+预算报告;缺卡/风格包/声纹表→exit 2 | 0/2 |
| check <file...> | 转发check.py+gate_chapter | 同被调 |
| done N [--revise][--strict] | 验收清单→重算progress+scores+盖章提示 | 0/1/2 |
| scores [--recompute] | 打印/重算scores.json | 0/1 |

实现约束：status/scores **import check.py的check()函数**（避免79次subprocess）；done用subprocess保持与hook完全同构。**单一实现，两个入口**：done与hook都只调check.py+gate_chapter.py；cadence检查只在done。

## done分级
- **硬拒(exit 1)**：缺卡、check.py任一FAIL、G4卷归属错、G1新章<1500、G5查重>15%、G2章号非next(无--revise)、--strict时全装轨冷读缺失
- **WARN(exit 0)**：5章窗口冷读欠账、六账未盖章、卡beat预算偏差>40%、--revise时卡卷错配
- 唯一豁免通道=ledgers/waivers.md登记制（复用hook既有函数）

## 技能文本迁移（先决项）
- **scene-draft**：第一步改为"五件套由`pipeline.py bundle N`装配并按此顺序注入"
- **pipeline-chapter**：取位→`pipeline.py next`；四个gates.py硬门收编进bundle/done；冷读→check+reader-proxy；章完成→`pipeline.py done N`；中断恢复→`pipeline.py status`禁凭记忆
- **continuation**：读四样→`status`+`bundle`；保留位置三问/防穿帮三查
- **ledger-update**：加"禁无章号记账"（盖章派生的前置）

## MVP切割
**v1必有**：status、next、bundle(章模式)、done(含--revise)、scores最小集、check薄封装。
**v1不做**：--scene、--full、卡卷自动修复、盖章历史回填、drift读scores。
**v2**：--scene/--full、卷纲预标解析、drift趋势图、hook C2改文件存在性、gates.py退役、章内多场景。

## 已接受限制
1. 卡先行git历史不可证；2. --no-verify绕过的补偿层(pre-push全库复扫)排期；3. 盖章派生基于grep章号token——依赖"禁无章号记账"纪律。
