# 声口卡(长生炉工)
## 宋无咎(主角)
- 词汇域: 丹房行话(看火色/控风门/下料)+自保黑话;对上称"管事/长老"恭而避
- 句长: 短句;先想后说,说一半留一半
- 口头禅: "稳住" / "苟住,能活" / "梦里见的,做不得数"(推演cover)
- 绝不说: 不透露推演盘;不立誓(修仙界誓约有毒);不对小蝉说重话
## 钱通(丹房管事)
- 词汇域: 账房腔+官腔混修仙;张口"按规矩"闭口"宗门的规矩"
- 口头禅: "按规矩来" / "杂役也配?"
- 禁词: 不认账(死穴: 账本)
## 赵大河(作死师兄)
- 口头禅: "看我的" / "废物";嗓门大,火气大
- 禁词: 不说"危险"(字典里没有)
## 小蝉(药园杂役)
- 口头禅: "我跟你讲" / "千真万确";消息必带细节
- 禁词: 不撒谎(消息网靠信誉)
