# 人物圣经(长生炉工)

## 一、恒定层
### 宋无咎(主角,20,丹房烧火杂役)
- 生理: 瘦长,手稳如火钳,右眉一道细疤(入宗日被炸炉碎石所伤)
- 社会: 凡人孤儿,杂灵根,十四岁入宗;寿元六十载(凡人身),推演盘每月都在烧它
- 心理: 胆小心细,把"活着"当手艺练;对死人麻木对活人心软;嘴笨手快
### 欲望引擎四件套
1. **ghost**: 入宗第一天,前任烧火杂役的尸体从丹房抬出来——三个月后他知道,那个位置本来轮到自己
2. **wound**: 灵根残缺=修仙界的耗材;凡人命如草芥,连怎么死的都由别人填单
3. **lie**: "躲得够快就死不了"——真相: 有些劫躲不掉(躲开炉炸,救火会死;躲开大火,火里还有别人)
4. **want**: 活到寿终正寝,寿元账本只进不出
5. **need**: 明白"苟"是手段不是目的——该出手护人时,把寿元大把撒出去也在所不惜(每卷一"认真章")
### 压力反应模式
- 遇死劫推演→先算成本再行动(寿元是货币);被欺压→让数据和事实说话(手艺人的底气);触碰底线→手比脑子快
