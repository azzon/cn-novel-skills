# 人物圣经（《法医秦见微》·拉力重建版 2026-09-14）

> 来源: 书主反馈"没兴趣"+双代理拉力诊断。根因=立项漏人物引擎设计(ghost/want从未定义),正文"技术合格没兴趣"。
> 本圣经按成功作品共性公式重建: **私人欲望驱动 + 关系不可逆移动 + 创伤与案件同构**。

## 主角引擎: 秦见微

| 层 | 内容 |
|---|---|
| **Ghost( ghosts from past )** | 父亲秦守拙,老法医,1990年"青阳纺织厂女工案"中出具的关键鉴定被经验派推翻,无辜工人周长贵被判十年;父亲三年前病逝,临终反复说"那个案子不对,我没做错"——没说完哪里不对就走了 |
| **Wound(正在流血的伤)** | 父亲死后背着"办错案老法医"的家属名声;周长贵1998年刑满释放回城,就住在县城——**愧疚是活的、会走动的** |
| **Lie(主角信的谎)** | "只要证据足够硬,真相自己会赢"——他以为父亲输在技术不够硬,其实父亲输在人事(卷宗缺的那页) |
| **Want(表层欲望)** | 让每具尸体说话,在队里站住脚(短期);**翻父亲的案**(全书引擎,卷一埋线) |
| **Need(深层需要)** | 弄懂父亲当年为何沉默——不是无能,是被压、是妥协、还是另有隐情。**每破一案既接近真相又撕开家族伤口:欲望与代价同轴** |
| **压力反应** | 被质疑:加做检测(外化). 被提父亲:停顿,转移话题(内伤). 赢案后:独处时不庆祝,复盘卷宗 |

## 对手重定位: 老拐(周德发)

| 层 | 内容 |
|---|---|
| **致命改动** | 老拐=1990年纺织厂案的**经办刑警**,当年签字推翻父亲鉴定的正是他 |
| 自洽逻辑 | 他不认为自己是坏人:当年"证据链不完整,按经验办是对的",此后的仕途与威望全建立在那个判断上——**翻案=否定他的26年** |
| 威胁等级 | 能拿走秦见微在乎的一切:转正评定、案件分配权、政治生命。ch002"人也会"是宣言:下阶段走人事不走证据 |
| 弧光方向 | 对手→强敌→镜像(他也护着某种"秩序")→最终对峙时观众应该犹豫 |
| **纪律** | 每3章必须对主角造成一次实际伤害(转正/案件/孤立),态度冷遇不算伤害 |

## 关系不可逆移动(狂飙式钩子的来源)

- 秦见微 ↔ 老拐: 每卷关系恶化一格(对手→仇敌→镜像),不可逆
- 秦见微 ↔ 周长贵(被冤者): 回避→偶遇→愧疚具象化→成为翻案理由
- 秦见微 ↔ 父亲(死者): 每破一案更懂父亲一分,也更怕知道答案
