# volume-outline:卷纲·章场景清单

> 溯源:docs/21(单元×主线咬合)·24(场景型)·25(钩三级/获得四类)。产物:`story/30-情节/卷一纲.md`(模板化,逐卷复制使用)。

## 前置条件

`story/30-情节/主线.md` 存在(本卷七步骤已定)。

## 流程

**1 卷骨架**
1.1 定本卷单元序列(3-6个单元)+每单元一句话案情;
1.2 咬合表:每单元"本案权成+主线推一格(递什么卷宗/拼图/关系)"——纯平行单元禁入(劈成两半的故事)。

**2 章场景清单(逐章)**
2.1 每章拆2-3场景,每场景预标:**场景型**(审讯/争辩/日常/动作/揭示)/**钩级别**(轻/中/重)/**获得类别**(能力/地位/人际/信息)/出场人物;
    （若用户点名断章法duanzhang，本卷改按叙事段规划、段内不设章界——两范式二选一）
2.2 章级检查:每章至少1场景带喜剧主档(喜剧向项目);每3章至少1中钩;每5-8章1重钩(25§三);
2.3 拆不出2场景的章=无事发生章→与邻章合并(狠心,别留)。

**3 压-弹预排**
3.1 标出本卷哪些章是燃/泪章(仅落位章号;数值规格与排期归pacing-score,不在此复抄);
3.2 燃泪章的前一章必须是喜剧或日常章(蓄力律)。

**4 节奏审计**
4.1 连续同型场景≤2;连续同钩级≤3;情绪档位相邻章必换。

## 四个必填块(红队H2:白金卷结构实测)

每卷卷纲必须含:
1. **晋升位**:本卷的大获得/晋升锁在最后15%卷幅(与卷末高潮同拍);
2. **固定群戏排期**:核心配角的集体场景每20-30章一次(跨地图心跳锚——塔罗会式容器的出勤表);
3. **换图三件套**(若本卷换地图):随迁情感角色≥2/旧图回流安排/情感账户不清空;
4. **卷末钉桩**:卷末高潮+下卷第一钩(收官卷则是Z级清算+终局验收)。

## 闸门

咬合表全覆盖/章场景清单预标齐/钩分布符合频率/压-弹相邻律成立/节奏审计过。

## 单元剧健康度判据十条（2026-09-12工艺深研,排单元时逐条过）
①单元体长2-4章(超6章读者按主线期待追必失望) ②单元内必有一次价值转变("修好"≠故事完成,主人自己变了才算) ③每3-5单元主线实质推进一格(只让主线人物露脸不推进=柯南式停滞) ④主线人物入单元必带走或留下东西(禁纯客串合影) ⑤连续3单元禁同模板(物件域/冲突类型/结局走向至少换两样) ⑥成功结局≤70%,结局五态轮换:修好/修不好/不修/修好后主人变了/物件换了主人(风险必须在场,反《大医凌然》快感透支) ⑦每单元给主线贡献≥1信息碎片,碎片分持不同人物(一人之下法) ⑧胶水可见化:手艺成长来自单元内失败;每3-5单元一次跨单元callback ⑨任务-奖励禁同构(钱/人情/线索/声望/手艺轮换,防刷肝感) ⑩病征监测:评论区只谈角色不谈案子=病入膏肓先兆;单元开篇1章内必须挂主线或新异象之钩。
