# Skill: trial-write
# trial-write:试写验证（构思域最后一步·先于正式写作）

> 溯源：白金作家实况——辰东"先写几章看感觉，不行就换"
> 本技能在构思域24叶全部走完后、正式开写前运行

## ⛔ 核心理念

**大纲写得再好，写出来不好就是不好。**

```
错误流程：构思完24叶 → 直接开写 → 写了100章发现不对
正确流程：构思完24叶 → 试写3章 → 冷读 → 好→正式开写 / 不好→回到构思
```

## 试写流程

### 第一步：选最有感觉的3章试写

不是开头的3章。是你**最想写的3章**。

```
选择标准：
- 第一章（测试开篇钩力）
- 一个中段高潮章（测试爽点兑现）
- 一个情感重场章（测试泪点成色）

如果这三章写完你自己都没感觉 → 整本书不会有感觉
```

### 第二步：写作（不带任何规则）

**关键：试写时不挂任何scene-discipline/check.py规则。**

```
为什么：试写的目的是测试"故事本身有没有感觉"，不是测试"工艺是否达标"。
带着30条规则写出来的试写稿，测试的是规则不是故事。

规则：
- 想怎么写就怎么写
- 写到哪算哪
- 不改错别字
- 不回头修改
- 目标：3000字×3章，一口气写完
```

### 第三步：冷置24小时

写完后放24小时不看。让初写的兴奋冷却。

### 第四步：冷读三问

24小时后读自己的试写稿，问三个问题：

**Q1：我想继续往下写吗？**
```
10分：迫不及待想知道后面发生什么
7分：有兴趣，但不是非写不可
5分：写着也行，不写也不难受
<5分：我在"完成任务"不是在"讲故事"
→ <7分 = 回到构思域，重新孵化
```

**Q2：我写的人物是活的吗？**
```
测试法：遮住名字，能分辨谁在说话吗？
        角色说了让你意外的话吗？
        你"跟着角色走"了还是"推着角色走"？
→ 全程在推角色 = 人物没活，回到char-bible
```

**Q3：这三章里有没有一个瞬间让我自己起了鸡皮疙瘩？**
```
可以是一句话、一个动作、一个沉默
如果没有 → 故事的"心跳"没找到
回到story-incubate的法1极端推演，找更极端的场景
```

### 第五步：裁决

| 结果 | 动作 |
|---|---|
| 三问全过（≥7分+角色活+有鸡皮疙瘩） | 正式开写 |
| 一问不过 | 定位问题→回到对应构思技能重做 |
| 三问全不过 | 回到story-incubate从头孵化 |

## 常见陷阱

### 陷阱1："再写几章就好了"
```
❌ 感觉不对但自我安慰"写到十章就顺了"
✅ 三章没感觉就是没感觉。白金作家会推翻重来，不会硬推
```

### 陷阱2："是大纲的问题，改改大纲就好"
```
❌ 只回去改大纲，不改核心创意
✅ 大纲改了写出来还是没感觉 = 核心创意本身有问题，回到孵化
```

### 陷阱3："工艺不好所以没感觉"
```
❌ 把"没感觉"归咎于文笔/技巧不够
✅ 试写本来就不看工艺。没感觉=故事没灵魂，不是笔法问题
```

## 产物

- `story/00z-试写/第X章.md` × 3（试写稿，不进入正式text/目录）
- `story/00z-试写/冷读记录.md`（三问的回答+分数+裁决）

## 过闸

试写冷读记录必须包含：
1. 三问的分数和具体回答
2. 如果通过：哪一章最有力、为什么
3. 如果不通过：具体问题在哪、回到哪个技能重做

## 与其他技能的关系

- **story-incubate**：不通过时回到这里重新孵化
- **style-compiler**：通过后才做风格包（正式进入写作域）
- **ideate-audit**：在试写之前运行（确保24叶齐），试写是最后一关
- **opening-arc**：正式开写时的黄金三章设计与试写的第一章不同（试写是测试，正式是打磨）

## evals

- "可以开写了吗" → 运行本技能
- "写出来感觉不对" → 冷读三问重新诊断
- "要不要推翻重来" → 看冷读记录的裁决
