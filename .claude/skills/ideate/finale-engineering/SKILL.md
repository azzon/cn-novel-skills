# finale-engineering: 完本收束工程

> 溯源:红队20260919商业批——plot-spine有终局三律(骨架),publish-prep有完本长尾(运营),倒数30章的章节级工程无技能。

## 输入

伏笔总谱(foreshadow-plan)/配角归宿账本(plot-spine 4.7)/魅力瞬间账/线弦账/卷册表。

## 倒数30章排期表(产物,入收官卷纲)

| 阶段 | 章位 | 义务 |
|---|---|---|
| 收割期 | 倒30-16章 | 支线收割日历:每2-3章收1条线(伏笔Z/A级全清,foreshadow-audit零悬空才许进终局期);配角告别章≥3场(用离别卡写法,观众缘三问全过的角色才配告别章) |
| 决战期 | 倒15-4章 | 终局三律(plot-spine):问题句当章回答/主题收官卷三禁三必;末三章加压梯照常(volume-outline必填块6);大反派决压三场景 |
| 余韵期 | 倒3-1章 | 大团圆工程:全员一处一场(名册式点名=粉丝服务,禁新冲突);主题句最后一答;末章=留口不挖坑(publish-prep完本长尾) |

## 硬线

1. 收割期禁开新线(新伏笔进终局期=太监预警,直接FAIL);
2. 回忆杀密度:决战期每3章≤1次(滥用=注水感);
3. 末章禁"一切都是梦"/禁全员复活/禁无字完结(plot-spine三禁延伸);
4. 完本月冲刺:加更余韵章对齐完本榜窗口(publish-prep月票排期同款);
5. 完本前全账清零审计:伏笔/期待债/线弦/魅力瞬间四账各出一份"全收"对表,任何一条悬空=不许标完本。
