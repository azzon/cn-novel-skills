# world-map:地理与地图

> 溯源:docs/21(结构/换幕)·22(呈现)。产物:`story/10-世界/地图.md`。

## 前置条件

`story/00-前提.md` 与 `story/10-世界/力量.md` 存在(地图规模随力量梯度与故事跨度定)。

## 流程

**1 分层地图**
1.1 按"卷进度"分层:首卷舞台(小而深)→中段扩展域→后期全域(每层标对应的卷);
1.2 每层一张简图(文字描述即可):核心地点+连接方式(路/河/禁地)+距离感(以剧情时间计,不以里计)。

**2 空间即剧情**
2.1 每个地点答三问:这里的**戏剧功能**(什么冲突只能在这发生)/这里的**规则差**(进入此地,哪条世界规则变了)/这里的**代价**(来这要付什么);
2.2 三问答不出的地点→删或并入邻地(地点不是布景,是关隘)。

**3 记忆负担审计**
3.1 首卷读者需记住的地名≤7;全域书名级地名≤15;
3.2 命名规则统一(同文化区同名源——接world-culture),生僻字禁用。

**4 呈现要点**
4.1 每地写"读者第一印象清单"≤3件(一景一物一声,经五感进入,禁导游式介绍);
4.2 标注换图节奏:每2-3卷换主地图,换图前3章埋新图钩子。

## 闸门

分层齐/每地三问有答/首卷地名≤7/每地第一印象清单≤3/换图节奏明文。
