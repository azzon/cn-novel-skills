# theme-dossier:主题档案

> 溯源:docs/21(主控思想/道德论证)·22§四(价值观即抉择)。产物:`story/01-主题.md`。开源五库均无主题独立立项——本技能是差异化件。

## 前置条件

`story/00-前提.md` 存在(含主控思想三件套)。缺→先调 premise。

## 流程

**1 道德论证网**
1.1 主控思想拆成正反两立场(主角代表X,主对手代表Y,Y必须有理可辩——立场原则);
1.2 每个主要人物登记为网中一个立场变体(同一主题问题的不同回答);
1.3 落盘为表:人物|立场|他靠什么剧情机会说出这个立场(用行动,禁演讲)。

**2 两难库(主题的单元剧燃料)**
2.1 围绕主题造≥5个具体两难(格式:若A则失B,若B则失A——**两头都是好东西**);真例:若判真话则折寿三日,若不判则冤者赴死;
2.2 每条标注:适用单元类型/预计卷次/主角的两难选择倾向(与want/need挂钩);
- 自检:五条互不同质(不是同一两难换皮)→同质则删并补新。

**3 高潮验证**
3.1 写终卷高潮场面一段(白描,谁在什么压力下做了什么选择、付了什么代价);
3.2 检验:主题是否不借台词被这个场面"演"出来;主角的选择是否就是主题的回答。

**4 反说教体检**
4.1 通读三节产物,逐句查"作者腔"(人物替作者发言/叙述者评论);查到→改为事件或删除;
4.2 删主题句测试:把主控思想句遮住,高潮段是否仍传达它?否→高潮还不够"事件化",回3.1。

## 闸门

论证网全覆盖主要人物+两难库≥5且不同质+高潮验证通过+反说教双检过。
