# 叙事距离(scene-draft的references,红队20260919文笔上限批新增)

> 溯源:文笔天花板审计——叙事距离三挡全库零字,高潮平推="高潮不燃"、过渡贴身="拖"的共同根因。

## 三挡定义

| 挡 | 镜头 | 语言特征 | 适用 |
|---|---|---|---|
| 贴身 | 在角色颅腔内 | 内心独白/秒级感知/身体感受先行/短句 | 高潮拍/情感重场/决断瞬间 |
| 中距(默认) | 跟在角色肩后 | 动作+对白为主,偶入内心 | 常规叙事 |
| 远景 | 无人机/说书人 | 概述数日/全知插叙"后来…"≤3次每卷 | 过渡/时间跳跃/卷首定场 |

## 换挡纪律

1. 场景卡"距离"字段=本场景主挡(缺省中距);一场内至多换挡2次,换挡处用空行或节奏急停标记;
2. **高潮前一句急停推贴身**: 决胜一击前插一个≤5字的超短段(急停),然后进贴身——这是"燃"的机械来源之一;
3. 过渡禁贴身: 换地图/隔天/赶路用远景带过,贴身硬磨=读者说"拖";
4. 与视点纪律(scene-discipline)分工: 视点管"谁的内心",距离管"离颅腔多远"——同一章可只一个视点但多挡。

## 机器代理

## 运镜对照表（红队20260919十波批W7:三挡管距离,此表管场内运镜,一场≤2次）

| 镜头 | 文字对应 | 用途 |
|---|---|---|
| 推 | 视线收窄到一物("他的目光落在那把算盘上") | 钉住关键器物 |
| 拉 | 从特写退到全景("整个柜台,只有他一个人") | 揭示处境/孤独 |
| 摇 | 视线平移带出环境("窗外,收废品的三轮正经过") | 无缝带入时代/氛围 |
| 移 | 跟着动作走("他穿过晾衣绳下的小院") | 空间转换不掉镜头 |

## 通感纪律

通感(味觉写声音/触觉写光)每章≤1次,须落在情绪拍(紧张时的"声音发涩"),禁装饰性通感("铃声很甜")。

## 心理时间伸缩比

贴身挡的时间膨胀: 实际1秒可写100-200字(慢镜头),**每场限1次**——膨胀是燃的来源,滥用=拖。远景挡反向压缩:数日一句话带过。

## 心理-身体禁配档（十波批W8:全是"必配"方向,反向规则零字）

压抑角色/冷峻叙述/读者应先于角色察觉时: 身体泄漏但**角色不自察**("他没注意到自己的手在抖")——禁角色自报身体反应。这是"忍"的机械写法,与泪卡一级忍互链。

## 潜意识泄漏四通道（十波批W8:角色不自知的动机只有审计无处方）

角色自己不知道的动机靠泄漏呈现,叙述者永不说破: ①口误(说错称呼/说漏地名) ②重复小动作(总在摸那枚戒指) ③对特定物过度反应(一句闲话摔门) ④梦(克制使用,每卷≤1)。character-audit"不解释的破例"的写作侧入口。
