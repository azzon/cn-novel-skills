# Skill: dialogue-engine v3
# dialogue-engine:对话引擎（"先声后形"+"织毛衣"法）

> v2教训：纯对话堆到47%仍然不像真人——因为没有"织线"（对话间的叙述插入），读起来像剧本。
> v3核心：对话是毛线，叙述是针——**每织2-3针（对话），必须插1针（叙述）**。

## 五步流程

### Step 1｜对话骨架（同v2）
剧本态写骨架，每角色≥5轮，每轮20-50字。

### Step 2｜数数验收(每2-3轮台词插1段动作/环境/内心;连续纯对话>6轮=违例,check.py #33口径)
轮数/轮长/废话/打断/助词。

### Step 3｜叙述织线（v3核心修正）

**不是"填充"，是"织线"。** 每织2-3轮对话，必须插1条叙述线。

三类织线（轮换使用，不连续用同一种）：

| 织线类型 | 示例 | 单条长度 |
|---|---|---|
| **动作线** | 老许把烟换到另一只手 | 1句话 |
| **环境线** | 一辆公交车进站了。灰西装往前迈了半步，又退回 | 1-2句话 |
| **内心线** | 十万。马小丁的表情没变，但他的手在口袋里掐了一下大腿 | 1-2句话 |

**织线规则**：
- 每2-3轮对话必须插1条（最长连续对话≤5段）
- 动作线最优先（50%的织线应该是动作）
- 环境线用来标记时间流逝/空间变化
- 内心线最克制（每场景≤5处(千字≥2,含标记词+身体反应+条件联想)）
- 织线不超过2句话——长了就变回"叙述主体"

### Step 4｜配比实测
对话占比：**40-55%**（不是v2的55-70%——那是纯对话堆砌）
最长连续对话段：**≤5段**
叙述段落占比：**35-50%**

### Step 5｜节奏检查
读一遍：有没有"喘不过气"的段落（连续对话太多）？有没有"走神"的段落（连续叙述太长）？

## 与v2的区别

| 维度 | v2（错误） | v3（正确） |
|---|---|---|
| 对话目标 | 55-70% | **40-55%** |
| 叙述定位 | "胶水"（越少越好） | **"织线"（每2-3轮必插）** |
| 最长连续对话 | 无限制 | **≤5段** |
| 核心比喻 | 骨架+胶水 | **毛线+针** |
| 效果 | 剧本体 | **小说体** |

## 为什么"织毛衣"是对的

真人网文的节奏不是"对话越多越好"，是**对话和叙述的交织节奏**：
- 连续3轮对话 → 读者需要"看到"说话的人在做什么
- 连续5轮对话 → 读者忘记了场景，只听到声音
- 连续10轮对话 → 读者在阅读剧本，不是小说

**织线的功能**（不只是"打断对话"）：
1. **视觉锚定**：让读者"看见"说话的人（动作线）
2. **世界存在感**：让读者记得场景不是真空（环境线）
3. **情感深度**：让读者知道角色在想什么（内心线）
4. **节奏呼吸**：给读者消化的时间

## 织线示例（从v5提取）

```
对话: "看了多久了？"
对话: "一个月了吧。"
动作: 马小丁把最后一口包子塞进嘴里，顺手把包装纸团成一团。没找到垃圾桶，先塞口袋里了。
对话: "每天七点一刻来，站到八点，然后淡了。第二天又来。"

↑ 2轮对话 + 1条动作线 = 正确的织法
```

```
对话: "后来呢？"
动作: 老许比划了一个拧保温杯盖的动作。
对话: "打开一看，里面一个老太太的回响……"
环境: 一辆公交车进站了。灰西装的男人往前迈了半步，又停住，退回原地。
对话: "所以这次呢？"

↑ 2轮对话 + 动作线 + 1轮对话 + 环境线 = 呼吸感
```

## evals
- "写这个场景" → 先骨架，再织毛衣式上叙述线
- "对话太密了" → 检查连续对话是否>5段
- "读起来像剧本" → 织线不够，每2-3轮补1条动作线
- "节奏太平" → 检查三类织线是否轮换（不能全是动作线）

## 对话工艺深水区十条（2026-09-12工艺深研,详见story/audit/工艺深研-对话工艺深水区.md）
1.话到人到(每句先过"只有他这么说"关,老舍) 2.对话即行动(每轮交锋筹码/关系/信息任一变动,不变即删) 3.双重功能绑定(剧情推进由性格驱动,换人说剧情照样走=播音) 4.说A指B(谈钱时谈手艺,潜台词不念出) 5.情绪极点话变短变笨(Burroway:越激动句子越钝) 6.沉默与答非所问是牌 7.信息差点火(读者比在场者多半分底,每句客气话自动双层) 8.群戏设轴(一场一话题≤2人主谈,其余动作锚定) 9.接话要抢不要让(接话服务自己的目的) 10.信息付过路费(行话干货藏在交锋里释放,禁行情科普)。

## 讨价还价戏三段结构（修理行当专用模板）
①互探底:不谈价先谈"病",一句反问点破外行立声纹;压价试探不接话,低头拆件(动作截断=沉默牌)。②拉锯:报高价不辩解,转讲旧客贪便宜翻车的闲事(绕着说+恐吓性信息差);对方"别家才半价"(说A指B=我不信你);擦手答非所问抛新筹码;学徒/同行插话拆台逼摊牌(接话要抢)。③成交:张力峰值让步但让步方式显性格——"我让的是人情,不是价"(抹零头不降价);末句对方收钩("三天后来取,别自己拆")。

## 信息配额（红队20260919十波批W7:说三分藏七分无计量）

每场泄密≤1层(人物背景/事件真相按层拆);剧情级新信息全章直给≤1条,其余藏进动作与反应;禁"两人互相说对方已知的事"(设定伪装,check.py#7族)。对话推进=关系与立场变化,信息只是载体。

## 微观节奏（十波批W8:对话轮次等长=节拍器）

同场景连续3轮对白长度±20%内=机翻感——拆一轮插动作,或改半轮(被打断)。对话轮长短交替是"两个人在说话"的最强证据。

## 谈判戏/表白戏专项（场景型专项只有动作/审讯/群戏三型的补位）

- 谈判: 开价锚定(先喊的价定锚)/让步必换条件(白让=示弱)/僵局退场话术("那我再问问别家")——禁全靠喊价数字(报表对白#61)。
- 表白: 打断式(话说一半被打断,留下的半句最响)/借物式(托物不托词)/被拒后收台词(拒绝后不解释不纠缠,转身动作收场)——romance-line 5.3临界点收住的句法层。
