# Skill: duanzhang
# duanzhang:断章法（连续叙事流→按张力切割成章）

> 来源：用户指出的根本性问题——"每章都像单元剧，不连贯。真人大神是先写一个整体，然后按字数在合适位置拆成章节。"
> 此技能的目的：彻底改变写作工作流，从"按章写"变为"按叙事流写→再切"。

## ⛔ 核心范式转换

### 旧范式（错误，AI默认模式）
```
构思卷纲 → 拆成30章 → 逐章写 → 每章有起承转合 → 每章末尾留钩子
结果：138个独立短篇，串起来像单元剧
```

### 新范式（正确，真人大神模式）
```
构思卷纲 → 拆成3-5个"叙事段"(每段5-10章的内容) → 
按叙事段连续写作(不思考章节边界) → 
写完后找到叙事流中的张力峰值 → 
在张力峰值处切割 → 
切割点就是章末，下一章从切割点的下一秒无缝续写
结果：读者感觉在读一个连续的故事，只是偶尔翻页
```

## 三步工作流

### 第一步：写叙事段（5-10章的内容量）

**不要想"这是第几章"。只想"接下来发生了什么"。**

一个叙事段是一个连续的故事流：角色从A状态走到B状态，中间经历若干场景，情感和线索连续推进。

写叙事段时的纪律：
- 场景与场景之间不加"---"分隔符
- 不写章标题
- 不在任何一个"可能成为章末"的位置停下来思考"要不要在这里收"
- 时间推进用自然过渡（"天亮时""等他吃完饭""三日后"），不用章节式的"第二日"重新开局
- 情绪不重置——上一场愤怒，下一场还是愤怒的余波

### 第二步：找张力峰值

写完叙事段后，通读一遍，标出所有"张力峰值"——

张力峰值 = 读者最想知道"接下来呢？"的时刻

峰值类型（按强度排序）：
1. **即将揭晓却未揭晓**——真相就在嘴边
2. **角色做出选择但结果未知**——按钮已按下
3. **新信息刚出现但尚未消化**——角色还没反应过来
4. **危机达到顶点但未解决**——刀架在脖子上
5. **关系发生转折但未言明**——两人之间的话没说完

### 第三步：在峰值处切割

- 峰值处就是章末最后一行的位置
- 切得越突然越好——最好在对话中间切、在动作中间切
- 下一章第一行 = 切割点的下一秒，不重复、不概括、不"回顾上文"

## 断章五法（具体操作）

### 断法1：对话中断
```
第N章末尾：
"如果你敢——"
第N+1章开头：
枪响了。
```
在角色话说一半时切。下一章直接给结果，不重复那句没说完的话。

### 断法2：动作中断
```
第N章末尾：
他把钥匙插进锁孔。
第N+1章开头：
门开了。屋里比他想象的更乱。
```
在动作进行到一半时切。下一章直接给动作的结果。

### 断法3：信息中断
```
第N章末尾：
信封里只有一张纸。上面写着一个名字。
第N+1章开头：
那个名字他认识。
```
在信息即将揭示时切。下一章第一句就是揭示。

### 断法4：危机中断
```
第N章末尾：
门外的脚步声越来越近。
第N+1章开头：
脚步声停在了门口。
```
在危机逼近时切。下一章危机到位。

### 断法5：情感中断
```
第N章末尾：
他看着她，忽然想起三年前那个雪夜。
第N+1章开头：
"你不是他。"她说。
```
在情感即将爆发时切。下一章直接爆发。

## ⛔ 断章五禁

### 禁1：禁止在"事件完结"处断章
```
❌ ……案子结了。他走出衙门，天已经黑了。（事件完结，无张力）
✅ ……案子结了。但他知道，真正的主使还在外面。（有追问）
```

### 禁2：禁止在"情感宣泄完成"处断章
```
❌ ……他磕了三个头，站起来，心里终于平静了。（情感闭环）
✅ ……他磕了三个头。第三个头还没碰地，身后传来一声："不必了。"（情感被打断）
```

### 禁3：禁止在"角色独白/反思"处断章
```
❌ ……他想了很多。关于过去，关于未来，关于这条路。（内心独白完结）
✅ 他想着想着，忽然停住了。（内心被外部事件打断）
```

### 禁4：禁止在"新场景开场"处断章
```
❌ 下一章开头：第二日清晨，陈更来到了县衙。（时间/地点跳转=重新开始）
✅ 下一章开头：县衙的门槛比昨天高了一寸。（直接在场景里继续）
```

### 禁5：禁止在"所有线索收束"处断章
```
❌ 至此，三条线索全部汇合。真相大白了。（全收束=无事可期待）
✅ 三条线索中两条汇合了。第三条——最要紧的那条——断了。（留一个缺口）
```

## 🔧 跨章续写三法

### 续法1：状态延续（最常用）
上一章末尾角色在做什么/什么状态，下一章开头从那个状态的延续写起。
```
第N章末尾：他把手搭在秤杆上。秤杆动了一下。
第N+1章开头：秤杆归位的那一瞬间，守秤的老吏揉了揉眼睛。
```

### 续法2：对话延续
上一章末尾有人说了半句话，下一章开头从那句话的效果写起。
```
第N章末尾："如果你敢——"
第N+1章开头：枪响了。
```

### 续法3：情绪延续
上一章末尾的情绪，下一章开头继续。
```
第N章末尾：他站在碑前，雪落满肩头。
第N+1章开头：雪还在下。他已经站了两个时辰。
```

## ⚠️ 每章结束前的自检（三问）

1. **翻页测试**：读者读完最后一行，会不会不由自主地翻到下一页？如果这行可以是任何一章的结尾——FAIL。
2. **接力测试**：下一章的第一行，能不能无缝接上这章的最后一行？中间需要"重新定位"（我在哪？谁在说话？刚才发生了什么？）——FAIL。
3. **切割测试**：把最后一行删掉，故事的完整性有没有受损？如果没有受损——说明这行是"收尾"不是"断章"。FAIL。

## 与现有技能的关系

- **卷纲**：卷纲拆的不再是"章"而是"叙事段"（每段5-10章），段内不设章界
- **场景卡**：场景卡服务于"场景"，多个场景连续编号（不分章），章界在写完后才画
- **scene-draft**：叙事流中的场景衔接处，不重置情绪、不重设场景、不加过渡句
- **check.py**：#15章末总结腔+#64章内时间跳跃已机检;跨章断裂感无机检,靠reader-proxy冷读(单文件输入做不到跨章)
- **reader-proxy**：冷读时额外检查"翻页冲动"——读到章末最后一行，是否不由自主想翻页

## 实战示例

### ❌ 旧写法（单元剧式）
```
[第134章末尾]
文渊缓缓地说："从今夜起，这个天下的账，他坐了一方。"
→ 完整的对话回合，宣告式结尾，叙事节奏落地

[第135章开头]
坐账境的第一道令，陈更下给了漕运的河捐房。
→ 新章节新开始，直接跳到"下一件事"，前章情绪没有延续
```

### ✅ 新写法（连续流+切割）
```
[叙事流（不分行不设章界）连续写：]
文渊缓缓地说："从今夜起，这个天下的账，他坐了一方。"
护卫们面面相觑。
文渊拂袖进帐。走了两步，停下来。
"传令。"他头也不回。"撤围。"
清道队撤了。但陈更没有出大堂。他坐在原来的位置上，面前摆着三十六箱账册的清单。
窗外，天快亮了。
他拿起笔，在白纸上写下三个字：
"冻河。"
然后他叫来了河捐房的差役。

[找张力峰值切割：]
峰1：文渊说"撤围"之后（读者想知道：他真的放了吗？）
峰2：陈更写"冻河"之后（读者想知道：冻河是什么？会怎样？）
→ 峰2更强。在这里切。

[切割后标注章界：]
第一章末尾 = "本座只是承认。他坐了一方。"（张力点：文渊的表态）
第二章开头 = "清道队撤了。但陈更没有出大堂。"（零成本续读）
```
