# alt-takes:多方案盲选(写作域)

> 溯源:docs/26(成对比较>绝对分/锚定)·Agents' Room评估结论(排序可靠性)·风格包盲评实战。产物:胜出版+落选版归档(`text/备/`)。

## 前置条件

场景被判定为**关键场**(卷纲标记章王候选/名场面/用户指定);普通场景不进本流程。

## 流程

**1 定差异轴(先定再写)**
1.1 列2-3版各自的**差异点**(禁随机重roll):入口不同(晚进更晚)/节奏不同(快vs铺)/视角留白不同(写满vs留白)/侧重不同(动作vs潜台词);
1.2 每版差异登记一行——版本间无明确差异=盲选无意义,回1.1。

**2 生成**
2.1 同一张场景卡、同一风格包,按各版差异指令分别整文件生成;
2.2 各版独立过 check.py 卫生。

**3 匿名盲评**
3.1 打乱标号(A/B/C),交**干净上下文**代理:逐对比较+六维量规(引文要求同reader-proxy);
3.2 判定:明显胜出→取之;两版各有长短→给合并指令出第四版(半价重roll);
3.3 落选版归档不删(备将来变体回收)。

**4 入流**
胜出版照常走 scene-audit→ledger;盲评记录附入场景文件头(供复盘追溯决策依据)。

## 闸门

差异轴≥2且登记/版本均过卫生/盲评有引文/胜出依据明确。

## Next Step

`NEXT-SKILL: audit:scene-audit`(胜出版验收)。

## evals

- "这版不行换一版"(→查:关键场?差异轴是什么?)
- "两版都不错选哪个"(→盲评+可合并)
- "普通场景也来三版"(→拒,成本纪律)
