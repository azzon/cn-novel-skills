# 术语微词典(写作时唯一需要翻的"翻译器")

> 每个SKILL.md里的专有术语在此一行一句。未列的术语以docs/20-26为权威。

## 工艺术语
| 术语 | 一句话定义 | 反例(不要这样) |
|---|---|---|
| gloss/自我解释 | 作者跳出来解释自己造的词或规矩 | "编外的意思是:天曹的俸禄册上没有他"——直接写就行 |
| 预告片腔 | 用"至少看上去…"/"空处什么都没有"暗示后面有事 | 删——让后文自己揭示 |
| 自觉句 | "他知道,这不是结束,而是开始"式句子 | 全删 |
| 松段 | 只干活不抖机灵的段落,每场景至少1段 | 句句都想被截图 |
| 警句 | 可被截图传播的金句,每章≤2句(方差优先) | 每段结尾都是重音 |
| 情绪标注 | 用"愤怒/震惊"直标情绪 | 改为动作时长:"停了半拍" |
| 价值换极 | 场景开场信任→收场怀疑(或反向),不变=非事件 | 开场信收场也信 |
| 晚进早出 | 从冲突已开打处切入,在余韵最长处切出 | 写"你好请坐"式寒暄 |
| 三翻四抖 | 三拍立预期,第四拍打破(笑点结构) | 直接抖,铺垫不足 |
| 遮名可辨 | 遮住名字,三句话能认出是谁说的 | 人人说一样的完整长句 |
| 死穴/绝不说什么 | 每个角色一生不说的一句话,终局破一次 | 随便破,不值钱 |
| Pre/Post/Forbid | 本场前提(上文必须已成立)/后果(结束时世界的新状态)/禁态(不许发生的事) | 跳步骤,Post与前文Post矛盾 |

## 台账术语
| 术语 | 定义 |
|---|---|
| 六账 | 伏笔/梗/钩分布/类型轮换/人物状态/线弦 |
| 期待债 | 章末向读者许下但未兑现的期待(钩/承诺/预告) |
| 回访 | 受保人/受助人事后的谢礼——人心的长期回报 |
| 冰山三区 | 示区(首卷读者必知≤7件)/藏区(有暗示按卷解封)/永不区(作者知永不写) |

## 世界观术语(随项目定制)
| 术语 | 定义 |
|---|---|
| 愿文 | 契约双层中的第二层:没写出口的真心话,只有清瞳血脉可见 |
| 天契 | 天契司官方模板契约,只验契文不验愿文 |
