# 工艺载药包(6个核心技能的深度注入)

> 依据:终极审计1"工艺载药深度检验"——技能是流程壳还是工艺手册,取决于有没有这一层。
> 使用:每个SKILL.md尾部引用本文件对应节,写作/构思时按需读。

## 一、scene-draft:叙述工艺(含正面处方)

### 正面处方(与禁令同权重)
- 每段至少3个可触摸的具体名词(条凳/三联单/豁了沿的水缸),删"仿佛/某种/说不清的";
- 情绪一律改写成可计时的动作("停了半拍""把筷子摆正了两次");
- 从冲突已起处切入,寒暄与路程跳过;
- 叙述始终过主角头脑过滤,只写他此刻会注意到的;
- 每个beat展开=目标-受阻-应对-落点四拍,落点带身体感受,禁以"他感到"开头。

### 开场三式
| 式 | 做法 | 例 |
|---|---|---|
| 断言句 | 黄历/账本/规矩口吻一行定调 | "霜降后第三天,宜收租。" |
| 在场感 | 第一句让人物在做具体的事 | "他正蹲在门槛上挑灯芯" |
| 异常暗示 | 一件"不对"的小事吸引注意 | "香灰里多了一撮,凉的" |

### 反比喻处方(AI最顽固的病——一切工艺之前先治这个)
AI默认 = 每个描写点挂一个比喻("码得像牌位""像品茶""推着一整个早晨")——不是"有文笔",是用修辞密度掩盖观察空洞。真人:白描为主,动词名词扛活,比喻每章至多3处。
替换法(每个"像/仿佛/似的/像是"自问:删了还成立吗?成立就删):
- "二十七个铜板,码得像牌位"→"二十七个铜板。他数了三遍,没多出一个。"(动作比比喻有文笔)
- "石磨推着一整个早晨"→"斜对面在磨豆腐,石磨转得慢,声音也慢"(白描去拟人)
- "准得像一杆秤"→"三十年更声,分毫不差"(直接陈述比比较准)
- "像是想说什么"→"柳三娘在门口站了站"(留白让读者补)
规则:描写靠具体名词+准确动词+感官事实,不靠比较;人物内心用行为和对话流露,不用叙述者猜。

### 节奏控制
- 紧张段:短句但**不全是短句**——三短一长(三拍加速+一拍定画面):"他退了半步。手按在戒上。契刑官笑了。那笑容里有他三百年前的老主顾的脸。"——最后一拍是长句,做慢镜头。
- 平静段:逗号长句为主(整句20-30字),偶尔断一个短句做节拍锚:"柜台上摆着三样东西:算盘、愿簿、半块吃剩的炊饼。炊饼是凉的。"——最后四个字是锚。
- **禁全短**:连续≥6段≤8字=碎片化(check.py会报);**禁全长**:连续≥3句≥35字=催眠。

### 笑点施工(四步法)
1. 选型(docs/23十四型选一);
2. 铺垫(三翻四抖为标准拍——立预期三拍,第四拍破);
3. 放置(笑点词=全句最后一个词——之后零字零标点);
4. 收刀(抖完即停/换行/转场——**加任何解释都是自杀**);

### 潜台词三法
| 法 | 做法 | 例 |
|---|---|---|
| 答非所问 | 问A答B,B才是真答案 | "你恨他吗?"→"他做的面不错。" |
| 第三物说话 | 不直说,借物/借事 | 不说"我担心你",说"你走后我把你杯子洗了三遍" |
| 说到临界 | 话到最关键处被外部打断 | "其实我一直想告诉你——"(锣响/门撞/猫跳桌) |

### 展开四拍法(AI密度过高的处方)
每个beat展开为四拍(共150-250字):
1. **目标**:他此刻想干什么(一句);
2. **受阻**:什么拦了一下(物/人/自犹豫,一句);
3. **应对**:他怎么应对(动作+内心各一句);
4. **落点**:应对的结果+身体感受(一句,禁"他感到")。
> AI的压缩本能会把四拍压成一拍("他犹豫了大概两息")——**每拍至少一句,禁合并**。
写前在卡上填:目标(打到哪算完)/障碍(什么拦)/空间(三处可用地形写进第一拍)/代价(输赢各付什么)。写时:动词优先,形容退场;伤害要真(下一场带伤)。

## 二、style-compiler:锚样本提炼方法

### 特征分层清单(20条至少覆盖六层,每层至少2条)
| 层 | 提取什么 | 示范 |
|---|---|---|
| 词汇 | 高频名词域/禁词 | "他把状纸折成三折"=动作+具体物+身体位置 |
| 句法 | 句长均值与波动/开头词类 | 开头是动词还是名词决定节奏感 |
| 段落 | 段长分布/段尾功能 | 一段几句?段尾是笑点还是余韵? |
| 节奏 | 对话叙述比/留白位 | 什么位置留白?留多长? |
| 笑点 | 铺垫拍数/落点方式 | 补刀独立成段还是破折号? |
| 禁项 | 题材词不入卡只入句式 | "状纸"是题材词,不入风格卡 |

### 从锚样本提取什么(五维)
1. **节奏签名**:段落长度分布(几段1-2句/几段3-4句)/对话占比/短句率;
2. **笑点语法**:补刀怎么放(独立成段/破折号/另起一句)/铺垫几拍/抖后有无解释;
3. **叙述声**:断言句式?在场感?第一人称还是贴身三人?语气是冷是热?
4. **信息投放**:世界观怎么进入(对话/冲突/闲笔)?设定是"撞上"还是"讲解"?
5. **温差管理**:庄与谐怎么切换(一段内/一句内/前后夹)?切换有没有信号词?

### 提炼输出(格式)
```
签名:段落[1-2句占80%]|对话[45%]|短句率[20%]
笑点:补刀独立成段|三翻四抖|抖后零解释
叙述:贴身三人+断言开场+冷面
信息:对话/冲突进入|零讲解
温差:庄谐一段内切|信号="。"改"——"
```

## 三、char-bible:弧线链正反例(含Lie三检与因果链)

### Lie三检(判定这是不是好的谎)
1. 它曾救过他,所以他才信;
2. 第1章就驱动一个可见行为;
3. 终局事件能证伪它。

### 因果链检查
Ghost造Wound,Wound养Lie——倒推必通;不通=五条互不相干的标签。

### Ghost(往创)——不是"悲惨过去",是"他至今没走出去的那一天"
- ✓好:师父押匾夜他睡在柜台底下听了一夜——没敢出声(具体的夜+具体的没敢)
- ✗差:童年不幸(抽象,谁的Ghost不是童年不幸?)

### Wound(伤口)——不是"创伤事件",是"创伤后他做的那个选择"
- ✓好:第一次作保看走眼,他选择"以后要验得更细"——这个选择本身成了牢笼
- ✗差:被人背叛过(事件而非选择,没有锻造出行为模式)

### Lie(信的谎)——不是"错误的信念",是"他靠这个谎活到今天"
- ✓好:"只要验得够细,就不会再看错人"——这个谎让他从十四岁活到二十岁,有用,所以难破
- ✗差:他不信任任何人(太泛,没有操作性——验契语法从哪来?)

### Want vs Need的对位
- ✓好:Want=赎匾重开(外在,可量化);Need=学会信人(内在,终局才破)——**Want越具体越好(3000两),Need越晚破越好(最后一章)**
- ✗差:Want=变强;Need=变强但更成熟(同轴,没有张力)

## 四、premise:前提句工艺(含欲望疼三源与修复法)

### 欲望要疼的三源(至少占二)
1. 代价:得到即失去更在乎之物;
2. 期限:过某个具体时点就没了;
3. 身份冲突:与他的Lie同根。

### 修复法
自检不过按三源逐项加,不换题材。

### 好前提句的三要素
1. **具体动词**:不是"面对",是"赎回/押上/验到底"——动词本身带代价;
2. **双钩**:表面问题(能不能赎匾?)+深层问题(验到最后是他不敢碰的什么?)——两个钩子同时埋;
3. **一句话可转述**:陌生人听一遍能复述——复述不了=信息太密或太模糊。

### 差前提句的三宗罪
- 太抽象:"他要面对自己的命运"(谁的命运不是这个?)
- 太复杂:"当A遇到B时,他必须C才能D否则E"——超过一个从句就没人记得住
- 没代价:"他想变得更强"——不痛,不痛就没人想看

## 五、reader-proxy:冷读精度校准(含及优线)

### 及优线(四项全中判优)
追读欲大于等于8且能说出为看哪件事|跳读等于0|笑点至少1个想截图转发级|成对比较明显更想读。

### 标黄操作化
无硬线命中但四项全为压线通过=标黄;连续两章标黄暂停流水。

### 区分三档(不是"好/不好",是"哪里差多少")
| 档 | 特征 | 处方 |
|---|---|---|
| 及格线 | 通顺有画面,但**跳读率>15%或笑点<2** | 结构重排(不是文笔问题) |
| 良好 | 通顺有画面有笑点,但**"记不住"**(章末没钩/爽点不具象) | 场景卡钩字段重填(不是文字问题) |
| 优秀 | 上述+**"想转发"**(至少一处可截图/可复述) | 不改——这是锚样本候选 |

### 常见误判
- 读者说"无聊"→查社会模拟(人物关系网),不是查节奏
- 读者说"太慢"→查信息投放(设定讲解?),不是查句长
- 读者说"看不进去"→查视角(心理距离太远?),不是查文风

## 六、unit-designer:单元案工艺(含三层显影与凑件法)

### 三层显影点
表在案发当场可见;里在中段靠物证翻出;根在结案最后一拍由主角点破——揭层即转折。

### 根层镜子律
根愿必须照出主角自己的Lie——否则只有反转没有人味。

### 母题凑件法
母题+一件具体信物+一个期限+一个不情愿的中间人=四件齐才立案。

### 三层错位的"真"标准
- 表里差是**身份级**的(不是小误会):表"讨债"/里"怕自己一文不值"——差的不是信息,是自我认知
- 根愿是**本人不知道的**:他以为自己在讨债,其实是在讨亡者的认可——他自己不知道,读者通过破案知道
- 三层是**递进深挖**的:不是平行三件事,是一件事的三层洋葱

### 对抗四力的选型逻辑
| 力 | 适用场景 | 常见错误 |
|---|---|---|
| 制度 | 主线交锋(法规/垄断) | 制度太抽象,不落到"哪个衙门哪条律" |
| 人心 | 关系案(亲情/信任) | 人心太软,没有不可退让的底线 |
| 诡物 | 高潮前的硬仗 | 诡物太强,把智斗变武斗 |
| 同僚 | 行业内竞争 | 同僚太假,动机不清 |

## 动词轮换处方（红队20260919文笔上限批:泛动词淹死画面,check.py#67机器查>12/千字）

每个泛动词给3个市井替换例,写作现场即取即用:
| 泛动词 | 替换例 |
|---|---|
| 走 | 蹭/挪/晃/趿拉/一头扎 |
| 看 | 瞟/剜/打量/上下扫/眯眼瞅 |
| 说 | 嘟囔/嗫嚅/脆生生甩一句/从牙缝里挤 |
| 站 | 戳/杵/靠/扎在那/钉在门口 |
| 坐 | 墩/陷/蜷/一屁股坐实 |
| 拿 | 拢/捻/抄起/薅/攥 |
| 放 | 搁/撂/墩/码/扣 |
| 转头 | 扭脸/回身/偏过头/脖子一拧 |
规则: 每千字泛动词>12=WARN;替换词必须带身体性与器物性,禁换成更文的词(走→行走=越改越AI)。
