# revise:修订域编排器

> 溯源:docs/30。修订域铁律:**一切修订有指令(来自审计/冷读/用户),一切修订整文件重输出**。

## 路由表

| 症状/用户说什么 | 走哪里 |
|---|---|
| 差点意思/这句不对/微调 | line-polish(四轴) |
| 打回了/结构不对/卡改了 | scene-rewrite(须有修订指令) |
| 太薄/字数不够/某拍太快 | beat-expand(四类合法内容) |
| 太拖/有水/没人看 | tighten(三问删法) |
| AI味/太装 | 句级违例→line-polish;通篇腔调→de-ai(八类清除) |
| 不好笑/太贫/该认真没认真 | tone-shift(事件不变) |
| 对话不行/一个味/没潜台词 | dialogue-doctor |
| 整卷重排/删章并章 | arc-restructure(须审计依据) |

## 域闸门

1. **先审后修**:无审计处方/冷读结论/用户明示的修订不受理;
2. **归因唯一**:重写前先答"主因在卡还是在笔"(卡→回ideate/write改卡);
3. 回路上限:同场景修订两轮不过→上报卷纲层,禁无限重写;
4. 修订联动:凡涉钩/笑点/获得/伏笔变更→ops:ledger-update。

## Next Step

修订完成→`NEXT-SKILL: audit:scene-audit`(复验)。

## evals

- "帮我改"(→先问哪类症状再路由)
- "随便润润"(→拒无指令通润,四轴说清)
- "越改越糟"(→回路上限+归因唯一)
