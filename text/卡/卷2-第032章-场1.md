# 场景卡 卷2-第032章（回头客）
- **开场型**: 对话直入(王大龙:"哥,有个大姐在门口转三回了,不进来。";与031异常直入错型)
- **场景型**: 温情单元(还账章②)+新威胁亮样品
- **戏剧问题**：一部存着亡夫四十七条短信的手机，和一部什么都还没来得及存的全新手机——哪部更该买？
- **价值**:杜家媳妇"不敢换(旧机是遗物)"→收"换新(给妹妹买新机,旧机留念)"
- **beats**:①杜家媳妇带着亲妹妹来买机:妹妹县城上班第一部手机;王大龙招呼(900)|②添头机还账:马小丁取出台花机,屏终于配好,添头机屏配好,发件箱里的短信与没写完的半句"妞妞,姐可能……"——非卖品上柜(900)|③贴牌机首现:王大龙引新供货样品,双卡双待大喇叭,马小丁当场拆验MTK板;"这东西要淹了这条街"(700)|带2400-3000
- **Pre**:A-11/A-13添头机短信(章龄27,卷二必还);ch012杜家媳妇备份规矩;A-21山寨机样品(ch011);ch31承诺战
- **Post**:①A-11/13兑付:正典短信+未写完半句+添头机转非卖品(第三台不卖的机器) ②杜家妹妹购机(280元,人生第一部) ③贴牌机入柜(卷二主轴实物到场)
- **Forbid**:不写杜家媳妇哭;不写读短信煽乐(读信人平静,听的人静);不写贴牌机质量定论(只验板,不下结论)
- **钩**:叙述收(夜里他把贴牌机的螺丝按位置摆了一桌)
- **获得**:泪点兑付+新威胁实物+妹妹手机(人际获得)
- **笑点**: 王大龙"这机子咋没牌子?无印良品啊?"/"喇叭比我家电视响";杜家妹妹怼姐
- **声纹**: 杜家媳妇(平静短句)/妹妹(新社会青年腔)/王大龙(大嗓门)/马小丁(短)
- **知情状态**: 杜家媳妇不知添头机来历;妹妹不知姐夫已故细节全貌;王大龙不知短信内容
- **焦点**: ①两代短信的对照(未发出的/即将发出的) ②没写完的半句的分量 ③没牌子的机器=没名分的对手
- **章级**: 温情单元(平);A-11/13兑付;卷二主轴实物到场
- **数字表**: 妹妹手机280元/贴牌机供货价300/添头机非卖品/杜家媳妇旧机内存条短信47+1(自己存的)
- **承接**: 上章末红纸承诺战——本章开头转温情,节奏回平(漂移3期令)
- **生活层**: 细节×3(妹妹的新工作证还别在胸前/添头机屏换的新屏膜没撕/贴牌机后盖用手一按咯吱响)+感官(大喇叭放《两只蝴蝶》震耳朵/新机塑料味/粥的热气)+慢拍(读信逐字降速)+私货(马小丁把螺丝按位置摆一桌回收)+家常(姐妹俩为谁付钱推让)
- **失败/意外**: 马小丁本想直接送妹妹手机,杜家媳妇坚持付钱(人情账的规矩)
- **时代锚**: 双卡双待/大喇叭山寨机/《两只蝴蝶》(≤2)
