# 10-世界/文化

## 称谓体系

| 身份 | 官称 | 私下/蔑称 |
|---|---|---|
| 送行者 | 送行先生/女士 | "跑堂的"（给死人跑腿） |
| 收集者 | （非法，无官称） | "罐子"（装死人的罐子） |
| 驯响师 | 驯响官 | "温度计"（只会量温度） |
| 猎响者 | （非法） | "钓鬼的" |
| 回响 | "逝者"（官方尊称） | "凉货"（黑市术语） |
| 完整回响(37.2°C) | "恒温者" | "热人" |
| 亲和体 | "共鸣者" | 实验体编号 |

## 禁忌

| 禁忌 | 犯了会怎样 |
|---|---|
| 对回响说"你已经死了" | 高阶回响会暴走（人格被否定会引发记忆雪崩） |
| 触碰37.2°C回响未经允许 | 相当于对活人的性骚扰（有完整人格，有身体自主权） |
| 在回廊巷大声说话 | 会加速回响衰变（情绪波动对回响有害） |
| 拿温度计指人 | 极度侮辱（暗示对方"快死了"或"不是活人"） |

## 节令

| 节 | 时间 | 内容 |
|---|---|---|
| 暖灯节 | 冬至 | 给游荡的回响放温水灯——"让它们暖暖" |
| 逝者日 | 清明 | 全城温度下降1度（回响集中出来的日子） |
| 恒温纪念日 | 未知日期 | 纪念第一个被发现的37.2°C回响（日期是它生前的生日） |

## 语言分层

**官方语**：规范、冷、不带感情。
- "该逝者已确认为低阶回响，温度+2度，建议进行标准处理程序。"

**市井语**：温度比喻多、形象。
- "巷子口那个又来了，转了一晚上，看着都替他累。"
- "你可别惹那个，温度高得很，不好惹。"

**黑市语**：隐晦、代号。
- "新到一批凉的，要吗？"
- "有个热的，但不好动。"

## 礼俗之争

1. **回响权利之争**：完整回响（37.2°C）是否应享有"准人权"？官方尚未立法，但民间已有"恒温者保护协会"。反对者认为"死的就是死的"。
2. **送走 vs 收集的道德之争**：送行者认为收集者是"囚禁死者的变态"；收集者认为送行者是"给屠宰场送肉的帮凶"（讽刺的是，收集者说对了）。
