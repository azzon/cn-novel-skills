# 50-风格包 v2：《回响》真人网文风格（推翻v1重写）

> v1的根本错误：用"文学短篇"的压缩美学写网文。v2彻底推翻。
> 核心认知：网文是让读者"住在角色的世界里"，不是"观察角色的电影"。

## 十条写作法则（违反任何一条=重写）

### 1. 对话是引擎，占50-60%
每章至少一半篇幅是对话。角色必须开口说话，大量说话。叙述只做串联。

### 2. 角色会啰嗦
正常人说话不是"言简意赅"的。他们会解释、重复、跑题、说废话。一个老手讲案子不会只说"回响绑架案"四个字——他会从头讲起，中间插入自己的看法，跑题讲一个旧案例，再拉回来。

### 3. 内心独白是聊天的
不是诗意的沉思。是自言自语式的："这他妈什么情况？干这行五年了没见过这种事。不对，等一下，上个月那个案子……算了，不想了，先吃饭。"

### 4. 每章有"无关剧情"的内容
角色要吃饭、要抱怨交通、要八卦同事、要说不好笑的笑话。这些"废话"是让读者觉得"这些人活在一个真实世界里"的关键。删掉全部废话=删掉生活气。

### 5. 角色会犯蠢、会误解
正常人不会每句话都精准。他们会听错、会误解、会做出错误判断然后被纠正。这种"人的毛边"比完美的对话更真实。

### 6. 解释通过对话自然发生
不是"禁止解释"——是禁止叙述者解释。角色之间的对话可以解释设定，而且应该解释，因为一个新人和一个老手的对话天然就是"一个人问一个人答"。

### 7. 描述是实用的不是审美的
不说"夕阳把影子拉得很长"。说"下午四点，太阳快下山了，他得赶紧，晚了管理所就关门了。"描述为行动服务，不为氛围服务。

### 8. 章末要"让人想翻页"不是"让人回味"
钩子是悬念、是期待、是"卧槽接下来会怎样"。不是文学性的留白。

### 9. 每章2500-3500字
低于2000字读者觉得亏。1000字是"大纲"不是"章节"。

### 10. 温度意象降到每章1-2次
v1的问题是温度无处不在。好的意象是稀缺的——用多了就变成tic。大部分时候不提温度，只在关键时刻用一次，才有冲击力。

## 范例对照

### ❌ v1的写法（文学压缩型）
```
"什么？"
"回响绑架案。富商的老婆，死了三年，回响一直好好的待在家里。昨晚被人端了。"
```

### ✅ v2的写法（真人网文型）
```
"什么玩意儿？"陈默把暖宝宝撕开，隔著裤子贴在大腿上。昨晚干活留下的凉气还没散干净，这会儿有了热度才觉得腿是自己的。

"回响绑架。"老许把烟叼上，又没点——他在管理所里从来不点，说是怕引回响，但陈默觉得他就是抠，舍不得那几块钱打火机的油。"就是你理解的那个意思。有人把回响当东西给绑走了。"

"……回响也能绑？"

"你问我？"老许的眉毛挑得很高，那个表情陈默太熟了——每次老许做这个表情，接下来肯定要说一段很长的话。"我干了三十年，什么怪事没见过？前年有一个案子，回响被人装在保温杯里带上了高铁——你别笑，真事——安检的时候温度计都响了，那哥们儿跟安检员说是保温杯里装的热粥。热粥！三十七度的热粥！安检员又不是傻的——"

"所以这次呢？"

"这次更离谱。"老许终于把烟从嘴上拿下来，在手指间转了两圈。"富商的老婆，死了三年了，回响一直待在家里好好的，每天晚上雷打不动地打开衣柜穿衣服照镜子。富商嫌烦，找过三个道士——"

"道士？"

"你别打断我。三个道士，一分钱没少花，屁用没有。最后不知道谁跟他说的，找我们管理所。管理所说什么？管理所说这不归我们管，回响没扰民没伤人，人家在自己家里穿衣服照镜子碍着谁了？"

"那怎么又归我们管了？"

"因为昨晚回响被人绑了。"老许压低了声音。"绑匪留了话。"

"要钱？"

"不要钱。"
```

## v2的检测标准

| 指标 | 标准 |
|---|---|
| 对话占比 | 45-60% |
| 对话轮次 | ≥30轮/章 |
| 均轮长度 | ≥20字 |
| 最长单轮 | ≥80字 |
| 章字数 | 2500-3500 |
| "废话"率 | 15-25%（非功能性对话）|
| 温度意象 | ≤2次/章 |
