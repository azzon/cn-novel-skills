# 声纹卡（写作时注入用·每张卡写对话前必须贴在场景卡旁边）

> 使用方法：写任何角色的对话前，把该角色的声纹卡复制到场景卡旁边。生成对话时逐条对照。如果生成的对话不符合声纹卡的特征，立即重写。

---

## 陈更（主角·账房掌柜）

```
【句长】8-15字为主。越紧张越短。激动时反而更冷静更精确。
【句式】陈述句→省略主语的判断句。极少疑问句。偶尔反问。
【口头禅】"这笔记上了。"（重大事项时）/ "先小人后君子。"（谈判时）
【必用词】账/契/凭/据/利/本/核/验/秤/数（数目必精确：四十六文，不是几十文）
【禁用词】大概、差不多、算了、可能、也许、无所谓
【情绪表达】不说"我很生气"。说"这笔记上了"然后声音更低。
【独有动作】说话时拨算盘或摸左手食指的茧。
【反模式】如果陈更说出文雅的长句、感叹句、情绪化的话→写错了。
```

## 闻人霜（女主·巡按）

```
【句长】5-12字。极短。像在念条款。
【句式】先引法条后说结论。用"按X条第X款"开头。几乎不用感叹号。
【口头禅】"核三遍。"（工作状态）/ "录。"（确认笔录时）
【必用词】律/条/款/章程/程序/案卷/堂/验/复核/存照
【禁用词】可能、也许、大概、我觉得、感觉、好像
【情绪表达】不说"我很难过"。说"核三遍之后"然后沉默。
【独有动作】说话前先抿一下嘴角（把官腔抿掉再说话）。
【反模式】如果闻人霜说长句、用语气词（啊/呢/吧）、或表现犹豫→写错了。
```

## 樊大（挚友·屠户·武力）

```
【句长】3-8字。极短。经常重复。带排比。
【句式】祈使句和感叹句为主。"上！""干！""揍他！"几乎不用问句。
【口头禅】"更子，上不上？我头前开路。"（战时）/ "记什么账！送你的！"（对陈更）
【必用词】肉/吃/杀/打/揍/力气/腿/刀/娘/干/他娘的（可 用于发泄非脏话）
【禁用词】文雅词（可谓/然也/诚如）、数目字（记不住账）、官面话
【情绪表达】不说"我很愤怒"。说"揍他！"然后真去揍。
【独有动作】说话前先撸袖子。激动时拍大腿。
【反模式】如果樊大说出文雅的长句、引用律条、或算账→写错了。
```

## 墨鸦（执笔候补·冷面）

```
【句长】4-10字。短平。省主语。冷。
【句式】陈述句和条件句。"如果…就…。""既然…那么…"。很少反问。
【口头禅】前期"奉谕行事。"→后期"……为什么？"
【必用词】奉/谕/查/看/记/影/签/线/六层/楼里
【禁用词】情绪词（高兴/难过/害怕）、感叹词、口语化表达（咱们/啥/咋）
【情绪表达】不说"我很纠结"。说"……"然后沉默，或问"为什么？"
【独有动作】说话时看别处不看人。
【反模式】如果墨鸦说长句、用感叹号、或主动表达情感→写错了。
```

---

## 文渊（文曲先生·销籍总管·中期反派）

```
【句长】10-25字。长。文雅。绵里藏针。
【句式】设问+自答。引经据典。表面客气实际威胁。
【口头禅】"后生可畏。"（每次见到陈更）/ "老夫……"（自称）
【必用词】本座/文脉/正道/祖师/笔/墨/纸/砚/斯文/可惜/弯路
【禁用词】粗话、直接威胁（他从不直接威胁，都是"劝"）
【情绪表达】不表现愤怒。笑容不变但眼神变冷。说"可惜"代替"你完了"。
【独有动作】说话时捻玉念珠。念珠转得越快越危险。
【反模式】如果文渊直接威胁人、说粗话、或失去冷静→写错了。
```

---

## 钱通宝（总号副掌柜·假盟友→真盟友）

```
【句长】10-20字。长。绕。先笑三声再报价。
【句式】"哎呀呀""小可""贤弟"开头。先寒暄后谈钱。
【口头禅】"这单，有的赚。"（真话时的口头禅）/ "小可"（自称）
【必用词】赚/亏/抽成/行情/行价/三成/利钱/盘子/做买卖
【禁用词】真数（报价永远虚三成）、承诺（从不给准话）
【情绪表达】不直接表现紧张。笑声变大=心虚。开始报价=在算计。
【独有动作】说重要的话之前先笑三声。
【反模式】如果钱通宝直接说实话、不绕弯子、或报价说真数→要么他在撒谎，要么他在做重大决定。
```

## 声纹对比速查（写对话时对照检查）

| 维度 | 陈更 | 闻人霜 | 樊大 | 墨鸦 | 文渊 | 钱通宝 |
|---|---|---|---|---|---|---|
| 句长 | 短(8-15) | 极短(5-12) | 极短(3-8) | 短平(4-10) | 长(10-25) | 长绕(10-20) |
| 语气 | 冷静精确 | 条款冷硬 | 粗犷直接 | 冰冷省略 | 绵里藏针 | 热络市侩 |
| 开口方式 | 报数字 | 引律条 | 喊人 | 省主语 | 先笑三声 | 先寒暄 |
| 情绪表达 | 更冷静 | 沉默 | 拍桌吼 | 停顿 | 笑容加深 | 笑声变大 |
| 绝不说 | 差不多 | 也许 | 请/谢谢 | 我怕 | 你完了 | 真数 |
```

## 使用示例：同一场戏，四种写法

**场景：发现一页假账**

❌ 错误写法（所有人一个腔调）：
> 陈更说："这本账有问题。" 闻人霜说："确实有问题。" 樊大说："什么问题？" 墨鸦说："问题很大。"

✅ 正确写法（各有各的腔调）：
> 陈更把账册翻到第七十三页，手指按住。"利息不对。月息二分，滚了三年，应该是十九两五。这里写的是二十六两四。"
> 
> 闻人霜凑过来看了一眼。"第六款。虚立利息者，债主反坐。核三遍。"
> 
> "核什么核！"樊大凑过来瞄了一眼，"假的！一看就是假的！这字歪的！"
> 
> 墨鸦没有看账。他在看账房先生的脸。"他的手在抖。"他说。"做贼的人，手才会抖。"
