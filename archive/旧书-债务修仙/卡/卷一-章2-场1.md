# 场景卡·卷一-章2-场1（吃面·市井晨）

- 领卡：卷一纲第2章①（日常喜剧/轻/质感）。
- **戏剧问题**：三日倒计时第一天的早饭，能吃出这个镇子的世道吗？
- **价值**：开"个人丧期（独）"→收"公共恶政浮出（米行收粮）"——由私入世✓。
- **攻防**：他要一文钱把早饭吃得体面 vs 面馆里满堂都是"卖粮还是饿着"的恐慌。
- **beats**：①吃面（450字：一文钱葱的奢侈/脚跟步进场/掌柜的赊账规矩）②满堂愁（500字：米行收粮的传闻四起/更夫的"口头讨债"夜闻/说书腔的民间信源）③离店（150字：他头顶看了一眼掌柜的——掌柜的也欠着米行的账，薄的；走出门口听见佃户张老栓被逼债的信儿）。**总字数带：1050-1300。**
- **有代价的选择**：他只买了一文钱葱——把仅剩的钱留着"作保用"（读者后知）。
- **晚进点**：从"面馆"进，不写起床。**早出点**：停在"张老栓"三个字入耳那一拍。
- **喜剧**：主型：降格双拍（赊账规矩的讲究）；目标≥2；callback："一文钱葱"（终章回收）。
- **钩**：轻（张老栓其人其事）。
- **获得**：信息（米行收粮+张老栓被逼）。
- **Pre**：悬账已立（章1）**Post**：卷入米行事的前厅戏落幕。**Forbid**：不写米行老爷出场；不写垫付决定（章末场2的事）。
- **声纹**：陈更（点菜报价式）；面馆掌柜（市井+忌讳：不说"欠"字说"挂"）；更夫（夜行的权威腔）。
- **知情**：镇民知：米行收粮；不知：陈更的三日限期与悬账。
- 自检：换极✓攻防✓删了塌（世界质感主场+张老栓引线）✓。

# 场景卡·卷一-章2-场2（救人·放话）

- 领卡：卷一纲第2章②（动作/中钩/地位）。
- **戏剧问题**：一个没有资质的学徒，敢不敢当众接下米行的债？
- **价值**：开"恶行畅通（无人敢拦）"→收"有人接招（三日之约立）"——换极✓。
- **攻防**：他验契放话 vs 米行管事的势压（+围观者的劝退声浪）。
- **beats**：①逼债现场（500字：打手搬粮/张老栓悬梁被救/管事的算盘——利滚三滚的阴阳契亮出）②验契（600字：他当众念出利息破绽——"利滚了三滚，这契是假的"，账眼验契全亮相/管事变脸）③放话（400字："三日，我替张老栓把这十两收回来"+管事的撂话+围观者喷他不自量力）。**总字数带：1450-1750。**
- **有代价的选择**：他可以只把人救下来不接契——接了，就是跟米行对上。他接了：付的是"三日办不到就身败名裂"。
- **晚进点**：从"打手搬粮"的动静进。**早出点**：停在他放下定钱（一文钱葱省下的钱押在桌上）那一拍——不写回家。
- **喜剧**：主型：错位（救命与算账同时进行）；目标≥2。
- **钩**：中（管事的冷笑"三日之后，连人带铺，我一起收"）。
- **获得**：地位（三日之约公开立）+信息（阴阳契实物到手——抄本）。
- **Pre**：张老栓其人已在场1入耳。**Post**：全镇知道陈更跟米行杠上了；阴阳契副本在他手里。**Forbid**：不开账（垫寿开账是第6章）；贵三仓本人不出场（管事代之）；不揭阴阳契背后官坊墨（第3章）。
- **声纹**：陈更（先报价）；管事（算盘腔+假客气）；张老栓（哭腔碎片）；围观者（起哄与劝退双声部）。
- **知情**：全镇新增知：陈更接了米行的债。
- 自检：✓✓✓。
