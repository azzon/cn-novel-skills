# 人物圣经(1998租碟店)

## 一、恒定层
### 许太平(主角,26)
- 生理: 173cm,瘦,常年熬夜的脸,笑起来有酒窝(妈说像外公)
- 社会: 1972年生,湖南衡阳人,华强北装机档口打工两年,攒8000;单身;父许建国(衡阳机床厂下岗钳工)/母李秀珍(纺织厂)
- 心理: 上辈子(1998流水线→2005网吧老板→2020倒闭→外卖→2023年51岁猝死)卷怕了;这辈子信条"够用就好";对钱迟钝对人情极准
### 欲望引擎四件套
1. **ghost**: 2023年猝死当夜,手机里父亲最后一通未接来电(2019年父亲病危他在改方案——两世同一场遗憾)
2. **wound**: 过劳+子欲养而亲不待;上辈子攒的钱全给了医院和房东
3. **lie**: "钱够用就好,不用争"——真相: 他不是不争,是怕再次输不起;躺是逃避不是满足
4. **want**: 守住小店,准点关门,接爸妈来深圳
5. **need**: 学会主动守护——躺是姿态,该出手时(有人动他想守的东西)必须出手(每卷一"认真章"即need显影)
### 压力反应模式
- 被逼赚钱→装傻+"瞎蒙的";被戳中父母→瞬间认真(反差名场面源);遇危险→先算退路
### 对手引擎(躺赢流: 麻烦制造者非宿敌)
- 卷一: 二房东表侄"赖皮强"(想收铺面转手)/市井泼皮级,威胁=收回铺面
- 卷二: 连锁音像店(正规军压价)/威胁=小店生存
- 长线: "为什么他总能踩对点"的窥探者(记者/税务/旧同事),麻烦即地位证明
