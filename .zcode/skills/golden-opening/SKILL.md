# golden-opening:黄金开篇（前500字=生死线）

> 来源：红队13审计——前500字内容真空与47%流失完全重合。金手指在63%处亮相、第一个爽点在70%处、前1600字零幽默——这些全是致命伤。

## ⛔ 前500字硬性指标（不达标=重写）

| 指标 | 要求 | 检测 |
|---|---|---|
| 悬念出现 | ≤第30字 | 第一句就有"不对劲" |
| 金手指亮相 | ≤第500字 | 或至少预示 |
| 第一个事件 | ≤第300字 | 有人敲门/有话被说 |
| 专有名词 | ≤3个 | 硬名词不超过3 |
| 数字噪音 | ≤2个金额 | 不堆数字 |

## 开篇三式（选一）

### 式1：异常暗示（最推荐）
第一句就是一件"不对"的小事。
```
✅ 香灰里多了一撮，凉的。
✅ 灯芯结了花。师父说过，灯花报账。可师父已经死了七天。
```

### 式2：断言句+在场感
黄历/账本/规矩口吻一行定调。
```
✅ 三月初九，宜安葬，不宜讨债。
```

### 式3：动作中进入
第一句让人物在做具体的事（有 stakes 的事）。
```
✅ 他把"死因：劫财"写完，笔尖悬着。然后添了两个字：存疑。
```

## 禁项

- 禁以纯环境描写开篇超过3行
- 禁以回忆/闪回开篇
- 禁第一句对话出现在第950字之后
- 禁前500字只有氛围没有事件
- 禁三章结尾形状同构（都是"夜里挑灯沉思"式收束）
