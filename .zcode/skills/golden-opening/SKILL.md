# Skill: golden-opening
# golden-opening:黄金开篇（前500字=生死线）

> 来源：红队13审计——前500字内容真空与47%流失完全重合。金手指在63%处亮相、第一个爽点在70%处、前1600字零幽默——这些全是致命伤。

**与opening-arc分工**：opening-arc管黄金三章的结构设计（排纲期）；本技能管前三章成稿的前500字硬指标（写作期）。用户说"前三章/开头不行"时先判断要结构设计还是成稿打磨。

## ⛔ 前500字硬性指标（不达标=重写）

| 指标 | 要求 | 检测 |
|---|---|---|
| 悬念出现 | ≤第30字 | 第一句就有"不对劲" |
| 金手指亮相 | ≤第500字 | 或至少预示 |
| 第一个事件 | ≤第300字 | 有人敲门/有话被说 |
| 专有名词 | ≤3个 | 硬名词不超过3 |
| 数字噪音 | ≤2个金额 | 不堆数字 |

## 开篇三式（选一）

### 式1：异常暗示（最推荐）
第一句就是一件"不对"的小事。
```
✅ 香灰里多了一撮，凉的。
✅ 灯芯结了花。师父说过，灯花报账。可师父已经死了七天。
```

### 式2：断言句+在场感
黄历/账本/规矩口吻一行定调。（此式属**判断句开场型**——卡上开场型填判断句，勿填时间状语；大审计-19）
```
✅ 三月初九，宜安葬，不宜讨债。
```

### 式3：动作中进入
第一句让人物在做具体的事（有 stakes 的事）。
```
✅ 他把"死因：劫财"写完，笔尖悬着。然后添了两个字：存疑。
```

## 禁项

- 禁以纯环境描写开篇超过3行
- 禁以回忆/闪回开篇
- 禁第一句对话出现在第950字之后
- 禁前500字只有氛围没有事件
- 禁三章结尾形状同构（都是"夜里挑灯沉思"式收束）

## 开场型四选一（大审计-19沉淀）
本技能所有式子按开场型归口：式1/式3=异常直入或动作直入；式2=判断句。场景卡"开场型"字段四选一（对话直入|动作直入|异常直入|判断句），禁时间状语长叙述段（>20字由G9机器门拦截），且须与前两章错型。
