# Skill: author-persona
# author-persona:作者人格卡（本书的"灵魂发生器"）

> 来源：红队D审计——"全库没有任何一处回答'这个假想作者是谁、他写这本书想证明什么、他会在哪夹私货'。"
> 白金作品的灵魂 = 作者的人格 + 执念 + 私货。本技能在立项时生成，每卷排纲时重读。

## 生成时机

与风格包并行生成。风格包管"怎么写"，作者人格管"为什么写"和"在哪发光"。

## 作者人格卡模板

```
【作者人格卡：《天道讨债人》】

## 如果本书是一个真人写的，他是谁？
一个三十多岁的男人。会计出身，做过审计，见过太多账目里的冤屈。
辞职写书是因为——他见过一个老出纳，替公司背了二十年的黑账，退休那天才知道真相。
他写这本书，是想替那个老出纳——和所有背了黑账的人——讨一个说法。

## 他的执念是什么？
"欠下的，终须偿还。"他信这个。信到骨子里。
他不信道德说教，他信制度。他觉得好的制度比好人更可靠。
但他也知道制度会腐坏——所以他写了陈更，一个在腐坏制度里用制度本身战斗的人。

## 他最得意的私货是什么？
- 账房行话。他真的懂会计，每一条账目他都算过。读者以为他在编，其实都是真的。
- 小人物的一碗面。他写不好大场面后的庆功宴，但他能写好一个刚讨完债的人吃的那碗面。
- 老男人的沉默。他笔下的师徒、父子、君臣，都不善于说爱，但会用行动。

## 他会在哪夹私货？
- 每卷至少一个"账房冷幽默"——只有懂行的人才会笑
- 每卷至少一次"一碗面/一盏灯/一面锣"式的物件仪式
- 师徒线里夹他对自己师父的怀念
- 感情线里夹他对自己妻子的亏欠（异地工作那几年）

## 他绝不会做什么？
- 绝不写后宫。他觉得那是没用的人才干的事。
- 绝不让主角不劳而获。每一分收获必须有代价。
- 绝不在关键剧情开玩笑。该严肃的时候绝不贫嘴。
- 绝不烂尾。哪怕写不动了，也要给读者一个交代。

## 他在写这本书时最怕什么？
怕读者说"设定好看但人物没温度"。
所以每写三章，他会回头问自己：陈更这小子，我有没有让他像个人？
不是像主角，是像个人。会累、会怕、会在深夜想娘。
```

## 使用方式

### 立项时
与premise并行，生成作者人格卡，存入 `story/50-作者人格卡.md`

### 每卷排纲时
重读一遍，问三个问题：
1. 这一卷他会在哪夹私货？
2. 这一卷有没有"只有他会写"的场面？
3. 这一卷的感情线，他写得下去吗？（写不下去说明感情不够真）

### 每卷完稿后
自由文本记录：
- 哪几章越写越费劲？（费劲感=可能的漂移预警）
- 哪几章写哭了/写笑了？（这些是灵魂锚点）
- 下一卷他想怎么写？

## 与其他技能的关系

- **writing-heart**：灵魂层的"什么是灵魂"，本技能是"灵魂从哪来"
- **style-compiler**：风格包管声音，作者人格管心跳
- **卷纲**：每卷排纲前必读本卡
- **scene-draft**：写重点章前问"他在这一章最想写什么"

## 最后

**风格让你像谁。人格让你是你。**
读者追300章，追的不是文笔，是"这个作者我信"。
