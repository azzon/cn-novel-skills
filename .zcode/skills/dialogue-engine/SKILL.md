# Skill: dialogue-engine
# dialogue-engine:对话优先生成引擎

> 溯源：三轮审计发现AI生成长文天然偏向"叙述→插入对话"，导致对话占比只有20-30%。本技能强制翻转生成顺序。

## ⛔ 核心翻转

```
错误顺序（AI默认）：     正确顺序（白金作家）：
─────────────        ─────────────
1. 想场景氛围           1. 想这场景里谁在跟谁说什么
2. 写环境描写           2. 写出完整对话（像剧本）
3. 插入对话             3. 在对话之间填最少量的叙述
4. 补动作标签           4. 加动作标签（不用"说道"）
                       5. 检查：叙述是否吃掉了对话比例
```

## 第一步：对话骨架

**不带任何叙述，只写角色名+台词。像剧本一样。**

规则：
- 每个出场角色至少5轮发言
- 每轮20-50字（一小段话，不是一句话）
- 至少2次跑题/废话（角色扯到无关的事再拉回来）
- 至少1次打断/抢话（用"——"或换人说话截断）
- 语气助词自然出现（呢/吧/啊/嘛/呗/呀/哦/嗯）
- 问句不超过40%（角色不是提问机）

### 骨架示例

```
老许：你又在看那个？
陈默：嗯，看了一个月了。
老许：你知道他是谁不？
陈默：不知道啊，看着像坐办公室的。
老许：上个月刚死的。心脏病，就死在这个站台。等车等死的。你说这叫什么事儿，坐了八年公交车，最后死在等车的时候。他家里人——老婆跟他离婚了，爸妈在外地，通知了，没来。
陈默：没人管？
老许：没人管。他就这样每天来等车。
    [跑题] 我跟你说，现在这些家属啊，十个有九个是这样的。上上个月城西有一个，老太太的回响在菜市场转了三个月，儿女就在同一个小区住着，愣是一次没来看过。最后还是菜市场卖豆腐的给报的案——你说卖豆腐的都比亲儿女上心，这叫什么世道？
    [拉回来] 咳，扯远了。你要送他走？
陈默：他没找我。
老许：回响不会找人，回响就会重复。你要是闲得慌就自己过去。
陈默：我不闲，我穷。
老许：[笑] 说到穷——有个活儿。
```

## 第二步：叙述填充

在对话之间加叙述，但**每条叙述不超过2句**。

规则：
- 动作标签优于"说道"（"老许把烟转了两圈"不用"老许说道"）
- 内心独白用口语（"十万。他掐了一下大腿"不用"他感到激动"）
- 场景描述一句带过（"公交站台"不用三行描写）
- 纯氛围段落全删

### 填充示例

```
老许：你又在看那个？
                        ← 不填（对话自足）
陈默：嗯，看了一个月了。
                        ← 陈默把最后一口包子塞进嘴里。
老许：你知道他是谁不？
                        ← 不填
陈默：不知道啊，看着像坐办公室的。
                        ← 不填
老许：上个月刚死的。心脏病……
                        ← 老许从口袋里掏出一根烟。没点。
    [老许的长段] ……没来。
陈默：没人管？
                        ← 陈默把包子纸团成一团，没找到垃圾桶，塞口袋里了。
老许：没人管。……
    [跑题段]
    [拉回来] 咳，扯远了。你要送他走？
```

## 第三步：比例检查

填充完后，数一遍：
- 对话占比是否≥45%？低于→回去删叙述
- 叙述段是否每条≤2句？超过→拆分或删减
- 是否有连续3段以上纯叙述？有→插入对话打断

## 与其他技能的关系

- **scene-draft**：本技能替代其生成顺序（对话骨架优先于场景描述）
- **scene-card**：beats字段改为"对话骨架大纲"
- **scene-discipline**：四条铁律不变，但增加"叙述不吃对话"原则
- **check.py**：对话质量评分器检测本技能的输出

## evals

- "写这个场景" → 先产出对话骨架，再填叙述
- "对话太少了" → 检查是否先生成了叙述、后插的对话（顺序错了）
- "怎么让角色多说话" → 用骨架法：先写完所有对话，再想叙述
