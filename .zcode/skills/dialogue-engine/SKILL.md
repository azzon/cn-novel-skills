# Skill: dialogue-engine v2
# dialogue-engine:对话优先生成引擎（"先声后形"法）

> 溯源：三轮审计+50轮骨架实测。核心机制翻转：AI自回归续写的开头200字文体态会锁死后面2000字——骨架先写，续写默认态就是"你一句我一句"。

## 为什么翻转在机制上有效

1. **默认态翻转**：骨架先写→模型的续写默认态是对话，叙述成了打断
2. **预算前移**：骨架轮数×轮长=对话字数下限，结构上锁死
3. **胶水隐喻**：叙述从"主体"降级为"胶水"，胶水的物理属性就是少

## 五步流程

### Step 0｜对话预算表（写进场景卡）
```
谁说话：老许/吴姐/陈默
话痨位（老许/吴姐）：每人≥15轮
沉默位（陈默）：≥5轮，轮长1-10字
废话：≥2处（各带人设功能）
打断：≥1处
beat信息分配：60%以上信息由谁的嘴递出
```

### Step 1｜生成对话骨架（剧本态）
格式：`编号. 人物名：台词`，一行一轮。
**禁止任何叙述、动作标签、心理描写**——出现即回炉。

硬值规则：
| 指标 | 硬值 |
|---|---|
| 话痨位角色 | 每人≥15轮 |
| 沉默位角色 | ≥5轮（短轮放信息爆点） |
| 主力轮长 | 20-50字/轮 |
| 短轮(≤10字) | ≤10%（接梗/冷场/打断） |
| 长轮(≥60字) | ≤10%（讲古/跑题） |
| 跑题/废话 | ≥2处（各带人设功能） |
| 打断/抢话 | ≥1处 |
| 语气助词 | 呢/吧/啊/嘛/呗/呀 每种≥1次 |

### Step 2｜骨架数数验收（闸门一）
逐项数：总轮数/每人轮数/轮长带/废话数/打断数/六助词。
抽3轮遮名测试。beat对表。
**不过只改骨架，不许带病进填充。**

### Step 3｜叙述填充（上胶，顺序固定）
三道胶按顺序上，每道有配额：

| 胶水类型 | 单处上限 | 每场上限 | 规则 |
|---|---|---|---|
| 动作标签 | ≤15字 | 不限 | 动词优先；裸"说道"≤2次/场；优先中插 |
| 场景转换 | ≤30字 | ≤2处 | 一句带过；三行以上=违例 |
| 内心独白 | ≤40字 | ≤3处 | 口语体；禁"他感到/他心中一沉" |

**删规则**：删掉不损失信息/笑点/钩子的叙述→删。纯氛围段→删。超3行连续叙述→拆或删。

### Step 4｜组装与配比实测（闸门二）
实测对话占比。目标带：**55%-70%**。
低于50%→只删胶水，**不许删对话**（单向回炉）。

## 七条保护机制

1. 骨架独立保存，填充只准加胶不准改台词
2. 胶水双配额（字数+次数），超一项即违例
3. 配比实测+单向回炉（只删叙述不删对话）
4. 信息单位翻转：60%信息由对话递（设定=对话）
5. 删单优先级：纯氛围→重复信息→心理段（对话永不在删单）
6. 长段警报：超3行连续叙述自动触发拆/删
7. 接受带而非极值：情绪重场可降到45%（要改卡声明）

## 骨架示例（50轮·《回响》）

```
1.  老许：先说好，这趟算你私人帮忙，所里车不能派，油钱你自己掏——别瞪我，我一个月工资也没比你高哪儿去。
2.  吴姐：两位把鞋套戴上吧。家属发话了，主卧的东西一件不许动——我也没办法，人家给所里捐过两台空调呢。
3.  陈默：围巾呢。
4.  吴姐：还在床头柜。家属本来要收走，我说这是案件关联物，才压下来的。
5.  老许：等会儿，你昨天就来过了？案子前天夜里才报的，你这出警速度比所里还快啊。
6.  陈默：顺路。
7.  老许：顺路，城东新区，你家在城西——全城你能顺出最远的一条路。（对吴姐）他就这样，你别理他。
8.  吴姐：陈顾问昨天还围了那条围巾，对着镜子说话呢。我在门口看着的，汗毛都立起来了呀。
9.  老许：他吃这碗饭的。（顿）……他对着镜子说什么了？
10. 吴姐：就两个字，好看。
11. 老许：好家伙。这小子对活人都没这么客气过。
12. 陈默：她等这句，等了三年。
...
33. 吴姐：哎呀说到钱，所里这个月的补贴还没发呢。冻疮膏我都使第三管了。
34. 老许：我给你个偏方，茄子秆煮水泡手——
35. 吴姐：许哥，我泡过，泡完更痒。
36. 老许：那是你煮的时间不够。
...
49. 吴姐：她被拖到巷口的时候，挣扎了两下。回响是不会挣扎的。
50. 吴姐：她回头了。看了摄像头一眼。就一眼。
```

## evals
- "写这个场景" → 先产出骨架，再上胶
- "对话太少了" → 检查是否先生成了叙述（顺序错了）
- "对话太密了" → 检查是否废话配额不足（需要稀释）
