# scene-discipline:场景化写作纪律（全书通用·每次写章前必读）

> 来源：全书138章多维度审计的系统性教训。此技能存在的目的：防止AI写手退化为"大纲式散文"模式。

## ⛔ 三条铁律（违反任何一条=必须重写）

### 铁律1：禁止叙述概述对话
```
❌ 他们讨论了红笔案的细节，最终决定分头行动。
❌ 两人商量了一会后，觉得天衣无缝。
✅ "你查纸坊，我查钱庄。"陈更把地图推过去。
   "要是碰到执笔的人呢？"
   "碰到再说。"
```
**判定标准**：如果两个角色之间的对话被压缩成一句叙述，而非逐句写出——FAIL。

### 铁律2：禁止叙述概述发现
```
❌ 陈更查了卷宗，发现了关键线索。
❌ 经过三天的调查，他终于弄清了真相。
✅ 陈更翻开第三册。手指停在了第七十三页。
   他把纸凑到灯下。纸背透出一个印子——淡的，圆的，像针眼。
```
**判定标准**：如果"发现"的过程被一句话带过，而非展开为带有动作、感官、递进的场景——FAIL。

### 铁律3：心理活动每千字≥2处
```
❌ （全章没有任何内心独白、心理反应、情感挣扎）
✅ 他想，师父要是还在，这时候该说什么。
✅ 心里一沉。他知道这意味着什么。
✅ 他忽然想起母亲信里那句话——越欠越富。
```
**判定标准**：check.py自动检测（心理词频<1.0/千字=FAIL）。心理活动不限于"他想"，可以是条件反射（手停了）、身体反应（后背发凉）、条件联想（忽然想起某人的话）。

## 🔧 信息交付三法（查案/发现/揭示必用）

信息不能靠叙述"告知"读者，必须通过以下三种方式之一"演"给读者：

### 方法1：对话交付（最常用）
两个角色讨论案情，信息在对话中自然流出。
```
"死者手里攥着一支笔。"
"什么笔？"
"红杆的。笔头秃了——秃得不成样子。"
```

### 方法2：动作交付（最适合发现）
角色通过具体动作（翻页、对灯、摸痕）让读者"跟着发现"。
```
他翻开第三册。手指停在第七十三页。
纸背透出一个印子——淡的，圆的。
他用指腹摸了摸。硬的。烧进去的。
```

### 方法3：比较交付（最适合揭示差异）
两个角色或两份物证放在一起，差异自己说话。
```
他把两本账并排摆在灵前。
戒尺落下去。笃。声闷的。
戒尺移过去。笃。也是闷的。
```

## ⚠️ 最后一道自检（写完每章后问自己三个问题）

1. **遮名测试**：把角色名遮住，能不能从对话判断出谁在说话？
2. **电影测试**：如果拍成电视剧，这一章有没有足够的"演员台词+动作戏"？还是全是旁白解说？
3. **删减测试**：如果删掉所有对话，剩下的叙述还能不能独立成章？如果能——说明对话只是装饰，不是骨架。FAIL。
