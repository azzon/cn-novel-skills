# world-rules:世界规则

> 溯源:docs/22§三(Sanderson法则/限制>能力/规则靠撞上)·21。产物:`story/10-世界/规则.md`(世界域第一叶)。

## 前置条件

`story/00-前提.md`、`story/01-主题.md` 存在。规则必须服务于前提与主题——先问"故事需要什么规则",不先造百科。

## 流程

**1 根本法则(3-5条)**
1.1 写本世界的根本法则(这个世界"物理"级别不可违背的东西,含金手指所属的法则);
1.2 每条配:**限制**(它做不到什么)与**代价**(用它要付什么)——限制与代价才产生故事(Sanderson第二法则);
1.3 限制要具体到可以写进冲突("听真话伤寿三日"优于"有代价")。

**2 例外(故事发生的地方)**
2.1 每条法则找例外:谁/什么情形例外?例外的代价更高(例外是剧情的富矿,不是bug);
2.2 每个例外登记:首次撞上的章次(预算内)。

**3 撞上方式(呈现纪律)**
3.1 每条规则写一行"读者在什么冲突里学会它"——**禁止任何角色口头讲解规则**;
3.2 标注首撞章次(黄金三章内至少撞上核心规则一次);
3.3 **设定挂麻烦律**(红队G):每条规则进场时必须"对主角当下不利或有直接用处"——它给主角添的麻烦是什么?答不出的设定推迟出场;
3.4 **不可靠转述者**(红队G):大块设定必须由**有立场的角色带着目的**说(他说的版本带他的利益/误解/隐瞒),禁"客观中立"的百科式转述;禁"如你所知"式伪装对话(check.py #27机械检测)。

**4 规则-故事对表**
4.1 逐条问:"这条规则产生了什么故事?"(冲突/两难/代价)答不出的规则→删(百科留给读者脑补);
4.2 与两难库(theme-dossier产物)对表:核心规则应能生成其中至少两条两难。

## 闸门

法则3-5条且各有具体限制与代价/例外有更高代价且标注首撞章/无口头讲解依赖/每条设定挂了麻烦/大块设定有不可靠转述者/规则-故事对表零废条。
