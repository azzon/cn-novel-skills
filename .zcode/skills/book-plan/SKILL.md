# book-plan:单本商业计划(预算与回报周期)

> 溯源: 磨刀十五批——"写多少写多久"此前在发布前(publish-prep)才想,公司立项即锁预算。

## 流程
1. **平台决策**: 目标平台(起点付费/番茄免费七猫/多平台)——对照读者画像消费场景;免费流=节奏更快/单章更短/黄金三章更狠
2. **体量承诺**: 总字数(150万/200万/300万档)×卷数×每卷章数——对照plot-spine三段式容量
3. **周期承诺**: 完本时间=总字数÷日更;日更档位(4千/6千/8千)与断更红线(连续3天断更=商业死亡)
4. **存稿计划**: 上架前存稿≥30章(缓冲),上架后存稿安全线≥10章
5. **产能核算**: 日更承诺 vs 本书流程实测成本(生成记录的迭代轮数×单章耗时)——不可持续=降档或简化日更轨(冷读抽检)
6. **系列化**: 完本后策略(世代续作/角色宇宙/独立完结)一句话定位
7. **落盘**: `<书根>/story/10-世界/商业计划.md` 七节

## 闸门
- 七节齐,数字全落地(禁"争取日更")
- 产能核算有生成记录或同类书实测背书(拍脑袋=不过)
- 与publish-prep发布检查单对齐(时序: 本技能立项期,publish-prep发布前30天)
