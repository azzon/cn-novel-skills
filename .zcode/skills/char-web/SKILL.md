# char-web:人物网络

> 溯源:docs/21(对手=主角变体/假盟友)·22(立场原则:对手三件套)。产物:`story/20-人物/网络.md`。

## 前置条件

主角与主要配角的 `char-bible` 产物存在(网络连接的是已完成的人)。

## 流程

**1 关系图**
1.1 画主要人物关系图(节点=人,边=关系动词,禁"朋友/敌人"这种名词边——用"欠/护/忌/瞒"这种可写戏的动词);
1.2 每条边标注:双方各自怎么看这段关系(信息差即戏)。

**2 立场光谱**
2.1 每个对手填三件套:**正当立场**(他为什么认为自己对)/守护之物/付过的代价;
2.2 光谱排布:按对主线问题的不同回答排开,主角只是光谱上的一极,不是中心;
2.3 三件套写不出→该对手退为功能性路人(降级处理,不给大戏)。

**3 镜像与假面**
3.1 主对手=主角的变体(争同一目标,价值观有理——立场原则);至少一个"镜像人物"(主角的可能未来);
3.2 设≥1个假盟友(表面同路,立场相左)与≥1个假对手(表面为敌,暗中同路)——每卷至少变一次阵营温度。

**3.5 群像的结构性容器(红队F2:塔罗会/打更人衙门实证)**
3.5.1 长篇配角群必须装进**容器**:仪式容器(定期聚会的固定场景,如塔罗会)+代号系统(成员间的第二身份)+科层容器(晋升触发群像换血);
3.5.2 **平行成长线**:每个容器成员有自己的进度,聚会时互相对账(主角在长,他们也在长);
3.5.3 **信息差高位**:主角在容器中占信息差高位(他知道别人不知道的),这是群戏的引擎;
3.5.4 **戏份预算**:单个配角戏份<15%/卷(实证红线:临安公主超限遭读者反噬);群戏出勤:核心配角每20-30章至少一次有戏分的出场(跨地图心跳锚)。

**3.6 反派五件套与败亡节奏(红队F2)**
3.6.1 立反派先立**威胁感**再给同情(汉尼拔>伏地魔的顺序铁律:先怕后懂,不是先懂后怕);
3.6.2 反派五件套:①主题的反面解法(他与主角争同一问题的不同答案)②压迫战绩(至少一次当众碾压主角阵营)③留活口的理由(为什么不直接杀死主角——必须立法)④边界原则(他也有所不为)⑤伏笔可回溯(他的行为在前文可查);
3.6.3 败亡三段式:断爪牙→揭底牌→正主伏诛;**见证者机制**(败亡场面必须有前文受害者/旁观者在场);最高级败亡=**守原则反被原则害**(他的"有所不为"正是死因);
3.6.4 恶人两层分级(红队M):单元级人渣可恨可打不给苦衷;只有顶层对手享受"不是恶"待遇——200万字需要恨意燃料。

**4 态度互斥矩阵**
4.1 抽查矩阵:任意两人对核心事件的态度必须有差异;全同→合并或改立场(人人同意的地方没有戏)。

## 闸门

关系边全动词化/对手三件套齐/光谱非中心化/真假两面各≥1/互斥抽查零全同。
