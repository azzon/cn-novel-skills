# Skill: writing-heart
# writing-heart:写作的灵魂层（超越所有技术规则的最高层）

> 来源：红队D审计的核心问题——"这套技能库造出来的文章，会不会每个零件都合格但整体没有灵魂？"
> 本技能是所有技能的上位技能。当本技能与其他技能冲突时，**本技能优先**。

## ⛔ 灵魂三问（写每章前问自己）

### 1. 这一章的"心跳"是什么？
每一章必须有一个让读者"心里咯噔一下"的瞬间。
- 可以是一句话（"对完账，就回家"）
- 可以是一个动作（把账册往怀里又捆紧了一圈）
- 可以是一个沉默（她没有说话）

**如果一整章都没有心跳——这章是死的。重写。**

### 2. 我爱这个角色吗？
写之前问自己：我写这个人时，是在"操作一个工具"还是在"陪伴一个活人"？
- 工具人写法：他做了A，然后做了B，效果是C
- 活人写法：他做A的时候手在抖，因为他想起了那年的事

**如果你不爱你的角色，读者也不会爱。**

### 3. 这一章我"忍不住想写"还是"不得不写"？
- 忍不住想写：有好场面、有好对话、有让你自己笑了或哭了的东西
- 不得不写：为了推进度、为了填大纲、为了完成KPI

**如果你写的时候无聊，读者读的时候更无聊。跳过这章或换一种写法。**

## 📝 灵魂注入五法

### 法1：每章一个"只有这个角色才会做的细节"
```
✗ 通用写法：他很难过。
✓ 陈更式：他把那笔账重新誊了一遍，誊完发现墨迹比昨天深了——他按笔太重了。
✓ 樊大式：他把杀猪刀磨了三遍，磨完了发现没猪可杀，蹲在门槛上发呆。
✓ 闻人霜式：她把那份笔录翻到最后，又翻回来，在"核三遍"旁边写了第四遍。
```

### 法2：让配角"活在他自己的世界里"
主角不在场时，配角在做什么？他们有自己的烦恼、自己的快乐、自己的小算盘。
```
✓ 老更夫回家路上会数路灯，数到第七盏的时候会想：周聋子那个老东西，走了也好，省得每天听我打更。
✓ 樊大收摊后会跟他娘说今天的事，说到"更子"的时候声音会大一点。
```

### 法3：对话中的"废话"是人味
真实的对话不是每句都推进剧情。真实的人会说废话、会打断、会跑题。
```
✗ 纯功能对话："查到了。""在哪里？""码头。"
✓ 有人味的对话："查到了。""真的假的？你吃了没？""……什么？""我问你吃了没。一天没吃东西查什么案。""……码头。"
```
**注意**：废话率控制在10-15%，不是让你写闲聊小说。

### 法4：场景的"温度"
每个场景不只是"发生了什么"，还有"感觉如何"。
- 冷的场景：不写"很冷"，写"他把手缩进袖子里，发现袖口也是凉的"
- 热的场景：不写"很热"，写"汗从下巴滴到账本上，他把那页折了个角"
- 穷的场景：不写"很穷"，写"他数了三遍钱袋，每遍都是四百二十三文"

### 法5：结尾的"余韵"
章末不是"任务完成"。章末是"这个瞬间过去了，但它留下了什么"。
```
✗ 任务式结尾：案子结了。他离开了。
✓ 余韵式结尾：案子结了。他走到门口，回头看了一眼那个灵位。灯还亮着。
```

## ⚖️ 灵魂与规则的冲突裁决

| 冲突 | 裁决 |
|---|---|
| 灵魂 vs 对话占比 | 灵魂优先（宁可对话少，不可人味无） |
| 灵魂 vs 字数 | 灵魂优先（宁可短一章，不可水一段） |
| 灵魂 vs 声纹卡 | 声纹优先（声纹是灵魂的载体） |
| 灵魂 vs 反AI纪律 | 灵魂优先（好句子不怕像AI，怕的是没灵魂的原创） |
| 灵魂 vs 节奏 | 视情况（快节奏时灵魂在动作里，慢节奏时灵魂在沉默里） |

## 与其他技能的关系

- **所有技能的下位**：本技能是最高优先级
- **scene-discipline**：技术层的好规则，但执行时要问"这一刀切下去有没有温度"
- **duanzhang**：断章的目的是制造张力，但张力的本质是"读者在乎"
- **plot-freshness**：反重复的目的是保持新鲜，但新鲜的本质是"真诚"

## 最后

**规则让你不犯错。灵魂让你被记住。**

一个读者读完300章后记住的不是"对话占比45%"，是"对完账，就回家"。
