# char-bible:人物圣经

> 溯源:docs/22§一(立体十问/want与need/压力反应模式)。产物:主角固定 `story/20-人物/主角.md`(gates按此查);重要配角每人 `story/20-人物/<人名>.md`。

## 前置条件

`story/00-前提.md`、`story/01-主题.md` 存在(人物从主题与前提长出,不是先有人再找事)。

## 流程

**1 三层档案**
1.1 生理层:年龄/外形(3个可写进动作的特征,禁发色瞳色流水账)/习惯性小动作;
1.2 社会层:出身/生计/关系位置/被人怎么议论;
1.3 心理层:恐惧/欲望/自我认知(他以为自己是什么人)。

**2 弧线链(英文圈标配+本书加强)**
2.1 Ghost(往创)→Wound(伤口)→Lie(他信的谎)→Want(外在欲望,按卷梯度兑现)→Need(内在需求,终局才破);
2.2 **内在矛盾**:他同时想要两个不可兼得之物(这对矛盾是他全部魅力的发动机,写不出=人物没立住);
2.3 Want按卷排梯度(每卷要赢什么,接reward-economy);Need的破除时刻登记在卷纲;
2.4 **弧光类型三选**(红队F):正向弧光(挑战后自我成长)/负向弧光(堕落)/**平面弧光**(信念坚定者改变周围世界——网文主角最常用:许七安/萧炎式"我信的东西从头到尾没变,变的是我能为它做什么");弧光本质=**内在信念的不可逆转变**("信的东西"变了),不是外在经历堆砌;
2.5 **活人感公式**(红队F):核心特质+鲜明缺陷+标志动作+成长弧光;**欲望与软肋的反差**是活人感核心(AI人物走直线的解药);
2.6 **翻转法**(红队F):把缺点变优点或反之——关键时刻让角色做出意料之外的决定(胆小者的孤注一掷/抠门者的倾囊)。

**2.7 决策语法四件套(红队F2:许七安/韩立实证,替代单句if-then)**
2.7.1 **目标标尺**(一票否决项:什么情况下他什么都肯干)+**禁区**(死也不做的事)+**执行烈度**(要么不做要做做绝?还是点到为止?)+**破例条件**(谁/什么事能让他在禁区破例);
2.7.2 双层算法范例:许七安=90%市侩人情世故外层+10%"民"字底线直通层,**人格高光全部发生在切换瞬间**——读者记住的从来不是规则,是规则的破例(韩立为承诺灭门);
2.7.3 **支柱词**:给他2-3个反复出现的私用词(韩立"道友"/许七安"诸位")——人格的听觉签名;
2.7.4 **双标检测**(唐三教训:驰名双标=主角口碑第一毒点):对人严对己宽的条款一条都不许有——立法时逐条问"这条用在别人身上他还会这么干吗?";
2.7.5 **代价排期**:人设的代价不能永远悬置——每卷至少兑付一次(怕死的必须在某卷真的面对死)。

**3 行为锚(防崩机制)+首秀协议(红队F2)**
3.0 **首秀卡四件套**:人物首次出场=①事件(他在干什么,不是他长什么样——**首个动作优先于外貌**)②特质演示(第一个动作就在演示核心特质:萧炎血书休妻=高烈度自主反击即人格宣言)③埋钩(首秀留一个未解处)④细微反应(一个只属于他的小动作)。**
3.1 压力反应模式:高压下第一反应是什么(不变项);
3.2 决策语法(if-then):"算得出的按X办,算不出的按Y办"式的一句可执行人格;
3.3 绝不做的事(死穴)——死穴即弧光,终局破一次。
