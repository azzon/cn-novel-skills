# rebuild:状态重建(ops域)

> 溯源:Claude-Code-Novel-Writer"手稿是唯一权威,追踪数据是派生物"原则。产物:重建后的ledgers/与story/60-圣经/。

## 前置条件

正文(text/)存在且为最新;台账疑似损坏/缺失/漂移(与gates或审计对不上)。

## 流程

**1 损伤评估**
1.1 盘点:哪些账缺/哪些账与正文抽查矛盾/时间线断点在哪;
1.2 评估重建范围(单账重建/全量重建)。

**2 从正文重导(手稿扫描法)**
2.1 逐章扫描正文,抽取:人物状态变更/数值变动(凡加必有源凡减必有处)/伏笔动作/钩级别/笑点类型/线推进——重填八账;
2.2 时间线:逐场重登日期/地点/在场人,重生成时刻卡;
2.3 圣经:按章摘要规则重新压缩。

**3 对账验证**
3.1 重建后重导后跑 python3 tools/pipeline.py status 核对(旧gates.py已归档);抽查三处与正文比对;
3.2 与旧账diff(若旧账残留):差异逐条判"正文对"还是"扫描漏"——**正文永远赢**。

## 闸门

八账+时间线+时刻卡齐/gates过/三处抽查零矛盾。
