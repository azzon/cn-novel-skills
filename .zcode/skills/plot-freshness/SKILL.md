# plot-freshness:情节新鲜度管理（反重复/反套路/反泄底）

> 来源：红队17（重复模式）、红队18（对话效率）、红队24（悬念管理）三大审计的系统性发现。

## ⛔ 五条反重复纪律

### 纪律1：异象"一器一用"制度
红队17检测：器物自异×8次（天地放款/纱动/秤动/算盘自鸣/鼓自鸣/大账翻页/血匾再生/血字渗透），功能100%单一（全部给主角背书）。

```
已用额度（冻结，不得复用）：
✗ 天地放款（26/52章）
✗ 白纱无风自动（43/48章）
✗ 铁秤自动（52/136章）
✗ 算盘自鸣（52/134章）
✗ 大鼓自响（80/105章）
✗ 大账翻页（48章）

后续异象必须：
① 换感官通道（温度/光影/嗅觉/味觉，不用听觉）
② 换立场——异象可以是：
   - 拒付（天地不认这笔账）
   - 算错（异象显出的账有误）
   - 审判（异象指向主角自己的债）
   - 沉默（该有异象的时刻什么都没发生——更可怕）
```

### 纪律2：胜利引擎轮换
红队17：每场胜利都是"掏出一本对方没算到的记录"（册子对册子）。

```
胜利引擎库（轮换使用，连续两场不用同一引擎）：
A. 册子反杀（已用3次：23/45/136——冻结至卷七）
B. 人证倒戈（让对方的人当堂开口——未用过）
C. 无实物心算（凭记忆揭穿，不掏任何东西——未用过）
D. 故意输（证据齐全却败诉，逼出"证据不是权力"——未用过）
E. 程序反制（用对方的程序困死对方——48章用过一次）
F. 民意压场（围观者的集体行为改变局面——6章用过一次）
```

### 纪律3：反派败走姿态去重
红队17：反派败走留话三连同构（"深意台词"预告代价）。

```
✗ 三连禁用：皂衣首领"楼内之事"+念账人"八十万功"+文渊"你收的是债"
后续反派败走方式轮换：
- 无言（只做一个动作）
- 反问（留一个问句而非陈述）
- 求饶（高层反派向主角低头——从未有过）
- 狂笑（精神崩溃式）
- 平静交代（像交代后事）
```

### 纪律4：对话不演讲
红队18：陈更话轮均长从70-100字（格挡式）单调升到120-200字（陈述式）——从"接招者"变成"演讲者"。

```
规则：
- 单轮对话≤100字（超过=在演讲）
- 每章宣言式对白≤3处（红队18实测126章8处=过载）
- 三连排比每章≤1处（"怕X怕Y怕Z"式结构正在固化为tic）
- 揭秘/危机场景：接收方至少打断2次（不能让一方独白超过150字不被打断）
```

### 纪律5：不替读者说破真相
红队24：128章主角推测已说破卷十真相七成。

```
规则：
- 主角的推测永远只能"半对"——真相比他猜的更深一层
- 终卷揭晓时让主角自己也承认"我只猜对了一半"
- 禁止叙述者或角色给出定性断言式的真相预告
```

## 📊 全局倒计时制度（红队24发现）

红队24：前135章无全局倒计时，136章才建立——太晚。

```
规则：
- 从卷三起，每卷至少一次"追诉时限"提醒
  （"被销之账追诉三十年，师父的账还剩X年"）
- 倒计时必须递减且有刻度感
- "天"的注视痕迹每卷只出现一次，逐卷逼近
```

## 📊 代价实付制度（红队19发现）

红队19：赌注在涨但实付归零——读者从第二次递帖就知道"他不会输"。

```
规则：
- 每次突破/递帖/认债，必须实付一项可感代价
- 代价要"留在身上"（不是付完就没事）
- "三月未赎"类挂账必须持续追踪（利滚利）
- 八十万功必须有还款进度条（每卷末更新）
- 让赢也流血
```

## 📊 金手指使用追踪（红队14发现）

红队14：账眼在卷一后完全退场（后期使用率0%）。

```
规则：
- 每卷至少2个案件中，账眼提供"只有它能提供"的线索
- 账眼必须有升级线（与境界突破咬合）
- 每卷至少1次"看不穿"的挫折（能力边界展示）
- 写完每卷后统计：账眼使用次数≥3次
```
