# unit-designer:单元设计器

> 溯源:docs/21(单元=主线一格)·23(喜剧场景密度)·单元案方法论。产物:`story/30-情节/单元库.md`(含母题库+使用登记表,活文件)。

## 前置条件

`story/30-情节/卷一纲.md` 存在(单元挂进卷序列)。

## 流程

**1 母题库(活资产)**
1.1 按母题分类建库(欲望类:求财/求子/求名/求寿/求恕…;关系类:亲子/夫妻/师徒/仇雠…;情境类:错认/隐瞒/交换/期限…);
1.2 每案登记:母题编号|变奏说明|结局态|章次(防重复台账:同母题间隔≥3案)。

**2 单元卡(每案一卡)**
2.1 **三层错位**:表(说出口的)/里(真实动机)/根(本人都没意识到的执念)——三层必须真的不同;
2.2 **对抗四力选一**:制度/人心/诡物/同僚(连用两案不重样);
2.3 **结局五态选一**:愿成/愿破/愿换/愿延/愿叛(连续同态≤2,每卷至少一破一叛防甜腻);
2.4 **漏网线**:本案结束留下什么线头=下案题面(案案相咬,禁独立单元);
2.5 主线格:本案给主线递什么(对咬合表)。

**3 公平性设计(涉谜案时)**
3.1 先写谜底,倒推三条前置线索(各注:埋于何章/当章第一功能)——一物两用;
3.2 红鲱鱼必须同时是真线索。

## 怪谈单元流配方(红队L:爆款实测)

- **三拍闭环(单元案情感结构)**:恐怖解谜外壳→悲情人性内核→情绪兑付收尾(怕→疑→悲→暖曲线,《非自然死亡》单集式);温情段禁插科打诨;
- **一案三用(咬合律)**:每个单元案必须①自身闭环②漏1条主线信息③主角弧线一格;每3-4个单元案安排一次主线大推进;
- **吓2暖1(配比)**:恐惧是"抑"、剧情爆发是"扬"——案内恐怖拍与温情拍约2:1;
- **防重复三件**:六型轮换盘(案型不连续重复)/短案优先(3-8章的小案好于15章大案——"前期短篇封神后期长篇下滑"实证)/第30案前后安排**结构自反案**(第一个不按套路的案子,刷新读者对规则的认知);
- **自耗型金手指四处方**(代价体系防失控,龙族反面教材):代价可读数(温度刻度)/每卷真咬人一次(代价必须真的兑现过)/"暖先行账后报"(兑付当场、代价延收——与"先爽后税"同律)/回温管道显性化(读者随时知道油箱还剩多少、去哪加油);
- **道具放置法**:单元案的关键道具在后文另一个案中变次要道具(草蛇灰线的单元版)。

## 闸门

三层真的错位/对抗与结局态不与前案重复/漏网线指向明/线索三件有当章功能。
