# unit-designer:单元设计器

> 溯源:docs/21(单元=主线一格)·23(喜剧场景密度)·单元案方法论。产物:`story/30-情节/单元库.md`(含母题库+使用登记表,活文件)。

## 前置条件

`story/30-情节/卷一纲.md` 存在(单元挂进卷序列)。

## 流程

**1 母题库(活资产)**
1.1 按母题分类建库(欲望类:求财/求子/求名/求寿/求恕…;关系类:亲子/夫妻/师徒/仇雠…;情境类:错认/隐瞒/交换/期限…);
1.2 每案登记:母题编号|变奏说明|结局态|章次(防重复台账:同母题间隔≥3案)。

**2 单元卡(每案一卡)**
2.1 **三层错位**:表(说出口的)/里(真实动机)/根(本人都没意识到的执念)——三层必须真的不同;
2.2 **对抗四力选一**:制度/人心/诡物/同僚(连用两案不重样);
2.3 **结局五态选一**:愿成/愿破/愿换/愿延/愿叛(连续同态≤2,每卷至少一破一叛防甜腻);
2.4 **漏网线**:本案结束留下什么线头=下案题面(案案相咬,禁独立单元);
2.5 主线格:本案给主线递什么(对咬合表)。

**3 公平性设计(涉谜案时)**
3.1 先写谜底,倒推三条前置线索(各注:埋于何章/当章第一功能)——一物两用;
3.2 红鲱鱼必须同时是真线索。

## 闸门

三层真的错位/对抗与结局态不与前案重复/漏网线指向明/线索三件有当章功能。
