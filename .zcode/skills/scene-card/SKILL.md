# scene-card:场景卡(写作域闸门叶)

> 溯源:docs/24(场景工艺)·23(喜剧)·25(钩/获得)·27(场景卡v3模板)。产物:`text/卡/卷N-章X-场Y.md`。

## 前置条件

`story/30-情节/卷一纲.md`(章场景清单)与 `story/50-风格包.md` 存在。缺→回ideate域/style-compiler。

## 流程

**1 领卡(从卷纲取位)**
1.1 在章场景清单中定位本场景:章号/场景号/预标(场景型/钩级别/获得类别)——**照预标填,改预标先改卷纲**。

**2 填卡(全字段,答案式)**
2.1 戏剧问题(一个问句)/价值:开__→收__(必须换极);
2.2 双方攻防(不定式各一)/beats≤3(动名词,**每个beat标注数字数预算**,场景总字数带=beats总和+400生活余量——20260917校准:15章实证旧公式+600虚高40%,首稿系统性欠带30%+全靠补丁回填;beats预算按实产基线压12%报,如目标2400字章则beats写2000)/有代价的选择;
2.3 进出:晚进点(从哪句进)/早出点(停在哪拍);
2.4 喜剧:**责任人+类型+一句话内容**(常驻编制见声纹表末节,无责任人的笑点栏=无效)+主笑点类型编号(docs/23十四型)+副型/callback(有则登记梗台账);
2.5 钩(场景末,**形态须与上两章不同——查ledgers/钩分布.md末3行**)与获得(四类之一,具体物);
2.5c **爽点行(必填,无此行=骨架卡)**: `爽点: 兑现P编号(七型之一,利息:超额收益)/充能P编号(悬念原料:挑衅|认可|机会)/扩散:谁围观+怎么传开`——七型与期待链见write:cool-point,管道状态查ledgers/爽点管道.md;**扩散栏(20260917温吞死修复):爽点兑现处必须设计围观/震惊/传开反应,装逼没人看=白爽,check.py爽感扩散门(<1/千字=FAIL)强制**;
2.5b ConWriter三栏:**Pre**(本场成立的前提)/**Post**(本场结束时世界的新状态)/**Forbid**(本场禁发生的事);
2.6 出场人声纹行(每人一行,从char-voice抄)/知情状态(谁知道什么,与上章对表);
2.5c2 **开场型(新章必填,大审计-08/11防同构)**: 本场第一段的开场方式,四选一——对话直入|动作直入|异常直入|判断句;**禁时间状语长叙述段开场**(>20字;初版'100%同构'经大审计-18勘误为度量假象,真实基线动作直入60%/时间状语28%,仍超配);且须与前两章实际开场错型(pipeline bundle会注入前两章开场型);
2.5d **数字表(必填,冷读验算依据)**: 本章出现的全部数字事实(金额/日期/年龄/天数)逐条列出——冷读按表验算,表外数字=穿帮嫌疑;**承接(转换约束)**: 上一场末状态一句话+本场开场如何接(治单元剧断裂,audits/22);
2.6b **焦点行(必填)**: `焦点: 2-3项,本章最高优先级`(bundle置顶注入,冲突时焦点获胜——治注意力超载,audits/21-Fix3);**章级行(必填)**: `章级: 普通|峰章`(峰章=卷纲标记的名场面章:字数上限5200、alt-takes多方案必走、done须--strict);
2.7 **生活层(v7必填,与剧情字段同级——缺生活层的卡=骨架卡,scene-draft拒工)**:
  - **细节×3**:本章不可移植细节清单≥3条(优先引`story/素材库.md`编号,现场造须个体化到"只有本书能用");
  - **钱面**:本场钱面事件(金额+谁的账+情绪运算方式;确无→写"以物代钱"的等价物);
  - **闲笔**:1处(≥60字,谁说/方向:好笑或漏规则);
  - **感官**:≥3通道(指定触/声/味/嗅/温中哪三类落在哪拍);
  - **慢拍**:(每2-3章≤1次,先查ledgers/钩分布.md尾·结构轮换账,连用即跳过)本章情感最重的一拍——三微拍处理;
  - **私货**:出场人物每人1个与剧情无关的动作(从素材库H袋取);
  - **家常**:≥1轮与任务无关的对话(谁和谁,聊什么)。

**3 卡自检(三问,不过自修)**
3.1 价值真换极吗(只写"变好"不算换)?
3.2 双方攻防真的相撞(不是各说各话)?
3.3 这场景删了后文塌吗(不塌→回卷纲砍)?

## 迷你样卡
```
戏剧问题:他敢不敢当众判师父?
价值:疑→信|攻防:他要当众验/师父要保颜面
beats:拦(400)/判(900)/付(600)|Pre:师父旧案卷宗已到手|Post:旧案翻案,师徒决裂|Forbid:真凶不揭
钩:中(异常供词)|获得:信息
```

## 闸门

全字段答案式填满(含2.7生活层)+三问过→卡落盘,头部注 `NEXT-SKILL: write:scene-draft`。生活层缺项=骨架卡,只配跑beat-expand回填,不配直接生成。
